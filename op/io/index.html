调用示例（浏览器控制台可直接执行）

// 1) 读取超星文件
const buf = await file.arrayBuffer();
const input = KGConverter.readWorkbook(buf);
// → { format:'chaoxing16'|'chaoxing15', headerRow, sheet, rows }

// 2) 转成统一课程图谱数据
const parsed = KGConverter.parseRows(input.rows, input.format);
const unified = KGConverter.toUnified(parsed, { course:'运筹学' });

// 3) 校验（模板硬约束）
const report = KGConverter.validate(unified);

// 4) 反向导出为超星文件
KGConverter.exportWorkbook(unified, 'chaoxing16', '导入.xlsx');

// 5) 旧版 / 新版互转（有损字段会列出）
const t15 = KGConverter.toChaoxing15(unified);
console.log(t15.lostFields);
转换只在浏览器内存中完成，不产生网络请求；结果可下载为文件后再到超星后台导入。

✅ 完全兼容

  • 16 列 xlsx 读写（第 1 行说明 / 第 2 行表头 / Sheet3）
  • A—G 层级、H—J 关系、K—P 属性
  • 模板硬约束校验（5000/2000/1000/256）

⚠️ 转换后兼容

  • 15 列 ↔ 16 列（类型、标签、分类、四属性有损）
  • 空引用剔除、重复关系合并
  • 标签与知识点分类保留在统一数据扩展字段

❌ 不在范围

  • 超星在线 API / 账号 / 课程绑定 / 审核发布
  • 图片、公式、附件、习题挂载
  • 学习行为数据、平台内渲染样式、7 级以上层级
