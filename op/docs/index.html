通用课程知识图谱系统 · 运筹学 7 章知识图谱 · 完整版可阅读 README.md
一、任务目标与交付范围
  • 调研并保留原始模板：GitHub 星标靠前的 5 个知识图谱静态网站模板，下载快照、记录来源/星标/许可证/功能特点/可借鉴展示形式。
  • 统一课程图谱数据：以用户上传的运筹学 7 章 xlsx 与超星 16 列标准导入文件为依据，构建全站共用的数据。
  • 扩展超星能力：在超星导入/导出之上扩展课程图谱展示；不完全兼容处提供清晰的数据转换接口。
  • 模板特色功能可进入：5 个演示页分别展示各模板进一步特色，全部使用同一份运筹学数据。
  • 统一登录入口：通往通用系统、模板演示、导入导出；目录清晰、离线可运行、可当堂检查。
二、前置条件与可用资源

前置条件

运行环境任意现代浏览器（Chrome / Edge）；推荐本地服务 http://127.0.0.1:8765/，双击 HTML 亦可
后端依赖无：无服务器、无数据库、无 API Key、无登录鉴权服务
网络运行时不需要联网；d3 / mermaid / SheetJS / ECharts 均已本地化
超星平台仅文件级交换；课程绑定、资源挂接、审核发布需在超星后台完成
复现工具Python 3 + openpyxl（重建数据）、Node.js（接口测试）、Chrome（运行时探针）；仅复跑校验时需要

四、与超星格式的兼容范围

✅ 完全兼容

  • 16 列 xlsx/csv 读写，复刻第 1 行说明、第 2 行表头、Sheet3
  • A—G 层级、H—J 关系、K—P 属性无损
  • 模板 11 项硬约束校验

⚠️ 转换后兼容

  • 15 列 ↔ 16 列（类型/标签/分类/四属性有损）
  • 空引用剔除、重复关系合并、方向统一
  • 标签与知识点分类保留在统一数据扩展字段

❌ 不在范围

  • 超星在线 API / 账号 / 课程绑定 / 审核发布
  • 图片、公式、附件、习题挂载、学习行为数据
  • 7 级以上层级、跨课程图谱合并
完整逐列对照与硬约束清单：02_超星兼容范围与字段映射.md；转换 API：03_数据转换接口说明.md。

八、操作要点与常见注意事项

操作要点

  • 所有页面共用 data/course-kg.js；不要在页面里另写一份数据。
  • 导入页用于校验/转换/生成超星文件，不会替换全站展示数据。
  • 导出 16 列 xlsx 含模板第 1/2 行原文，可直接拿去平台导入。
  • 15 列导出会列出有损字段，不会静默丢弃。
  • 关系图节点半径 = 关系数，颜色 = 章节；点击节点看邻接与属性。

常见注意事项

  • file:// 下"载入内置示例"会因 fetch 受限而提示，改用手动选择文件即可。
  • Mermaid mindmap 在纯本地 UMD 环境可能不可分包加载，页面会明确提示并保留 flowchart 演示。
  • 登录是前端演示，不做真实鉴权；不要把真实账号密码写进本系统。
  • 更换基础数据需同步更新 data/course-kg.js，否则各页与 JSON 不一致。
  • 原始模板体积较大（约 200 MB），交付时请勿删改；校验脚本会检查其完整性。
三层校验（均可在项目文件夹内复跑）： python tools/verify.py（21 项静态一致性）· node tools/test_converter.js（22 项转换接口）· python tools/runtime_probe.py（Chrome headless 逐页检查 JS 运行时错误）。 当前结果依次为 21/21、22/22、16/16 页零错误，详见 04 / 05 / 06 号记录。
