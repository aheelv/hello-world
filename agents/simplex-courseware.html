第一章 · 认识线性规划

1.1 什么是线性规划

点击下方热点，逐个认识标准式的三个组成部分
互动：热点标注 × 3

线性规划（Linear Programming）：在一组线性约束条件下， 求一个线性目标函数的最大值或最小值。它是资源分配、生产计划、运输调度等问题最基础的数学模型。

max  z = 3x₁ + 5x₂ + 2x₃
s.t.  x₁ + 2x₂ + 3x₃ ≤ 14  （车间工时）
      2x₁ + 3x₂ + x₃ ≤ 11  （原料配额）
      x₁, x₂, x₃ ≥ 0

s.t.  x₁ + 2x₂ + 3x₃ ≤ 14   2x₁ + 3x₂ + x₃ ≤ 11   x₁, x₂, x₃, s₁, s₂ ≥ 0

小问答：当约束「恰好用完全部资源」时，松弛变量 s₁ 的取值是？

为什么需要松弛变量

松弛变量把「资源还剩多少」变成一个显式的变量：
s₁ = 14 − (x₁ + 2x₂ + 3x₃) 令所有决策变量为 0，得 s₁ = 14, s₂ = 11 —— 这就是初始基本可行解（什么都不生产，资源全剩余）。单纯形法正是从这个「原点」出发开始寻优的。

完成上面两条约束的转换，小问答题会自动出现。

2.2 顶点定理：最优解藏在角上

先点击顶点卡片算出各自的 z，再回答哪个是最大
互动：点选计算 × 5 + 判分题 × 1

顶点定理：若线性规划存在有限最优解，则至少有一个最优解出现在可行域的顶点（极点）上。 可行域有无穷多个点，但顶点只有有限个 —— 这正是单纯形法「只查顶点」的理论依据。

判一判：哪个顶点使目标函数 z = 3x₁ + 5x₂ 取得最大值？

从几何走向代数

图解法只能处理两个决策变量（画平面图），而真实问题往往有几十、几百个变量。

单纯形法的思路是把几何语言翻译成代数语言：

顶点（角点）↔ 基本可行解 沿边移动 ↔ 换一个基变量（枢轴） 「这条路还能更高吗」↔ 检验数 σ > 0

第三章 · 单纯形法原理

3.2 规则一：谁入基

先看规则，再做题（答错也会给出解析）
互动：判分题 × 2

检验数：往哪个方向走最划算

σj = cj − zj，表示「让非基变量 xj 从 0 增加 1 个单位， 目标值 z 能提升多少」。它就是单纯形表目标行里的数字。

入基规则与终止条件

在所有 σj > 0 的非基变量中，选 σ 最大的那个入基（最陡的改进方向）。
若所有 σj ≤ 0 —— 没有任何方向能再改进，当前解即最优解，迭代停止。

为什么取最小比值

x₂ 每增加 1，s₁ 就减少 2、s₂ 就减少 3。要让所有基变量保持 ≥ 0，x₂ 的增量不能超过任何一个上限： x₂ ≤ min(14/2, 11/3) = 11/3 超过它，s₂ 就会变成负数，解不可行。最小比值所在行的基变量被「顶」出去，这就是出基变量； 该行与入基列的交点称为枢轴元素（此处是 3）。

要点回顾
01

线性规划与标准形

三要素（决策变量 / 目标函数 / 约束）；「≤」加松弛变量化为等式，令决策变量为 0 即得初始基本可行解。

02

图解法与顶点定理

目标线沿改进方向平移，最后卡在可行域的顶点上；顶点有限个 —— 这让「逐点检查」成为可能。

03

单纯形表与两条规则

检验数 σ 指出「往哪走」（最大正者入基）；比值检验指出「能走多远」（最小 θ 者出基）。

04

迭代与终止

枢轴运算（归一 + 消元）完成换基；所有 σ ≤ 0 时达到最优。本课例题的最优值 z* = 135/7 ≈ 19.29。
