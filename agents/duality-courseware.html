对偶理论
每个问题都有它的另一面

Duality Theory

同一个生产计划，既可以问「怎么排产利润最高」，也可以问「这些资源各值多少钱」。 两个问题看似不同，答案却由同一组数字决定 —— 这就是对偶。

适合：运筹学 / 管理科学基础 时长约 30 分钟 互动练习 × 4

第一章 · 对偶模型

1.1 同一个工厂，两种问法

点击任意一个高亮片段，看它在另一个问题里对应什么
互动：片段对照

原问题 P厂长关心：怎么排产，利润最高？

max z = 3x₁ + 5x₂
s.t.
x₁ ≤ 4　（原料甲）
2x₂ ≤ 12　（原料乙）
3x₁ + 2x₂ ≤ 18　（工时）
x₁, x₂ ≥ 0

对偶问题 D经理关心：这些资源各值多少钱？

min w = 4y₁ + 12y₂ + 18y₃
s.t.
y₁ + 3y₃ ≥ 3　（对应 x₁）
2y₂ + 2y₃ ≥ 5　（对应 x₂）
y₁, y₂, y₃ ≥ 0
黄色高亮的是同一份数据在两个问题里的不同角色。点击左侧任一高亮片段，看看它在右边变成了什么。
一句话读懂：原问题求「在资源限制下最多赚多少」，对偶问题求「把这些资源整体租出去，最少该收多少钱」。 两者互相牵制，最优值必然相等 —— 赚不到更多，也少不了要价。
本节结论：z* = w* = 36

第二章 · 弱对偶与强对偶

2.1 弱对偶性：可行解互设上下界

任取一个原问题可行解 x、任取一个对偶可行解 y，永远有 cTx ≤ bTy
互动：任选 x 与 y

选一个原问题可行解 x = (x₁, x₂)

选一个对偶可行解 y = (y₁, y₂, y₃)

cTx 0
bTy 0

判断

cTx ≤ bTy
两条长度之差，就是「对偶间隙」。
绿色虚线 = 最优值 36：蓝条永远够不到它，橙条永远越不过它。
原问题的最优值不会超过 36，对偶问题的最优值不会低于 36 —— 上界与下界把最优值夹在中间。
第二章 · 弱对偶与强对偶

2.2 强对偶性：最优值恰好相等

把一批可行解的目标值标在同一根数轴上，从两侧向中间靠拢
互动：逐个标出
蓝色 = 原问题可行解的目标值（下界），橙色 = 对偶可行解的目标值（上界）。
所有蓝点都在 36 左侧，所有橙点都在 36 右侧 —— 中间那条竖线，就是最优值。
第三章 · 互补松弛与影子价格

3.1 互补松弛性：成对为零

点击表格每一行，展开这一对的取值与乘积
互动：逐对展开 × 5
原问题一侧取值 对偶一侧取值乘积
松弛 s₁ = 4 − x₁2 对偶变量 y₁0?
松弛 s₂ = 12 − 2x₂0 对偶变量 y₂3/2?
松弛 s₃ = 18 − 3x₁ − 2x₂0 对偶变量 y₃1?
原变量 x₁2 剩余 d₁ = y₁ + 3y₃ − 30?
原变量 x₂6 剩余 d₂ = 2y₂ + 2y₃ − 50?
yi · si = 0　（每个约束一对）
资源还有剩余（si > 0），说明它不值钱，影子价格必为 0。
xj · dj = 0　（每个变量一对）
产品在赚钱（xj > 0），说明它的对偶约束必须取等号，没有"超额利润"。
5 对乘积全部为 0 —— 这正是「这两个解同时最优」的判定条件。

第三章 · 综合

3.3 一对最优解的全景对照

同一份数据，两个方向，答案被四个条件牢牢锁定
结论：z* = w* = 36

原问题 Pmax z

max z = 3x₁ + 5x₂
x₁ ≤ 4　·　2x₂ ≤ 12　·　3x₁ + 2x₂ ≤ 18
x* = (2, 6)　z* = 36
两条约束取等号（原料乙、工时），原料甲还剩 2 个单位。

对偶问题 Dmin w

min w = 4y₁ + 12y₂ + 18y₃
y₁ + 3y₃ ≥ 3　·　2y₂ + 2y₃ ≥ 5
y* = (0, 3/2, 1)　w* = 36
两条约束都取等号；原料甲不值钱，所以 y₁ = 0。
① x 可行
x₁=2≤4；2×6=12≤12；3×2+2×6=18≤18 ✓
② y 可行
0+3×1=3≥3；2×1.5+2×1=5≥5 ✓
③ 值相等
z = 3×2+5×6 = 36；w = 12×1.5+18×1 = 36 ✓
④ 互补松弛
5 对乘积全部为 0 ✓（见上一页）
四条同时成立，就说明 x* 与 y* 是一对最优解。其中①②③是充分条件：只要能找到一对可行解使目标值相等， 就能断言两边都已最优 —— 不需要真的把两个问题都解一遍。

课程小结

一个问题的两面

对偶不是新问题
而是同一份数据的另一种读法
1

对偶模型：行列互换

约束 ↔ 变量、目标系数 ↔ 右端项、A ↔ AT；max 配 ≤ 与 x≥0 时，对偶是 min 配 ≥ 与 y≥0。

2

弱对偶：互设上下界

任何可行 x 给出下界，任何可行 y 给出上界：cTx ≤ bTy。差值就是「离最优还有多远」的度量。

3

强对偶：最优值相等

一方有最优解，另一方必有，且 z* = w*。本例 x*=(2,6)、y*=(0,3/2,1)，都等于 36。

4

互补松弛：成对为零

yisi = 0、xjdj = 0。有剩余的资源不值钱，赚钱的产品没有超额利润。

一条链 写对偶（A → AT）→ 弱对偶 cTx ≤ bTy→ 强对偶 z* = w*→ 互补松弛验证→ 影子价格 Δz = yi

本讲结束

原问题告诉你「怎么做最好」，对偶问题告诉你「什么最值钱」。
两者等价，却是两种完全不同的视角。
