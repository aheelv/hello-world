阶段一 · 基础夯实 M1–M9

目标：建立数学直觉与工程手感，能复现经典 ML 算法。
  • 补线性代数 / 概率 / 微积分 / 优化（3Blue1Brown + MML 书）
  • 精通 Python、PyTorch、Git、Linux、GPU 基础
  • 完成吴恩达 ML + CS229，手写线性回归 / 树模型 / SVM

阶段二 · 深度学习 M7–M13

目标：能独立训练 CNN/RNN/Transformer 并调参。
  • CS231n + CS224n + MIT 6.S191 + fast.ai
  • 精读《Deep Learning》《动手学深度学习》
  • 做一个完整项目（图像分类 / 文本生成）

阶段三 · 大模型与生成式 AI M13–M21

目标：理解并动手训练/微调大模型，跟踪最新范式。
  • CS336 从零训大模型 + Hugging Face LLM 课程
  • 掌握 SFT/LoRA/RLHF/DPO、推理模型、RAG、上下文工程
  • 复现一篇 2025–2026 主流论文（如 MoE / 多模态）

阶段四 · AI 工程与应用 M21–M29

目标：能把模型做成可落地、可评测、可部署的系统。
  • Agent 架构、工具调用、MCP、多智能体协作
  • 向量库、LLMOps、评测体系、vLLM 推理加速
  • 在垂直场景交付一个端到端应用

阶段五 · 科研与领域专精 M29–M36

目标：具备独立科研与教学能力，达到副教授层次。
  • 系统文献调研、论文写作、实验可复现
  • 在 1–2 个垂直领域深耕，投顶会 / 申基金
  • 开设课程、指导研究生、做技术报告

5关键里程碑与自测

用可验证的产出检验是否达到对应层级，而非单纯「看过课程」。

M6 · 基础达标

能手推梯度下降 / 反向传播；用 PyTorch 从零实现并训练一个 CNN。

M12 · 深度学习达标

在公开数据集上复现论文结果，写出可复现的实验报告。

M18 · 大模型达标

用 LoRA 微调一个开源大模型并完成 RAG 应用；理解 RLHF/GRPO 流程。

M24 · 工程达标

交付一个多 Agent 系统，含评测与部署，延迟/成本可控。

M30 · 科研入门

完成一篇领域综述；在 arXiv 或顶会 workshop 发表/投稿工作。

M36 · 副教授层次

主持课题、指导研究生、开设课程、在垂直领域形成持续产出与影响力。
