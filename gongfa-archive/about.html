关于与免责 ​

这是什么 ​

一个静态资料站 + 可核对资料库 + 可嵌入静态资源库项目，以《中国秘传养生术公开化现状调研报告》（2026 年 11 月 13 日）为唯一输入范围整理而成。站点内容只做文献编目、传承关系展示、来源核对与公开资源的本地展示，不提供功法教学。

静态站架构选型 ​

实测数据来自 GitHub REST API，查询时间 2026-11-13（UTC+8）：

候选Star最近推送许可本机可运行性结论

选择 VitePress 的依据：高星标且持续维护（前一日仍有推送）、MIT 许可便于保留版权声明、基于 Vue 3 与 Vite、内置静态搜索与响应式布局，且本机 Node 22 可直接安装运行。实际安装版本 1.6.4（npm 镜像 registry.npmmirror.com）。上游许可全文见项目根目录 THIRD_PARTY_LICENSES.md。

运行方式 ​

bash
cd gongfa-archive
npm install          # 首次；依赖 VitePress 1.6.4
npm run dev          # 本地开发预览，通常为 http://localhost:5173
npm run build        # 生成静态站点到 docs/.vitepress/dist
npm run preview      # 预览构建产物

构建产物为纯静态文件，可部署到任意静态托管；base 默认为 /，若部署到子路径需修改 docs/.vitepress/config.mts。已嵌入资源位于 docs/.vitepress/dist/media/，随静态站一并发布，不需要后端或第三方 CDN。

复现资料处理流程 ​

bash
python tools/extract_sources.py   # 1. 从报告抽取 212 个唯一 URL + 引用语境
python tools/collect.py           # 2. 首轮 HTTP 探测（基线日志）
python tools/collect_final.py     # 3. 最终采集（curl + HTTPS 升级 + 完整性校验）
python tools/build_catalog.py     # 4. 编译站点数据、功法详情页、来源清单与 CSV
python tools/crawl_assets.py      # 5. 资源爬虫：下载、SHA256 去重、受限状态台账
python tools/verify.py            # 6. 交付自检
npm run build                     # 7. 构建站点

步骤 5 依赖步骤 4 产出的 docs/data/catalog.json（含功法关联字段）。采集结果依赖当时的网络可达性与第三方站点状态；重跑时数字可能变化，日志会如实记录每次尝试。

合规与版权声明 ​

  • 版权：所有第三方资料的著作权与许可归原权利人。已存档的网页全文与许可未明示的 PDF 不在站内转载、不提供下载。
  • 资源嵌入边界：在允许访问和下载的范围内（官方/政务公开页面引用、服务器直返、无登录与 DRM、MIME 在允许列表内）采集的图片、公开音视频与样式表，在资源库逐条标注原始链接、来源页、SHA256 与版权状态后展示，仅供本地教学研究核对，不得再分发。受平台条款或授权限制的内容一律不下载，保留原始链接并标记状态。
  • 不新增疗效承诺：报告与历史出版物题名中的「抗癌」「抗衰老」「养生长寿」「返老还童」等表述，属传承人宣称或早期文献题名的原始记录，不等同于现代临床证据，不代表本站立场。
  • 不提供医疗或练习建议：本站不提供功法教学、动作示范、诊断、治疗或保健建议；患病请接受规范医疗并遵医嘱。
  • 不构成背书：可信度分级只评价来源类型，不评价功法真伪，也不构成对任何流派、机构、传承人或出版物的推荐。
  • 不编造缺失信息：无法获取、来源不明、许可未明示或可靠性不足的内容逐条注明原因并排除；报告已声明未获取的 ISBN、论文篇数、早期新闻存档均保持空缺。
  • 版本与争议：金刚功删改版、大雁功「总部」名义、冒名账号、自称流派等争议均在排除与缺口中标注，未作事实采信。

适配性 ​

站点为浅色主题，采用固定配色（蓝 #2E5C8A / #4A90D9、绿 #27AE60、橙 #E67E22、粉 #D4537E、紫 #7F77DD）。资料卡片、资源卡片、筛选工具栏、统计条形图、传承链与非遗表格均针对窄屏做了自适应；宽表格在移动端可横向滚动，时间轴图表可横向查看。站点装饰图形（图标、图表、时间轴）均为项目原创 SVG / CSS；资源库中的第三方图片属于资料本身，逐条标注出处。图片懒加载、音视频按需加载，不阻塞首屏。
