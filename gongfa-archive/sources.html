本表为站点内的可核对视图。完整 212 条清单另以两种格式随项目交付： SOURCES.md（按状态分组的完整 Markdown 表）与 data/sources_verified.csv（含 SHA256、两次访问尝试、报告行号与引用语境）。 归档文件体积约 57.0 MB。

三种可核对格式 ​

文件用途
SOURCES.md按下载状态分组的完整 Markdown 表，212 条逐条列示，便于人工阅读与版本比对
data/sources_verified.csv同清单 CSV（UTF-8 BOM），含 SHA256、报告行号、报告引用语境、关联功法 ID，便于 Excel 筛选
data/visit_log.json机器可读的完整访问日志：两次访问尝试、HTTP 状态、Content-Type、字节数、耗时、最终 URL、页面标题、排除原因
ASSETS.md / data/assets.json / data/assets_verified.csv静态资源台账：图片、音视频、文档、样式表的下载地址、SHA256、去重关系、来源页、站内路径与受限状态，见资源库

首轮探测日志另存为 data/visit_log_first_pass.json 与 data/catalog_first_pass.json，可与最终日志对照，查看哪些链接在改用 curl 与 HTTPS 升级后恢复访问。

采集方法与限制 ​

  1. 抽取：tools/extract_sources.py 从报告正文正则提取内联链接与裸 URL，保留锚文本、报告行号与该行的引用语境。
  2. 首轮探测：tools/collect.py 用 urllib 逐条 GET，记录基线状态。
  3. 最终采集：tools/collect_final.py 改用 curl，http:// 失败时自动尝试 https:// 升级；PDF 使用更长超时完整下载并校验 %PDF 头与 %%EOF 尾。
  4. 落盘判定：仅政务公开网页、国家级公共平台、官方媒体公开新闻页与完整 PDF 保存；其余逐条写明原因。
  5. 编译：tools/build_catalog.py 关联功法、生成站点数据、功法详情页与上述清单。

环境限制如实记录：本环境对部分 http://（80 端口）请求存在拦截，且第三方站点普遍设有反爬策略。最终仍有若干条目返回 HTTP 403；这些条目在清单中统一标注为「服务端拒绝访问」，未被伪装成「资料不存在」。少量链接为 404（已失效）或 502（网关错误），同样逐条注明。
