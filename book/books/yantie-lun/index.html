01

导读 · 全书概览

从始元六年的盐铁会议到桓宽的推衍成书：一部保存了两千年前经济政策辩论全过程的对话体政论

一、一场会议，一部书

《盐铁论》的开头是一句极简的史笔：「惟始元六年，有诏书使丞相、御史与所举贤良、文学语，问民间所疾苦。」汉昭帝始元六年即公元前 81 年，朝廷召集郡国荐举的贤良、文学六十余人，与丞相田千秋、御史大夫桑弘羊等就盐铁官营、酒榷、均输等政策当面诘难。会议的直接结果是「罢榷酤」而盐铁如旧，规模远不如争论本身热闹。约至宣帝时，汝南人桓宽（字次公，治《公羊春秋》，官至庐江太守丞）据会议记录「推衍、增广条目」，整理为十卷六十篇。《四库全书总目提要》概括其体例：「为书凡六十篇，篇各标目，实则反复问答，诸篇皆首尾相属。」也就是说，六十个篇名之下是一条连贯的辩论流，而非六十篇独立论文。

桓宽并未亲与会议，这一点决定了本书的性质：它既有会议实录的骨架，又有后代整理者的文学加工与立场取舍。末篇《杂论》借「客曰」与汝南朱子伯之言，点出与会人物（贤良茂陵唐生、文学鲁国万生之伦六十余人），并对桑弘羊、车千秋「深著微词」——这一段是判断作者倾向的关键内证。

二、谁在和谁辩

书中的发言者主要有三方。大夫（御史大夫桑弘羊一方，有时作「御史」「丞相史」）主张保留盐铁、酒榷、均输、平准，理由是边备军费、国家调控、通有无而平万物；文学（郡国所举儒生）主张罢之，理由是「与民争利」「进本退末」，认为示民以利会败坏风俗；贤良在后半部分发言渐多，议题转向吏治、奢俭与刑法，语气与文学相近而不尽相同。此外还有「丞相」（田千秋）居中调和、「客」在末篇作评。读时务必先分清发言者，否则极易把大夫的话当成作者的立场，或把文学的主张当成全书结论。

三、六十篇讲什么

前五卷（本议第一至国疾第二十八）是政策与价值的核心区：《本议》立纲领，《力耕》《通有》《错币》《禁耕》《复古》围绕本末、货币、山泽之利往复；《非鞅》《晁错》《刺权》《论儒》把争论引向对商鞅、晁错、儒者效用的评价；《园池》《轻重》《未通》《地广》《贫富》等再落到财政、疆域与贫富。后五卷（散不足第二十九至杂论第六十）议题明显外扩：《散不足》《救匮》论奢俭，《疾贪》《除狭》《后刑》论吏治与刑罚，《备胡》《击之》《结和》《和亲》《论勇》论匈奴与和战，《刑德》《申韩》《周秦》《诏圣》《大论》论德刑与法度，最后《杂论》收束全篇。可以说，盐铁只是入口，全书实际覆盖了西汉中期的财政、边防、吏治、教化与治国路线之争。

四、版本与校读

《盐铁论》自宋以来历代有刊本，较重要的有明弘治十四年涂祯刻本、明张之象注十二卷本、清张敦仁考证本，以及近人郭沫若《盐铁论读本》、王利器《盐铁论校注》。因正文为对话体、异体与通假字多，篇名亦偶有异文（如《繇役》或作《徭役》、《论菑》或作《论灾》、《国疾》或作《国病》），本站篇目以维基文库十卷全文所标六十篇为准，并在逐篇要点中提示常见异文。本站所引原文均由该全文核校，用简体转写，读者可据「读原文」链接复核。

五、怎么读

建议先走学习路径五阶段：辨人物与时间线 → 精读《本议》 → 按议题分组读前五卷 → 读后五卷的吏治与边防 → 回到《杂论》判断作者立场。再看思维导图建立七大议题的坐标，读核心理念把七组争论拆成「大夫怎么说／文学怎么说／分歧何在」，对照网上经典分析了解实录与重构、桑弘羊评价等公开争议，用名言警句记住双方最锋利的几句，最后回到六十篇逐篇核校。右上角 ⌕ 支持跨栏目检索。

六、一点提醒

本书最诱人也最危险的读法，是替古人选边站，把「大夫＝法家／功利」「文学＝儒家／道德」当成固定标签。实际上双方在不同篇章里不断换位：大夫也引《易》与管子，文学也谈财政实效；辩论的锋芒常在「同一价值如何落实」而非「要不要价值」。本站尽量把「谁说的」「依据什么」「针对什么」分开陈述，避免把对话体读成单声道的宣言。

02

学习路径

五阶段路线：先认清会议与人物，再精读《本议》抓住争论总纲，按议题分组通读六十篇，最后回到《杂论》判断编撰者的立场。每阶段标注建议篇目与可交付成果。

01

第一阶段 · 建立坐标系：会议、人物与版本

建议 2—3 天

本阶段目标：弄清始元六年（前 81）盐铁会议的缘起、参会三方、会议的实际结果，以及桓宽据记录推衍成书的时间差与版本链。

  1. 读《本议》开篇与《杂论》结尾前者给出「诏书使丞相、御史与所举贤良、文学语，问民间所疾苦」的原始场景，后者点出六十余位与会者并交代作书大旨；首尾合读即可框定全书。本议第一 / 杂论第六十
  2. 做一张人物立场卡分别记下大夫（桑弘羊一方）、文学、贤良、丞相田千秋的发言标记与主要主张，特别注意「御史」「丞相史」与「大夫」常属同一阵营。全书对话标记
  3. 记住时间差会议在前 81 年，成书约在宣帝时，桓宽并未与会；这决定本书既非逐字实录，也非凭空虚构。《四库全书总目提要》 / 百度百科·盐铁论
  4. 列一份版本清单涂祯本、张之象注本、张敦仁考证本、郭沫若《盐铁论读本》、王利器《盐铁论校注》，并记下常见篇名异文。本站「延伸阅读与出处」

阶段产出一页时间线 + 一张人物立场卡 + 一份版本异文清单。

02

第二阶段 · 精读《本议》：全书的总纲都在这篇里

建议 1 周

本阶段目标：把第一篇逐段拆开，能分别复述文学与大夫的完整论证链，而不是只记住「罢盐铁」三个字。

  1. 文学的论证链治人之道在防淫佚、广道德 → 官营与民争利、散敦厚之朴 → 百姓趋末者众 → 请罢盐铁酒榷均输，进本退末。本议第一
  2. 大夫的论证链匈奴寇边 → 修障塞屯戍 → 边用不足 → 兴盐铁、设酒榷、置均输以佐边费 → 罢之则内空府库、外乏执备。本议第一
  3. 两种「利」的用法标出双方各自在何处用「利」字：文学多指私利与风俗之害，大夫多指国用与调剂之利；概念不同是争论久持不下的重要原因。本议第一 / 力耕第二 / 通有第三
  4. 抄一遍双方核心句把「抑末利而开仁义」「愿罢盐、铁、酒榷、均输」与「蕃货长财，以佐助边费」「通委财而调缓急」并列抄写，做成对照卡。本站「名言警句」栏目

阶段产出一份《本议》逐段论证对照表，标明每一环的前提与跳跃。

03

第三阶段 · 前五卷：经济与价值的正面交锋

建议 2—3 周

本阶段目标：按「本末—货币—山泽—财政—人物评价」五组读完第二至二十八篇，看清双方如何把同一套价值推到不同政策结论。

  1. 本末与通商《力耕》《通有》《错币》《禁耕》集中讨论农商关系、货币与山泽之利；注意大夫引《易》「通其变」为官营辩护，文学则以「示民以利」相责。力耕第二 / 通有第三 / 错币第四 / 禁耕第五
  2. 政策效果与历史评价《非鞅》《晁错》《刺权》《复古》《论儒》把争论转为「商鞅之法有效吗」「儒者能安国吗」；双方都在用历史案例作论据。非鞅第七 / 晁错第八 / 论儒第十一
  3. 财政、疆域与贫富《园池》《轻重》《未通》《地广》《贫富》《毁学》等把问题落到具体制度与民生，读时可做「主张—理由—反例」三栏表。园池第十三 / 轻重第十四 / 未通第十五 / 地广第十六 / 贫富第十七
  4. 留意对话的连续性《四库提要》说「诸篇皆首尾相属」，试把相邻两三篇连读，找出上一篇留下的话头如何在下一篇被接住。卷二至卷五

阶段产出五组议题各一张论证对照表，并标出至少三处跨篇承接的话头。

04

第四阶段 · 后五卷：从经济到吏治、边防与德刑

建议 2—3 周

本阶段目标：理解议题为何从盐铁扩展到整个治国路线，并看清贤良在后半部发言增多带来的语气变化。

  1. 奢俭与吏治《散不足》《救匮》《疾贪》《除狭》把矛头指向风俗与基层吏治，其中《散不足》列举大量器物饮食，是社会经济史常引的材料。散不足第二十九 / 救匮第三十 / 疾贪第三十三 / 除狭第三十二
  2. 边防与和战《备胡》《击之》《结和》《诛秦》《西域》《和亲》《繇役》等把《本议》中的军费前提重新展开，宜与第一篇对读。备胡第三十八 / 结和第四十三 / 和亲第四十八 / 繇役第四十九
  3. 德刑与法度《后刑》《刑德》《申韩》《周秦》《诏圣》《大论》集中辩论法令繁简与德教先后，是全书哲学浓度最高的一组。刑德第五十五 / 申韩第五十六 / 大论第五十九
  4. 做一张议题迁移图把六十篇按议题涂色，观察从「财政」到「风俗—吏治—边防—法度」的推进，并写出三条理由解释这一安排。卷六至卷十

阶段产出一张议题迁移图 + 一篇「盐铁为何只是入口」的千字笔记。

05

第五阶段 · 回到《杂论》：判断编撰者立场

建议 1 周

本阶段目标：把「会议记录」「桓宽的推衍」「后世解读」三层分开，学会对一部有明确倾向的对话体政论作史料批判。

  1. 细读《杂论》注意「或上仁义，或务权利」的概括、对六十余位与会者的追述，以及对桑弘羊、车千秋的微词，判断作者更同情哪一方。杂论第六十
  2. 检查文本层累列出三处「像是整理者加入」的痕迹（如人物评骘、整齐的排比、首尾呼应），并说明为什么它们不能自动等同于会议原话。本站「网上经典分析」栏目
  3. 对照后世评价把《四库提要》「惜其议不尽行」、郭沫若与王利器的整理取向，以及当代关于桑弘羊的翻案讨论并列，看评价如何随时代问题变化。四库提要 / 郭沫若《盐铁论读本》 / 王利器《盐铁论校注》
  4. 写一份不站队的总结要求分别写出双方各三条最有力的论据、各一条最薄弱的环节，以及一条双方共享的前提。全部栏目

阶段产出一份分层清晰的史料批判笔记，与一份双方论据强弱对照表。

会议与文本这是一部什么性质的书
  • 始元六年盐铁会议 — 前 81 年诏举贤良文学问民疾苦，结果是罢榷酤而盐铁如旧。（本议第一）
  • 桓宽的推衍增广 — 宣帝时据会议记录整理，未亲与会，故兼有实录骨架与文学加工。
  • 三方发言者 — 大夫（桑弘羊一方）、文学、贤良；丞相居中，末篇「客」作评。
  • 《杂论》的史笔 — 追述六十余位与会者，对桑弘羊、车千秋深著微词，是判断作者倾向的内证。（杂论第六十）
  • 版本链 — 涂祯本、张之象注本、张敦仁考证本，近人郭沫若《读本》与王利器《校注》。
本末与义利最根本的价值分歧
  • 进本退末 — 文学主张抑末利、广利农业，认为官营使百姓趋末者众。（本议第一）
  • 开本末之途 — 大夫主张农商工师各得所欲，引《易》「通其变，使民不倦」。（本议第一）
  • 与民争利 — 「今郡国有盐、铁、酒榷，均输，与民争利」是文学最核心的指控。
  • 示民以利 — 「导民以德则民归厚，示民以利则民俗薄」，把政策争辩上升为风俗判断。
  • 富在术数 — 大夫以「富在术数，不在劳身」反驳重农唯一论，强调区位与流通。（通有第三）
财政与官营制度层面的具体争点
  • 盐铁酒榷 — 三项官营收入直接支撑边费，是「罢不罢」的焦点。（本议第一、非鞅第七）
  • 均输平准 — 大夫称「平万物而便百姓」，文学则讥其「开利孔而为民罪梯」。（本议第一）
  • 边用度不足 — 「蕃货长财，以佐助边费」——大夫全部财政论证的前提是匈奴战事。
  • 轻重之术 — 「天下之下我高，天下之轻我重」的国家调控思路。（轻重第十四）
  • 山泽与园池 — 资源归国家还是归民，牵出「擅山泽」与「困桡公利」的对称指责。（园池第十三、取下第四十一）
人物与学派评价用历史案例作论据
  • 商鞅之评 — 大夫称其「国富民强……有益于国」，文学则称「后礼让，先贪鄙」。（非鞅第七）
  • 晁错之评 — 削藩与边策的历史责任如何归属。（晁错第八）
  • 儒者效用之辩 — 御史讥孔子「当世不为治」，文学以「无势位，虽舜禹不能治万民」回应。（论儒第十一）
  • 申韩与德刑 — 法度能否补弊，法令繁简是否反而生奸。（申韩第五十六、刑德第五十五）
  • 孔子与六艺 — 双方都引经典，说明争的不是要不要儒家，而是如何解释经典。
民生与吏治后半部的现实关怀
  • 散不足与奢俭 — 《散不足》列举器物饮食之奢，是社会生活史的高频引用材料。（散不足第二十九）
  • 疾贪与禄薄 — 贤良指出小吏禄薄、上府下求层层相迫，把腐败归因于制度而非个人德行。（疾贪第三十三）
  • 上取有量 — 「用民之力，不过岁三日；籍敛，不过十一」——贤良提出的财政限度。（取下第四十一）
  • 水旱与阴阳 — 大夫归之于天时，贤良归之于政德，是汉代天人感应框架内的责任之争。（水旱第三十六）
  • 国疾与在位者 — 「国有贤士而不用，非士之过，有国者之耻」。（国疾第二十八）
边防与和战《本议》前提的展开
  • 备胡与屯戍 — 修障塞、饬烽燧的成本，正是官营政策被辩护的理由。（本议第一、备胡第三十八）
  • 击之与结和 — 主战与主和的往复，牵涉对武帝以来边功的评价。（击之第四十二、结和第四十三）
  • 和亲与世务 — 以德怀远还是以力制夷，与《本议》「善克者不战」呼应。（和亲第四十八、世务第四十七）
  • 繇役与险固 — 徭役负担与地理险固之争，把边防成本落回民生。（繇役第四十九、险固第五十）
  • 论勇与论功 — 对将帅、边功与「任武可以辟地」的再评价。（论勇第五十一、论功第五十二）
德刑法度全书哲学浓度最高处
  • 令与法 — 「令者所以教民也，法者所以督奸也」——大夫的法治提纲。（刑德第五十五）
  • 法令众则民惑 — 文学以「秦法繁于秋荼，而网密于凝脂」反驳法密可治。（刑德第五十五）
  • 民之仰法犹鱼仰水 — 「水清则静，浊则扰」，把法的正当性系于清明。（诏圣第五十八）
  • 时世不同 — 「衣弊而革，法弊而更制」——大夫一方的变化论根据。（诏圣第五十八）
  • 风俗使然 — 「文王兴而民好善……非性之殊，风俗使然也」——文学的教化论总结。（大论第五十九）

01

本末之辨：重农抑商不是一个标签

文学与大夫在「本」与「末」上的分歧，既有价值判断，也有对流通功能的实证判断

经济

经文依据

《本议》中文学开篇即言「抑末利而开仁义，毋示以利」，并以「百姓就本者寡，趋末者众」「末盛则质亏」说明官营政策改变了民业结构，结论是「愿罢盐、铁、酒榷、均输，所以进本退末，广利农业，便也」。《通有》中大夫则正面反驳：「古之立国家者，开本末之途，通有无之用」，并引《易》「通其变，使民不倦」，提出「工不出，则农用乏；商不出，则宝货绝」；《力耕》《通有》又有「富在术数，不在劳身；利在势居，不在力耕也」一类说法，把财富来源指向流通、区位与经营之术。

逻辑结构

文学的路径是「价值—风俗—生产」三段：国家若以利示范，民风趋于贪鄙；民风一变，务本者减少，粮食与财力之本动摇。其「本」不只是产业分类，更是社会秩序的根基。大夫的路径是「分工—流通—国用」三段：农、工、商各有不可替代的功能，官营与均输在于调缓急、通委财，最终佐边费、备灾荒。其「末」不是应被压制的对象，而是系统中的必要环节。两方使用同一组词，却指向两套不同的因果模型，这正是六十篇反复诘难而难有结论的原因。

常见误读

其一，把「重农抑商」直接等同于本书的结论。实际上会议结果是罢榷酤而盐铁如旧，大夫的政策主张在现实中并未被推翻；书中也完整保留了反方论证。其二，把文学读作「不懂经济」、大夫读作「唯利是图」——前者对官营挤占民业与吏治腐败的观察相当具体（见《疾贪》《散不足》），后者也常以《易》《管子》立论，并非不谈德。其三，忽略「本末」在汉代语境中的道德含义，只当作产业结构之争，会漏掉《本议》「散敦厚之朴，成贪鄙之化」这一层。

后世流变与阅读建议

后世经济思想史常把《盐铁论》视为中国古代「国家干预／自由放任」的早期文本，20 世纪的整理者又从不同立场重新评价桑弘羊。这类框架有启发性，但不宜把现代概念直接套回：汉代的「利」始终嵌在义利、风俗与边防的语汇中。读时建议做一张三列表，分别写「双方如何定义本／末」「各自援引的依据」「各自回避的问题」；填完会发现分歧最深处往往不是数据，而是评价尺度。

与民争利：一句指控背后的财政逻辑

文学把官营定性为道德问题，大夫把它定性为国防融资问题

财政

经文依据

《本议》文学曰：「今郡国有盐、铁、酒榷，均输，与民争利。散敦厚之朴，成贪鄙之化。」又引孔子「有国有家者，不患贫而患不均」，提出「天子不言多少，诸侯不言利害，大夫不言得丧」。同篇文学另有一句常被引用的财政观：「民人藏于家，诸侯藏于国，天子藏于海内……是以王者不畜聚，下藏于民，远浮利，务民之义。」大夫方面的对应陈述则是：「边用度不足，故兴盐、铁，设酒榷，置均输，蕃货长财，以佐助边费」，并追问罢之之后「使备塞乘城之士饥寒于边，将何以赡之？」《非鞅》又补上一层：「盐、铁之利，所以佐百姓之急，足军旅之费，务蓄积以备乏绝。」

逻辑结构

这句指控的力量在于把财政问题翻译成政治正当性问题：若国家亲自经商获利，君主便从裁判变成当事人，教化也就失去超然位置。文学因此不满足于论证「效率低」，而要证明「不该做」。大夫的回应则始终卡在替代性上：既然边防开支客观存在，罢去一项收入就必须指出另一项来源，否则只是把负担转嫁给守边士卒或另加赋敛。整场辩论里，双方真正没有交锋的是那个共同前提——国家所需之财终须取自民间；文学说「藏于民」，大夫说「一取之民间」不如统筹调度，《非鞅》中文学自己也留下「利不从天来，不从地出，一取之民间」的尖锐一句。

常见误读

其一，把「与民争利」读成纯粹反对国有企业，忽略它同时指向官商合流与吏治腐败（《疾贪》《刺权》有更具体的描写）。其二，把大夫的「蕃货长财」当作贪财自辩，实际上他在多数篇章里都以边费、赈灾与调缓急为理由，论证结构是条件式的。其三，忽略会议结局：罢榷酤而盐铁如旧，说明「争利」的道德指控并未转化为全面政策撤回，这一落差恰是《杂论》「惜其议不尽行」的背景。

后世流变与阅读建议

后世讨论常把这一对命题提炼为「藏富于民／国家统制」，并在不同时代各取所需。读原文时建议把每一处「利」字标出，注明是国用、民利、私利还是浮利；同一个字在双方口中的所指不同，是许多「看似针锋相对、实则各说各话」段落的根源。

均输平准：同一套制度的两种叙述

大夫称其「平万物而便百姓」，文学讥其「开利孔而为民罪梯」

财政

经文依据

《本议》大夫为均输、平准给出的定义相当清晰：「故盐、铁、均输，所以通委财而调缓急。罢之，不便也。」同篇另有：「以县官不失实，商贾无所贸利，故曰平准。平准则民不失职，均输则民齐劳逸。故平准、均输，所以平万物而便百姓，非开利孔而为民罪梯者也。」注意最后一句——大夫预先引用并否定了对方的措辞，可见「开利孔」「为民罪梯」正是文学一方的现成批评。文学的回应落在征收方式上：「古者之赋税于民也，因其所工，不求所拙」，指责均输以实物折算与官府采购扰民。

逻辑结构

大夫的模型：各地物产与劳逸不均 → 官府统筹运输与吞吐 → 平抑物价、均齐劳逸、阻断商贾囤积 → 百姓与财政同时受益。关键预设是官府能掌握信息、公正定价且不以牟利为动机。文学的模型：官府一旦成为最大买家与卖家 → 定价与折算权集中 → 官吏可借机侵渔、强取所拙 → 「利孔」既开，民众反而多了一条获罪与受剥的通道。关键预设是权力缺乏约束时必然外溢。两者并非对「要不要调剂」有分歧，而是对执行者能否被约束给出相反判断。这也解释了为什么后文《疾贪》《除狭》会自然衔接：制度争论最终落到吏治。

常见误读

其一，把「平准」「均输」当成同一种政策，实则一者侧重京师物价吞吐、一者侧重郡国贡输与物资调运，汉武帝时期的施行也分属不同环节。其二，把大夫的说法当作实际效果的记录——那是辩护词而非审计结论，书中并未提供物价数据。其三，忽略文学并非主张「完全不管」，其替代方案是恢复以民所工为税的轻简征收，重点是减少官府直接进入市场。

后世流变与阅读建议

经济史研究常把均输平准与桑弘羊的财政体系、武帝朝的战时经济连起来考察，也有研究指出其效果高度依赖吏治质量。读《本议》相关段落时，建议把「制度设计意图」「执行条件」「可能的失败模式」写成三栏；这三栏恰好对应大夫、文学与后世研究者各自的关注点，也是把这组争论读厚而非读扁的有效办法。

边费与匈奴：大夫全部论证的隐含前提

若把「备胡」抽掉，官营政策的财政论证就失去支点

边防

经文依据

《本议》大夫开篇即把政策系于边事：「匈奴背叛不臣，数为寇暴于边鄙，备之则劳中国之士，不备则侵盗不止」，于是「修障塞。饬烽燧，屯戍以备之。边用度不足，故兴盐、铁，设酒榷，置均输，蕃货长财，以佐助边费。」文学的反驳则试图拆除这一前提：「善克者不战，善战者不师，善师者不阵。修之于庙堂，而折冲还师。王者行仁政，无敌于天下，恶用费哉？」后五卷《备胡》《击之》《结和》《诛秦》《伐功》《西域》《世务》《和亲》《繇役》等篇，把这个前提重新摊开反复辩论。

逻辑结构

大夫的推理是一条成本链：外部威胁 → 常备边防 → 财政缺口 → 需开辟不依赖加赋的收入 → 官营与均输。文学的反驳不是在同一链条上砍价，而是换掉链条的第一环：若以德怀远、以仁义服人，则不必长期屯戍，财政缺口自然消解。因此《本议》的分歧表面是「盐铁该不该罢」，深层是「边境安全能不能靠德化替代军备」。这也是为什么后半部会花大量篇幅讨论和亲、和战、边功与徭役——会议记录者很清楚，不解决第一环，财政之争无解。文学一方的「善克者不战」并非纯粹的和平主义，而是汉代「修文德以来之」的一套标准论述；大夫则持续以「匈奴桀黠，擅恣入塞」的具体侵扰作经验反驳。

常见误读

其一，把大夫的论证简化成「为敛财找借口」，忽略其论据始终是可核查的边费负担。其二，把文学的主张读成「不要国防」，实际它主张以德政与均平降低冲突根源，属于另一套因果模型。其三，忽略会议的时代背景：武帝长期用兵之后，昭帝朝财政与民力确实吃紧，双方都在回应同一场现实压力，只是处方相反。

后世流变与阅读建议

后世读《盐铁论》常把这一组篇章与《汉书·食货志》《史记·平准书》对读，以补上制度与财政数据；现代讨论则多关注「国防开支如何塑造国内经济政策」这一问题。建议第一遍读时把《本议》大夫语与《备胡》《结和》并置，标出哪些论据是经验描述、哪些是价值预设；分完这一层，六十篇中最反复的争执会清楚很多。

义利与风俗：政策争论怎样被翻译成教化问题

「导民以德」与「示民以利」是文学反复使用的框架，也是全书最难被现代术语替换的一层

价值

经文依据

《本议》文学曰：「夫导民以德则民归厚；示民以利，则民俗薄。」同篇又有「散敦厚之朴，成贪鄙之化」「夫文繁则质衰，末盛则质亏」。《本议》文学引孔子「不患贫而患不均，不患寡而患不安」，并推衍出「天子不言多少，诸侯不言利害，大夫不言得丧」。在后半部，《散不足》以大量器物、饮食、丧葬的铺陈写「俗侈」，《取下》提出「古者，上取有量，自养有度……用民之力，不过岁三日，籍敛，不过十一」，《大论》则以「文王兴而民好善，幽、厉兴而民好暴，非性之殊，风俗使然也」收束为教化论。

逻辑结构

这一命题的核心不是「利不好」，而是上位者的行为具有示范效应：国家逐利，等于向全社会宣告逐利可取，风俗随之改变；风俗一变，制度成本上升、治理难度加大。于是经济政策被纳入「上行下效」的因果链，评价尺度从效率转为风俗厚薄。它与《取下》「上取有量」互为表里：既要限制国家的取，也要限制国家的示。大夫一方并非不谈德，而是把论域拉回「边费如何筹措」；《诏圣》「衣弊而革，法弊而更制」与《大论》「治民者，若大匠之斲」则给出另一套更重时势与工具的论证。

常见误读

其一，把「义利之辨」读成笼统的道德说教，忽略它由具体的制度批评（官营、均输、爵禄、奢用）触发，几乎每段都有明确所指。其二，把「风俗」当成纯修辞：在汉代的治理逻辑里，风俗是可观察、可归因的治理指标，与「水旱，天之所为」还是「政有德则阴阳调」的责任归属直接相连（见《水旱》）。其三，把双方读成「道德派／功利派」的固定阵营——大夫也引《易》《管子》与圣王之制，文学也谈仓廪与民力。

后世流变与阅读建议

后来的儒家政治论述反复援引「与民争利」「藏富于民」，近现代整理者则常以「重义轻利」概括文学一方，并给出不同评价。读这组建议做一件小事：把书中每处「德／义／利／俗／质／文」圈出，看它们在相邻段落里是否被换了含义。能看出概念滑动，才算读懂了这场辩论为何总在「同一句话」上打转。

06

德刑与法令繁简：后五卷的哲学核心

令以教民、法以督奸，还是法令愈密而奸伪愈生

法度

经文依据

《刑德》大夫立纲：「令者所以教民也，法者所以督奸也。令严而民慎，法设而奸禁。罔疏则兽失，法疏则罪漏。」文学的反论同样锋利：「道径众，人不知所由；法令众，民不知所辟。故王者之制法，昭乎如日月，故民不迷」，并举秦朝为例：「昔秦法繁于秋荼，而网密于凝脂。然而上下相遁，奸伪萌生。」《申韩》御史以「衣小缺……裂可以补」说明法度可补弊，《诏圣》提出「衣弊而革才，法弊而更制」「时世不同，轻重之务异也」；同篇文学以「民之仰法，犹鱼之仰水，水清则静，浊则扰」回应，把法的正当性系于政治清明。《后刑》《周秦》《大论》续论德教与刑罚的先后。

逻辑结构

双方的争点不在「要不要法」，而在法的有效条件。大夫一方认为人性趋利避害，法令明确而必行即可止奸，且法度须随世变更，不能等待圣王复出；「禁不必，怯夫侥幸」强调的是确定性。文学一方认为法令的可执行性有上限：条目愈多，民众愈不知避，官吏愈有解释空间，反而制造规避与勾结；故主张法要简明、更要「昭乎如日月」，并以德教减少法的负载。两者其实共享一个判断——法必须能被众人理解；分歧在于达成路径是「加密与必行」还是「简化与教化」。

常见误读

其一，把这一组读成「法家／儒家」的标签战。书中发言者常互换论据：御史也谈「待周公而为相，则世无列国」的务实，文学也并不主张废法。其二，把「秦法繁于秋荼」当成纯历史陈述，它首先是修辞性反例，用来质疑「法密→奸禁」的单调因果。其三，忽略《大论》「风俗使然也」与《刑德》的关系：文学把法的成效归因于风俗，等于把法律问题重新接回教化问题，全书因此首尾闭合。

后世流变与阅读建议

后世法制史与政治思想史常引《刑德》《诏圣》讨论「法密而奸生」与「法随时变」这对命题，也有研究将其置于昭帝朝「宽政」与武帝朝「严政」转向的背景中理解。建议把《刑德》《申韩》《诏圣》《大论》连读，并逐条标注「主张／依据／反例／隐含前提」，你会看到全书最抽象的一段，其实处处指向具体的吏治与徭役现实。

07

对话体与编撰立场：谁在替谁说话

《盐铁论》不是会议速记，也不是单声道宣言；分清三层声音才不会被带偏

文体

经文依据

《四库全书总目提要》对体例的判断很关键：「宽集其所论，为书凡六十篇，篇各标目，实则反复问答，诸篇皆首尾相属。」又指出桓宽「惟以盐、铁为名，盖惜其议不尽行也」，并说明「书末《杂论》一篇，述汝南朱子伯之言……于桑弘羊、车千秋深著微词，盖其著书之大旨」。《杂论》本身以「客曰」开篇：「余睹盐、铁之义，观乎公卿、文学、贤良之论，意指殊路，各有所出，或上仁义，或务权利」，末段更有「然蔽于云雾，终废而不行，悲夫」的感叹。正文则以「大夫曰」「文学曰」「贤良曰」「御史曰」「丞相曰」标记发言者。

逻辑结构

读这本书至少要分三层。第一层是会议中的发言：六十余位贤良文学与公卿的往复，是材料主体。第二层是桓宽的整理：篇名、段落安排、首尾承接、排比句式的整齐化，以及《杂论》的人物评骘，都带有编撰者痕迹；《四库提要》明说他「推衍、增广条目」，意味着并非逐字速记。第三层是后世解读：从《四库提要》「所论皆食货之事，而皆述先王，称六经」的归类，到现代整理者对桑弘羊的重新评价，每一代都在借这部书谈自己的问题。把三层混作一层，最常见的后果是把某段漂亮排比直接当作会议原话，或把作者的褒贬当成史实结论。

常见误读

其一，把「大夫」的话当全书立场，或反过来把「文学」的话当作者结论。实际上《杂论》的微词提示作者更同情贤良文学，但正文仍完整保留了对方的论据，这正是本书的史料价值所在。其二，把对话体读成「作者没有观点」——篇目安排与末篇评骘都在表态。其三，忽略发言者的切换：后半部「贤良」发言增多，「御史」「丞相史」与「大夫」常属同一阵营，读快了很容易张冠李戴。

后世流变与阅读建议

关于《盐铁论》究竟是会议实录还是文学重构，学界与网络讨论长期有分歧；郭沫若《盐铁论读本》与王利器《盐铁论校注》代表了两种不同的整理取向。建议初读时在页边只做一件事：每段开头标出发言者，并在《杂论》处回头核对自己的印象是否与作者的评骘一致。这个笨办法比记住任何结论都更能防止替古人选边站。

史实ANALYSIS 01

盐铁会议的时间线：前 81 年到底发生了什么，结果又如何

会议、政策调整、成书三件事相隔数十年，混为一谈会读出许多不存在的因果

网上介绍《盐铁论》的短文，常把「会议」「罢盐铁」「桓宽写书」压成一句话，于是产生两类常见错误：一是以为会议废除了盐铁官营，二是以为桓宽现场记录了辩论。把时间线拆开，问题就清楚了。

三个不同的时间点

第一，汉昭帝始元六年（前 81）：诏郡国举贤良、文学之士，「问民所疾苦」。这是《本议》开篇那句「有诏书使丞相、御史与所举贤良、文学语」所对应的事件。与会者据《杂论》有六十余人，公卿一方以御史大夫桑弘羊为主，丞相田千秋居中。第二，会议之后的政策调整：《四库提要》明确说「后罢榷酤，而盐、铁则如旧」——被废止的是酒类专卖，盐铁官营大体保留。这也是桓宽「惜其议不尽行」的缘由。第三，约宣帝时成书：桓宽字次公，汝南人，治《公羊春秋》，宣帝时被举为郎，官至庐江太守丞；他并未参与会议，而是据记录「推衍、增广条目」编成十卷六十篇。

为什么这条时间线重要

其一，它解释了本书的结构性落差：贤良文学在书中论辩气势极盛，现实政策却只让步了一部分；若以为「文学赢了」，就误读了《杂论》的怅惘。其二，它解释了文本层累：成书晚于会议数十年，整理者的语言、编排与评骘都可能进入正文，不宜把每一句当作现场速记。其三，它提醒我们把政策史与思想史分开评价：会议的实际成果有限，但它保存的论证结构，成为后世讨论国家干预、本末与义利时反复回到的文本。

如何自行复核

最直接的路径是查《盐铁论》首篇与末篇，再对照《四库全书总目提要》该条与《汉书·食货志》相关段落；三者都不长。若还想延伸，可比较《史记·平准书》对武帝朝财政制度的记述。本站「学习路径」第一阶段即要求做出这张时间线，正是为了避免在后续分析中把三层时间压平。

评价史ANALYSIS 02

桑弘羊是否被「妖魔化」：一部书的立场与后世的翻案

从《杂论》的微词到当代经济思想史的重估，评价变化往往映照的是提问者的时代

《盐铁论》里最强势的发言者是「大夫」，一般即指御史大夫桑弘羊。但全书末尾《杂论》却对他「深著微词」，并断言「公卿知任武可以辟地，而不知广德可以附远；知权利可以广用，而不知稼穑……」。这一褒一贬之间的张力，催生了后世持续不断的评价翻案。

几种主要立场

传统取向：《四库提要》把全书归入儒家，理由是「所论皆食货之事，而皆述先王，称《六经》」；同时又指出黄虞稷《千顷堂书目》把它改隶史部食货类是「循名而失其实」。这一脉络下，贤良文学的义利之辨被视为正论，桑弘羊多被看作兴利之臣。近代重估：20 世纪的整理与研究中，桑弘羊常被重新描述为有财政才干、支持国家统一与边防的改革家，文学一方则被批评为空谈德教、不谙实务；郭沫若《盐铁论读本》的取向常被归入这一类。当代讨论：经济思想史、财政史研究者更多回到制度条件本身，讨论战时财政、官营效率与吏治约束，不再急于给人物贴「进步／保守」标签；网络上的翻案文章则往往走得更远，把桑弘羊塑造成「古代宏观调控第一人」。

判别材料的三条线索

第一，看引用的是哪一段：只引《本议》大夫语，容易得出「务实」印象；只引《杂论》微词，容易得出「贪利」印象；两者并置才接近文本全貌。第二，看是否区分「政策辩护」与「政策效果」：大夫的论证是条件式的（若罢，则边费无着），书中并没有提供物价与民生数据来证明效果；把辩护词当成绩单，是翻案文章最常见的跳跃。第三，看时代问题：不同年代对「国家干预」的态度差异，会显著影响对桑弘羊的评价；读这类文章时把作者的现实关切一并读出，比争谁对谁错更有收获。

小结

与其在「贤臣／聚敛之臣」之间选边，不如把《盐铁论》当作一份保留了双方最强论据的材料。本站「核心理念」把每组争论都拆成「大夫怎么说／文学怎么说／共同前提是什么」，正是为了让读者先看清论证结构，再决定是否评价人物。

文体考辨ANALYSIS 03

会议实录还是文学重构：《盐铁论》的史料性质之争

「推衍、增广条目」六个字，决定了这本书该被怎样引用

《四库全书总目提要》说桓宽「集其所论，为书凡六十篇，篇各标目，实则反复问答，诸篇皆首尾相属」，另有材料明言他对原始议文作了「推衍、增广条目」。这两句话把一个问题摆到台面上：我们读到的，究竟是会议现场的记录，还是后人以记录为素材写成的政论？

支持「实录骨架」的证据

其一，全书有稳定的发言者标记（大夫、文学、贤良、御史、丞相史），且针锋相对、少有单方独白，符合诘难的现场形态。其二，议题推进有可追溯的话头：《本议》立纲领，后文《备胡》《结和》反复回到边费前提，《取下》《疾贪》又把制度批评落到吏治，篇与篇「首尾相属」。其三，大量具体到器物、地名、官名、制度的细节（见《散不足》的器物罗列），不像凭空拟构。其四，会议结果与书中主张并不一致（盐铁如旧），若纯为立场宣传，大可把结局写得更「正确」。

支持「文学加工」的证据

其一，作者晚于会议数十年且未与会，须依赖二手记录；「推衍、增广」本身就说明有扩写。其二，许多段落排比整饬、用典密集，双方都能随口引《诗》《书》《易》《论语》，更接近书面论辩的理想化形态。其三，《杂论》以「客曰」评议人物、表明作意，是明确的编撰者声音，不属于会议发言。其四，篇名整齐、六十篇之数带有编次意图。

折中的读法与实操建议

较稳妥的立场是：把它视为以会议记录为底本、经后代整理的对话体政论——论证结构与人物的基本主张可信，逐字归属则需谨慎。这对引用习惯有直接影响：写学术性文字时宜说「《盐铁论·本议》载文学曰……」，而不宜说「前 81 年某某在会上说……」；引用《杂论》的评价，则应标明这是桓宽的评骘。本站「名言警句」因此一律标到篇名，不标到「会议发言」，并在导读里把三层声音分开。

小结

这场争议不必有唯一结论，但必须被意识到。对话体文本最容易让人把「写得好」误当成「记得准」；知道有整理者这一层，读六十篇时才不会替古人补上他们没说过的话。

版本ANALYSIS 04

郭沫若《盐铁论读本》与王利器《盐铁论校注》：两条整理路线

一部为通读与评价，一部为校勘与考订，读之前先弄清自己需要哪一种

《盐铁论》文字古奥、对话切换频繁、异体与通假字多，现代读者几乎都要借助整理本。中文世界最常被提到的两种成果，恰好代表两条不同的整理路线：郭沫若的《盐铁论读本》与王利器的《盐铁论校注》。此外，20 世纪还有马非百等学者的相关研究，以及各类注译本（如以《诸子集成》本为底本的《盐铁论注译》）。

两条路线的差别

《盐铁论读本》侧重「让书可读」：分段、标点、语译与条理化，并带有整理者对这场辩论的评价取向。它适合第一次通读，尤其适合快速把握「谁主张什么」。但正因为带有鲜明的时代视角，若要做人物评价或思想史判断，不宜只据读本的按语下结论。《盐铁论校注》侧重「让字有据」：广校各本、汇集异文、考订名物制度，是引用原文、核查篇名与字句时的首选。它信息密度高，却不适合作为第一本通读书。

常见的混淆

其一，把注译本的白话译文当作原文引用；二者在「利」「本」「末」这类关键字上常有解释性偏移。其二，把整理者的分段与标题当成原书结构——《盐铁论》原本只有篇名，段落划分多出自后人之手。其三，忽略底本差异：明弘治涂祯刻本、张之象注十二卷本、《四部丛刊》影印本、清张敦仁考证本之间，字句与篇名偶有出入（如《国疾》或作《国病》、《论菑》或作《论灾》），不同整理本的取舍并不一致。

怎么选、怎么核

初读建议用带译文的注译本建立整体印象；要引用时，回到全文底本按篇名核对，再看校注本的异文说明。本站采用的是维基文库十卷全文所标六十篇，篇名与引文均由该全文核校，并在逐篇要点里提示常见异文；「延伸阅读与出处」同时给出全文、目录与版本考证链接，便于三步复核。

小结

整理本不是原书的替身，而是通往原书的一种读法。知道手上这一本解决什么问题，就能避免把「好读」误当「有据」，也避免把「有据」误当「易读」。

版本ANALYSIS 05

十卷六十篇的版本流变与篇名异文

从涂祯本到张敦仁考证本，篇名、卷数与字句差异从何而来

翻开不同版本的《盐铁论》，第一眼就可能遇到不一致：有的著录为十卷、有的为十二卷；同一篇名或作《繇役》或作《徭役》，或作《论菑》或作《论灾》；《国疾》亦有作《国病》者。这些差别不影响全书主干，却会影响检索与引用，值得单独交代。

版本链的大致轮廓

《四库全书总目提要》著录「《盐铁论》十二卷（内府藏本），汉桓宽撰」，同时说明「为书凡六十篇，篇各标目」——卷数与篇数是两个层面：六十篇是内容单位，十卷或十二卷是装订分卷方式，历代刊本的分卷并不固定。较常被提到的底本与校本包括：明弘治十四年涂祯刻本（《儒藏》精华编选刊即以此为底本）、《四部丛刊初编》所影印明正德嘉靖间刻本、明张之象注十二卷本、清卢文弨《群书拾补》本、清张敦仁考证本，以及《两京遗编》本、《汉魏丛书》本等；现代整理又参考《群书治要》《通典》《太平御览》所存异文。

异文从哪里来

通假与异体：繇／徭、菑／灾、疾／病一类，多为用字差异而非内容差异。传抄与刊刻：对话体切换频繁，「大夫曰」「文学曰」偶有脱漏，导致段落归属在不同整理本里不一致。避讳与后改：后世刊刻可能改字，需靠多本对校还原。整理者判断：如《盐铁论注译》一类注本会明确标注「国（病）〔疾〕」式的校改，这类方括号是整理者的取舍，不属于原文。

对读者的实际影响

第一，检索篇名时要用异文各试一次；本站「核心章节要点」按维基文库十卷全文的六十篇标目，并在相应条目中提示异写。第二，引用原文务必注明所据版本，尤其是涉及关键字句时；仅写「《盐铁论》曰」而白话转写，很容易在转引中失真。第三，读到「某本作某」的校语时，把它当作信息而非结论：校勘判断有强弱之分，宜回查底本影像或多本对校说明。

小结

版本知识看似琐碎，却是把《盐铁论》当作史料使用的前提。本站所有引文均标注到篇，篇目与字句以同一份全文为底本核校，正是为了让「可回溯」这件事不至于停在口号上。

名言警句

原文 · 释义 · 评析三层整理，引文据维基文库十卷全文核校

“
窃闻治人之道，防淫佚之原，广道德之端，抑末利而开仁义，毋示以利，然后教化可兴，而风俗可移也。

— 《盐铁论·本议第一》文学曰

释义听说治理百姓的要道，在于堵住放纵的源头、扩充道德的端绪、抑制末业之利而开启仁义，不向百姓展示利益，然后教化才能兴、风俗才能改。

评析全书第一篇的第一段立论，把经济政策直接放进教化框架。此后六十篇的许多争论，都是这句话与大夫边费论证的往复。

义利本末总纲
“
今郡国有盐、铁、酒榷，均输，与民争利。散敦厚之朴，成贪鄙之化。

— 《盐铁论·本议第一》文学曰

释义如今各郡国有盐铁官营、酒类专卖与均输，与百姓争夺利益，涣散了敦厚朴实之风，养成了贪鄙的习气。

评析「与民争利」四字是文学一方最有影响的指控，重点不只在财政，更在官府进入市场后的示范效应。

义利财政
“
愿罢盐、铁、酒榷、均输，所以进本退末，广利农业，便也。

— 《盐铁论·本议第一》文学曰

释义希望废止盐铁官营、酒榷与均输，以此推进本业、抑退末业、广利农业，方为便利。

评析文学的具体政策主张。注意会议实际结果是「罢榷酤而盐铁如旧」，主张并未全面实现，这也是《杂论》怅惘的由来。

本末政策
“
边用度不足，故兴盐、铁，设酒榷，置均输，蕃货长财，以佐助边费。

— 《盐铁论·本议第一》大夫曰

释义边防费用不足，所以兴办盐铁、设酒类专卖、置均输，增殖货物、增长财用，以补助边费。

评析大夫全部财政论证的支点。抽掉「备胡」这一前提，官营政策的理由便无从成立，后五卷也反复回到这一点。

边防财政
“
工不出，则农用乏；商不出，则宝货绝。农用乏，则谷不殖；宝货绝，则财用匮。

— 《盐铁论·本议第一》大夫曰

释义工匠不生产，农具就缺乏；商人不流通，货物就断绝；农具缺乏则粮食不增，货物断绝则财用枯竭。

评析大夫用分工与流通反驳「重农唯一论」，是全书最具「经济分析」味道的一段，前引《易》「通其变，使民不倦」。

本末流通
“
故盐、铁、均输，所以通委财而调缓急。罢之，不便也。

— 《盐铁论·本议第一》大夫曰

释义盐铁与均输，是用来流通积压物资、调剂缓急的，废止它并不便利。

评析把官营定义为调剂机制而非敛财工具，与文学「开利孔」的叙述构成同一制度的两种讲法。

均输财政
“
平准则民不失职，均输则民齐劳逸。故平准、均输，所以平万物而便百姓，非开利孔而为民罪梯者也。

— 《盐铁论·本议第一》大夫曰

释义平准使百姓不失业，均输使劳逸均齐；二者用来平抑物价、便利百姓，并非开启牟利之门、为百姓设下获罪的阶梯。

评析大夫在此预先引用并否定了对方的措辞，可见「开利孔」「为民罪梯」是当时已流行的批评。

均输平准
“
善克者不战，善战者不师，善师者不阵。修之于庙堂，而折冲还师。

— 《盐铁论·本议第一》文学曰

释义善于制胜的不必交战，善于用兵的不必兴师，善于治军的不必列阵；在朝廷上修明政教，就能使敌师退去。

评析文学用以拆除「边费不可免」的前提，属于汉代「修文德以来之」的标准论述，另一套因果模型而非单纯和平主义。

边防德治
“
有国有家者，不患贫而患不均，不患寡而患不安。

— 《盐铁论·本议第一》引孔子语（本出《论语·季氏》）

释义诸侯大夫不必担忧财富少，而该担忧分配不均；不必担忧人口少，而该担忧不安定。

评析文学援引经典把财政争论转向分配与安定。引用时应注明这是《本议》所引《论语》，而非《盐铁论》原创。

义利经典引用
“
民人藏于家，诸侯藏于国，天子藏于海内……是以王者不畜聚，下藏于民，远浮利，务民之义。

— 《盐铁论·本议第一》文学曰

释义百姓把财富藏在家中，诸侯藏于封国，天子藏于四海之内；所以君王不私自积聚，而让财富留在民间，远离浮利，致力于百姓的道义。

评析「藏富于民」的经典表述之一。与大夫「蕃货长财」并读，可见双方对「国富」与「民富」关系的假设完全不同。

义利财政
“
富在术数，不在劳身；利在势居，不在力耕也。

— 《盐铁论·通有第三》大夫曰

释义致富在于经营之术，不在于体力劳作；获利在于所处区位，不在于努力耕作。

评析全书最经常被经济思想史引用的句子之一，强调流通、区位与经营的作用；网络上常被截去上下文，读时宜回到《通有》全篇。

本末流通
“
贤圣治家非一宝，富国非一道。

— 《盐铁论·通有第三》大夫曰

释义贤圣治家不靠一件宝物，使国家富足也不止一条路。

评析针对「务本即足」的方法论反驳，可视为大夫一方最简洁的纲领；下文即举管仲以权谲称霸为例。

本末方法论
“
故物丰者民衍，宅近市者家富。

— 《盐铁论·通有第三》大夫曰

释义物产丰饶的地方人口繁衍，住宅靠近市场的家庭容易富足。

评析以区位与集聚解释贫富，与「利在势居」同属一组；注意它是论辩中的举证，不是统计结论。

流通贫富
“
利不从天来，不从地出，一取之民间，谓之百倍，此计之失者也。

— 《盐铁论·非鞅第七》文学曰

释义利益不会从天上掉下、从地里长出，终究取自民间；却称之为百倍之利，这是算计上的失误。

评析文学最锋利的一句财政常识，点破「官营不增赋」的说法：收入只是换了征收通道。与《取下》「上取有量」呼应。

财政义利
“
国有贤士而不用，非士之过，有国者之耻。

— 《盐铁论·国疾第二十八》文学曰

释义国家有贤才却不能任用，不是贤士的过失，而是掌国者的耻辱。

评析《国疾》把批评从政策转向在位者，「私家累万金」与「百姓贫陋困穷」的对照是本篇最尖锐处。

吏治贤良文学
“
不患择之不熟，而患求之与得异也；不患其不足也，患其贪而无厌也。

— 《盐铁论·疾贪第三十三》大夫曰

释义不担心选拔不够审慎，而担心所求与所得不一致；不担心俸禄不足，而担心贪欲没有止境。

评析《疾贪》由大夫先承认吏治之弊，贤良随即指出小吏禄薄、上府下求层层相迫，把腐败归因于制度条件。

吏治制度
“
古者，上取有量，自养有度……用民之力，不过岁三日；籍敛，不过十一。

— 《盐铁论·取下第四十一》贤良曰

释义古时在上者取用有定量、自奉有节度，征用民力一年不超过三天，赋敛不超过十分之一。

评析文学／贤良一方少见的量化主张，可作为「上取有量」的具体标尺；也是与《本议》「不畜聚」相连的制度落点。

赋敛民生
“
水旱，天之所为；饥穰，阴阳之运也，非人力。

— 《盐铁论·水旱第三十六》大夫曰

释义水旱是天时所致，丰歉是阴阳运行的结果，非人力所能左右。

评析大夫把灾害归为天时以卸去政策责任，贤良则以「政有德则阴阳调」相责；这一组是理解汉代天人感应框架的好材料。

天人责任
“
令者所以教民也，法者所以督奸也。令严而民慎，法设而奸禁。

— 《盐铁论·刑德第五十五》大夫曰

释义政令用来教导百姓，法度用来督察奸邪；政令严明则百姓谨慎，法度设立则奸邪止息。

评析大夫一方的法治提纲，重点在「必行」的确定性；同篇下文「罔疏则兽失，法疏则罪漏」是同一逻辑。

德刑法度
“
道径众，人不知所由；法令众，民不知所辟。

— 《盐铁论·刑德第五十五》文学曰

释义道路太多，人不知该走哪条；法令太多，百姓不知该回避什么。

评析与上一句构成全书法度之争的核心对偶：分歧不在要不要法，而在法的有效条件是「加密必行」还是「简明可晓」。

德刑法度
“
昔秦法繁于秋荼，而网密于凝脂。然而上下相遁，奸伪萌生。

— 《盐铁论·刑德第五十五》文学曰

释义从前秦朝法令比秋日茅草还繁密，法网比凝固的油脂还细密，然而上下互相规避，奸伪反而滋生。

评析以秦为反例质疑「法密→奸禁」的单调因果。这是修辞性史例，引用时不宜当作法制史的数据性结论。

德刑历史例证
“
民之仰法，犹鱼之仰水，水清则静，浊则扰。

— 《盐铁论·诏圣第五十八》文学曰

释义百姓依赖法度，如同鱼依赖水；水清则安静，水浊则惊扰不安。

评析把法的正当性系于政治清明，而非条文数量。与《大论》「风俗使然也」共同把法度问题接回教化问题。

德刑民生
“
文王兴而民好善，幽、厉兴而民好暴，非性之殊，风俗使然也。

— 《盐铁论·大论第五十九》文学曰

释义文王兴起则百姓向善，幽王、厉王在位则百姓凶暴，并非本性不同，而是风俗造成的。

评析全书教化论最凝练的收束句，也解释了文学为何始终把制度问题追溯到上位者的示范。

德治风俗
“
公卿知任武可以辟地，而不知广德可以附远；知权利可以广用，而不知稼穑……

— 《盐铁论·杂论第六十》客曰

释义公卿知道用武可以开拓疆土，却不知道广施德政可以使远方归附；知道权与利可以扩充用度，却不知道农事才是根本。

评析末篇的评骘，被《四库提要》视为「著书之大旨」所在。这是桓宽的声音，不是会议发言，引用时须标明层次。

十卷 60 篇逐篇精读：要旨、双方论点、关键原文与研读提示

卷一至卷五

28 篇

本议开宗明义，围绕罢不罢盐铁、本末轻重、义利之辨与儒法评价反复诘难；篇目多短兵相接。

卷一至卷五-01 本议第一全书总纲：文学请罢盐铁酒榷均输，大夫以边费与通有无相驳，双方在义利、本末与边防上立定立场。 ＋
要点拆解
  • 文学以「与民争利」「进本退末」立论，把政策问题转为风俗问题。
  • 大夫以「边用度不足」为支点，提出官营是筹措边费的替代手段。
关键原文
愿罢盐、铁、酒榷、均输，所以进本退末，广利农业，便也。
研读提示

必精读的一篇。把双方论证链逐环抄出，后续五十九篇多是这条链的展开与回返。

总纲本末边防
卷一至卷五-02 力耕第二围绕「力耕」与「术数」的致富之辩，大夫强调流通与经营，文学强调农桑为本。 ＋
要点拆解
  • 大夫以「富在术数，不在劳身」质疑耕作唯一论。
  • 文学以俭力趋时、务本积谷相对，并警惕示民以利。
研读提示

与《通有》连读，可见大夫的财富理论并非零散感想，而是成套的分工—流通说。

本末流通
卷一至卷五-03 通有第三以各地物产与「通有无之用」为据，讨论工商是否足以富国，兼及奢俭与地域差异。 ＋
要点拆解
  • 大夫提出「开本末之途，通有无之用」，引《易》「通其变」。
  • 文学列举荆扬、蜀汉等地物产，反驳「近市者富」的推论。
关键原文
贤圣治家非一宝，富国非一道。
研读提示

「富在术数，不在劳身；利在势居，不在力耕」即出本篇，常被经济思想史引用。

本末地域流通
卷一至卷五-04 错币第四论货币铸行权与币制变更：大夫主张国家统一铸币以禁奸伪，文学追述古者以物易物。 ＋
要点拆解
  • 币制统一被大夫视为防止私铸与奸钱的条件。
  • 文学以「币数变而民滋伪」质疑频繁改动制度的效果。
研读提示

读时可对照《史记·平准书》所记武帝朝币制，理解双方各有所指。

货币制度
卷一至卷五-05 禁耕第五就山泽之利与铁器专营对辩，文学指其妨害农时与民生，大夫强调统一供给与边备。 ＋
要点拆解
  • 文学以「山海之利」归公导致器用不便、价格不齐为论。
  • 大夫把官营铁器与军备、农具供给的稳定相连。
研读提示

与《园池》《取下》同属资源归属问题的一组，宜合读。

山泽官营
卷一至卷五-06 复古第六借「复古」之名论制度是否应回归旧制，大夫以时势不同反驳，文学以先王之制相责。 ＋
要点拆解
  • 双方共享「法古」这一话语资源，却给出相反结论。
  • 大夫强调「时世不同，轻重之务异」，为后文《诏圣》张本。
研读提示

注意「复古」在此是论辩策略而非明确纲领，别把篇名当成主张。

复古时势
卷一至卷五-07 非鞅第七围绕商鞅变法的评价交锋，大夫称其国富民强、有益于国，文学称其后礼让、先贪鄙。 ＋
要点拆解
  • 大夫以「不赋百姓而师以赡」为官营辩护，把商鞅与桑弘羊连成一线。
  • 文学以「利不从天来，一取之民间」拆解「百倍之利」。
关键原文
利不从天来，不从地出，一取之民间，谓之百倍，此计之失者也。
研读提示

人物评价在本书中往往是政策论据的延伸；读时先找出「评古人」服务于哪条现实主张。

商鞅财政
卷一至卷五-08 晁错第八评晁错削藩与边策的是非，双方借历史人物争论「法度」与「权变」的边界。 ＋
要点拆解
  • 大夫以晁错之忠而罹祸说明制度变革之难。
  • 文学把责任归于用刑与趋利之政，而非个人。
研读提示

史料信息密度高但论辩性强，引用人物事迹前宜另核《史》《汉》。

晁错人物评价
卷一至卷五-09 刺权第九讥刺权贵恃势牟利、奢僭逾制，把官营之弊具体化为权势与财富的结合。 ＋
要点拆解
  • 文学描写权家「擅山泽」「困桡公利」的具体形态。
  • 与《疾贪》《散不足》构成对社会不平等的连续观察。
研读提示

本篇是理解「与民争利」并非抽象道德指控的重要文本。

权贵吏治
卷一至卷五-10 刺复第十讥刺被举荐者名实不符，讨论选官与「贤良文学」自身的资格问题。 ＋
要点拆解
  • 大夫一方反击儒生「不任事而论国事」。
  • 双方围绕「名」与「实」互相诘难，语气较前数篇更峻。
研读提示

从本篇起，争论开始反身指向发言者自身，读时注意攻守易位。

选官名实
卷一至卷五-11 论儒第十一御史讥孔子周游而「当世不为治」，文学以「无势位，虽舜禹不能治万民」回应儒者效用之问。 ＋
要点拆解
  • 御史举齐稷下千余人不能救齐为例，质疑儒术实效。
  • 文学把成效系于是否得位，将责任转回制度条件。
关键原文
无势位，虽舜、禹不能治万民。
研读提示

全书儒法评价最集中处；双方其实都在论「效用」，只是对生效条件的判断不同。

儒者效用
卷一至卷五-12 忧边第十二回到边防负担，文学忧内地民力耗竭，大夫强调边患不可松备。 ＋
要点拆解
  • 把《本议》的边费前提重新摊开。
  • 为后五卷《备胡》《击之》《结和》埋下话头。
研读提示

与《本议》大夫语并读，可看出全书论证的回环结构。

边防民力
卷一至卷五-13 园池第十三论皇家园池与山泽归属，文学主张还利于民，大夫强调国家统筹以补财用。 ＋
要点拆解
  • 资源归属的争论从盐铁扩展到土地与苑囿。
  • 与《取下》「擅山泽」的指责相对成组。
研读提示

制度史角度常被引用，注意区分「描述」与「主张」。

山泽园池
卷一至卷五-14 轻重第十四以「轻重之术」论国家调控物价与物资，大夫主张「天下之下我高，天下之轻我重」。 ＋
要点拆解
  • 把均输平准提升为一般性的调控原理。
  • 文学质疑官府定价必然带来侵渔与折算之弊。
研读提示

与《管子·轻重》诸篇关系密切，是经济思想史的重点篇目。

轻重调控
卷一至卷五-15 未通第十五论赋税与民力是否相称，文学以「未通」讥政策未达民情，大夫以边费与赈贷作答。 ＋
要点拆解
  • 把宏观财政落回农户负担。
  • 双方对「民有余」还是「国不足」给出相反判断。
研读提示

与《取下》《授时》同属民生一组，可连读成一条线。

赋税民生
卷一至卷五-16 地广第十六论开疆拓土与内地民生孰先，大夫重边功，文学以「地广而民贫」相责。 ＋
要点拆解
  • 疆域扩张的成本第一次被系统质疑。
  • 与《忧边》《备胡》《诛秦》构成边防议题链。
研读提示

注意此处「广地」与《本议》「边用度不足」是同一笔账的两面。

疆域边防
卷一至卷五-17 贫富第十七论贫富之由：大夫偏重才智、区位与经营，文学偏重权势兼并和风俗。 ＋
要点拆解
  • 承接《通有》「富在术数」的思路。
  • 文学把「私家累万金」与百姓困穷并列，指向分配。
研读提示

与《国疾》《刺权》连读，可见文学对不平等的解释相当一贯。

贫富分配
卷一至卷五-18 毁学第十八互讥对方所学无实，围绕儒生是否「不耕而食」与大夫是否「不学而仕」往复。 ＋
要点拆解
  • 论辩从制度转向学风与人格。
  • 常见的人身指摘与反讥，语气最激烈的一篇之一。
研读提示

读时留意这是论辩修辞，不宜当作学派史料直接采信。

学风论辩
卷一至卷五-19 褒贤第十九列举并褒扬贤者，讨论「贤」的标准与出处进退，隐含对当世用人之讥。 ＋
要点拆解
  • 与《毁学》成对，一贬一褒。
  • 借古人立标准，服务于本书对在位者的批评。
研读提示

与《讼贤》《遵道》同组，可观察作者如何安排褒贬节奏。

贤良用人
卷一至卷五-20 相刺第二十双方相互讥刺言与行、名与实，兼论「儒者难与言治」与「公卿不知民隐」。 ＋
要点拆解
  • 论辩进入互相拆台的阶段，议题密度下降而修辞增强。
  • 仍可见文学对「在位者之耻」的一贯线索。
研读提示

若初读吃力，可先跳至《国疾》，再回来补这一组。

论辩名实
卷一至卷五-21 殊路第二十一论同门异路、取舍不同，借人物际遇讨论仕进与守道的分歧。 ＋
要点拆解
  • 以「殊路」概括价值选择的多元。
  • 为后文《论诽》《孝养》铺路。
研读提示

篇名提示本篇重在「路径分殊」，不必强求单一政策结论。

仕进价值
卷一至卷五-22 讼贤第二十二为贤者辩诬，继续围绕「贤而不用」与「举非其人」往复诘难。 ＋
要点拆解
  • 与《国疾》「国有贤士而不用」呼应。
  • 把选官问题与政策得失连在一起。
研读提示

《四库提要》称诸篇首尾相属，本篇与前后数篇正是例证。

贤良选官
卷一至卷五-23 遵道第二十三论是否应恪守先王之道，文学主「遵道」，大夫主「随时」，与《复古》遥相呼应。 ＋
要点拆解
  • 「道」与「时」的关系被明确提出。
  • 为《诏圣》「法弊而更制」预作铺垫。
研读提示

把本篇与《复古》《诏圣》三篇并读，能看清全书的变化论线索。

复古时势
卷一至卷五-24 论诽第二十四论批评朝政是否构成诽谤，涉及言路、士人责任与「讪上」之辨。 ＋
要点拆解
  • 把前数篇的人身攻讦提升到言论正当性层面。
  • 文学为「讥刺」辩护，大夫强调分际。
研读提示

议题接近言论尺度，读时留意汉代的语境与现代概念不宜直接对应。

言路论辩
卷一至卷五-25 孝养第二十五论孝养重在「敬」还是「养」，顺势把奢俭与礼制之争引入家庭伦理。 ＋
要点拆解
  • 以「养口体」与「养志」之别讥刺时俗重物质。
  • 与《散不足》的器物铺陈构成一组。
研读提示

伦理议题在本书中同样服务于奢俭与风俗的论证，不是闲笔。

孝养奢俭
卷一至卷五-26 刺议第二十六讥刺议事者不达事理，讨论「坐而言」与「起而行」的张力。 ＋
要点拆解
  • 公卿一方反击文学「不任事而论国事」。
  • 与《论儒》《相刺》同一话头。
研读提示

读时把「谁能发言」与「谁该负责」两个问题分开，条理会清楚许多。

论辩名实
卷一至卷五-27 利议第二十七聚焦「言利」本身是否正当，把义利之辨从政策层面推到言论层面。 ＋
要点拆解
  • 文学坚持「天子不言多少」，大夫强调国用不可不计。
  • 为《国疾》对在位者的总批评蓄势。
研读提示

与《本议》「毋示以利」对照，可见同一命题在卷一与卷五的不同用法。

义利言论
卷一至卷五-28 国疾第二十八文学总斥「国之疾」在贤士不用、在位者富而百姓困，是前五卷批判性的收束。 ＋
要点拆解
  • 「私家累万金」与「百姓贫陋困穷」的对照最尖锐。
  • 把政策批评明确转为对执政者的责任追问。
关键原文
国有贤士而不用，非士之过，有国者之耻。
研读提示

卷五终篇，情绪与立论强度达到前半部高点；宜与《杂论》对读。

吏治总纲

卷六至卷十

32 篇

由经济政策扩展到奢俭、吏治、边防、和战、刑法与德治，末尾《杂论》交代人物与作书大旨。

卷六至卷十-29 散不足第二十九以大量器物、饮食、车马、丧葬的今昔对照写「俗侈」，是后五卷社会生活史材料最密集的一篇。 ＋
要点拆解
  • 贤良以「古者」与「今者」逐项对照，铺陈三十余类器用之奢。
  • 把财政问题转写为「散不足」：用度无节，积蓄必亏。
研读提示

常被社会经济史论文引用；读时宜做器物分类表，不宜只当文学铺陈。

奢俭社会生活史
卷六至卷十-30 救匮第三十承《散不足》论如何补救财用匮乏，贤良主节用、省事、均劳，公卿一方强调制度调度。 ＋
要点拆解
  • 与《取下》「上取有量」互为表里。
  • 奢俭之争在此正式转化为财政建议。
研读提示

与《散不足》连读，可见「列举现象—给出处方」的典型编排。

奢俭财政
卷六至卷十-31 箴石第三十一以针石喻直言规谏，讨论「箴」是否有助于治病（治国），兼及言路与听纳。 ＋
要点拆解
  • 延续《论诽》《利议》关于批评正当性的话头。
  • 贤良以医喻政，把谏议视为诊断而非冒犯。
研读提示

比喻性篇名，读时先还原喻体所指，再进入论证。

言路讽谏
卷六至卷十-32 除狭第三十二论仕途狭隘、官吏升迁壅滞，贤良把吏治之弊归因于选任制度。 ＋
要点拆解
  • 与《疾贪》《除狭》构成吏治三连。
  • 从「人不好」转向「路不通」，是分析中很重要的一步。
研读提示

读时留意「除狭」是主张而非描述，勿把篇名当现状记录。

吏治选官
卷六至卷十-33 疾贪第三十三双方共斥贪吏，却给出不同病因：大夫侧重贪欲无厌，贤良侧重禄薄与层层诛求。 ＋
要点拆解
  • 大夫先承认「为吏既多不良矣，又侵渔百姓」。
  • 贤良细述小吏禄薄、上府下求、乡里无所取的结构性压力。
关键原文
不患择之不熟，而患求之与得异也；不患其不足也，患其贪而无厌也。
研读提示

全书最值得反复读的吏治文本：分歧不在「是否反贪」，而在「归因于个人还是制度」。

吏治制度
卷六至卷十-34 后刑第三十四论刑罚应置于教化之后还是先行，文学主张先德后刑，大夫强调禁奸不可缓。 ＋
要点拆解
  • 与《刑德》《申韩》《大论》同属德刑组。
  • 「后刑」篇名本身即是文学一方的立场提示。
研读提示

建议把本篇与《刑德》并读，看法度之争如何从原则走向条文。

德刑法度
卷六至卷十-35 授时第三十五论农时与政令节律，贤良主张不夺民时，大夫强调赈贷与调度的时效。 ＋
要点拆解
  • 把《未通》的民力问题落到季节与征发安排。
  • 「授时」体现汉代政令顺时的传统框架。
研读提示

与《水旱》对读，可见「天时」在双方论证中被分别如何使用。

农时民生
卷六至卷十-36 水旱第三十六大夫归灾于阴阳天时，贤良归之于政德，围绕灾害责任展开天人感应框架内的争论。 ＋
要点拆解
  • 大夫称「六岁一饥，十二岁一荒」，把灾害从政策责任中摘出。
  • 贤良以「政有德则阴阳调」把责任重新接回治理。
关键原文
水旱，天之所为；饥穰，阴阳之运也，非人力。
研读提示

理解汉代天人框架的好材料；双方共享同一套语汇，结论却完全相反。

天人责任
卷六至卷十-37 崇礼第三十七论礼制与接待外宾的规格，把奢俭与邦交、名分连在一起讨论。 ＋
要点拆解
  • 由内政转向朝聘礼制。
  • 为后续《备胡》《和亲》等边防篇章过度。
研读提示

议题转换的枢纽篇之一，注意全书从「财用」向「礼与外事」的滑移。

礼制邦交
卷六至卷十-38 备胡第三十八重回匈奴边患，大夫以屯戍之费辩护官营，文学以德怀远、省民力相责。 ＋
要点拆解
  • 《本议》「边用度不足」的完整重演。
  • 双方对「备」的成本与替代方案各有说法。
研读提示

与《本议》《忧边》三篇并置，可看清全书论证的回环。

边防匈奴
卷六至卷十-39 执务第三十九论为政当务本实、去虚文，贤良讥公卿多言而少实，大夫反问具体可行之策。 ＋
要点拆解
  • 「务」与「文」的对举延续《本议》「文繁则质衰」。
  • 把论辩再次拉回「谁能负责」。
研读提示

与《能言》相邻，两篇宜连读以见「言」与「行」的反复诘难。

务实论辩
卷六至卷十-40 能言第四十讥「能言而不能行」，双方互相指摘空谈，是后五卷论辩修辞的高点之一。 ＋
要点拆解
  • 与《执务》构成一组反身批评。
  • 仍可见大夫重事功、文学重立场的差异。
研读提示

读时勿把讥刺语当作人物评定的可靠依据。

言行论辩
卷六至卷十-41 取下第四十一论在上者取民之限度，贤良提出「用民之力不过岁三日，籍敛不过十一」。 ＋
要点拆解
  • 大夫责文学「专欲损上徇下」，贤良以「上取有量」回应。
  • 全书少见的量化财政主张。
关键原文
古者，上取有量，自养有度……用民之力，不过岁三日；籍敛，不过十一。
研读提示

与《非鞅》「利一取之民间」并读，可拼出文学一方较完整的财政观。

赋敛民生
卷六至卷十-42 击之第四十二论是否继续对匈奴用兵，主战与主和的论证首次成组交锋。 ＋
要点拆解
  • 「击之」与《结和》《和亲》构成和战三部曲。
  • 边功评价与民力负担被并列计算。
研读提示

与《本议》大夫的边费前提合读，能看出政策与军事如何互相锁定。

和战边防
卷六至卷十-43 结和第四十三论与匈奴结和之利，文学强调休息民力，大夫质疑和约的可持续性。 ＋
要点拆解
  • 把「和」当作可计算的财政与民生方案。
  • 双方都承认边患未消，分歧在应对方式。
研读提示

注意「和」在汉代语境中与后世条约概念不同，不宜直接比附。

和亲边防
卷六至卷十-44 诛秦第四十四评秦之亡，把「任力」与「任德」的教训用于当前的边防与法度之争。 ＋
要点拆解
  • 以秦为反例是双方共用的论证资源。
  • 与《刑德》「秦法繁于秋荼」相互发明。
研读提示

历史例证在本书中多为修辞性服务，引用前宜另核基本史实。

历史例证德刑
卷六至卷十-45 伐功第四十五论边功如何评价，大夫称拓地之绩，文学质疑功成而民疲、赏罚失当。 ＋
要点拆解
  • 把军事成果与财政成本放在同一张账上。
  • 与《论功》《地广》同组。
研读提示

议题与《击之》《结和》相接，宜按卷八顺序连读。

边功边防
卷六至卷十-46 西域第四十六论经营西域的得失，涉及远略、贡赐与转运成本。 ＋
要点拆解
  • 地理视野由北边扩展至西北。
  • 与《地广》《伐功》共同构成「疆域成本」议题。
研读提示

可与《汉书·西域传》对读，补足本书未展开的制度背景。

西域疆域
卷六至卷十-47 世务第四十七论当世急务究竟在边备、财用还是教化，双方各自重排优先次序。 ＋
要点拆解
  • 把前数篇的分歧收束为「何者为先」的元问题。
  • 与《本议》的首段纲领遥相呼应。
研读提示

读时把双方各自列出的「优先序」抄成两行，差异一目了然。

治国路线总纲
卷六至卷十-48 和亲第四十八专论和亲之策，文学以德怀远、省费安民为说，大夫以夷狄无常为虑。 ＋
要点拆解
  • 「善克者不战」的命题在此被重新调用。
  • 与《结和》《击之》构成完整和战序列。
研读提示

注意把「和亲」的具体制度与一般性的「主和」区分开。

和亲边防
卷六至卷十-49 繇役第四十九论徭役负担的轻重与均平，贤良把边费成本落回编户齐民的日常。 ＋
要点拆解
  • 「繇役」或作「徭役」，属常见篇名异文。
  • 与《取下》「用民之力不过岁三日」直接相应。
研读提示

检索时记得同时试「徭役」，否则容易漏检。

徭役民生
卷六至卷十-50 险固第五十论山川险固与人为守备孰足恃，大夫重形胜，文学以「在德不在险」相驳。 ＋
要点拆解
  • 把边防争论从费用推进到「依靠什么」。
  • 与《论勇》相接，构成对「力」的连续质疑。
研读提示

「在德不在险」是先秦以来的常典，注意双方都在引用共享资源。

险固德治
卷六至卷十-51 论勇第五十一论勇力与谋略、个人武勇与国家之守，文学继续消解「任力」的正当性。 ＋
要点拆解
  • 与《险固》《论功》同属对边功价值体系的拆解。
  • 为《论菑》《刑德》等篇转向德刑预作过渡。
研读提示

篇名简短但论域宽，读时抓「勇」的定义之争即可。

德力边防
卷六至卷十-52 论功第五十二论何者可谓之功，质疑以拓地、斩获计功而忽略民力与风俗。 ＋
要点拆解
  • 与《伐功》相接，评价标准之争更明确。
  • 隐约回应《杂论》对「任武可以辟地」的批评。
研读提示

读完本篇再回看《杂论》，作者的评价立场会更容易辨认。

边功评价
卷六至卷十-53 论邹第五十三评邹衍一派大九州、阴阳终始之说，涉及天人框架与方术化论述的边界。 ＋
要点拆解
  • 把《水旱》中的阴阳语汇推到更极端的形态。
  • 双方在此对「非常之论」的态度有微妙差别。
研读提示

思想史材料价值高，但与其他篇的论辩主线关联较弱，可后读。

阴阳思想史
卷六至卷十-54 论菑第五十四论灾异与政事的关系，延续天人感应框架，篇名亦常作《论灾》。 ＋
要点拆解
  • 「菑／灾」为常见异文，检索需两试。
  • 与《水旱》共同构成灾害责任之争。
  • 为转向《刑德》的法度议题作结。
研读提示

卷九末篇，宜与卷十《刑德》连读，观察议题如何从天时转到法度。

灾异天人
卷六至卷十-55 刑德第五十五全书德刑之争的核心：大夫主「令以教民、法以督奸」，文学主法贵简明、法密反生奸。 ＋
要点拆解
  • 大夫以「罔疏则兽失，法疏则罪漏」强调必行。
  • 文学以「法令众，民不知所辟」与秦法之密相驳。
关键原文
昔秦法繁于秋荼，而网密于凝脂。然而上下相遁，奸伪萌生。
研读提示

与《后刑》《申韩》《诏圣》《大论》连读，构成全书哲学浓度最高的一组。

德刑法度
卷六至卷十-56 申韩第五十六评申不害、商鞅与法术之治，御史主「弊则补之」，文学主张任贤、返本。 ＋
要点拆解
  • 「衣小缺……可以补」的补弊论，是大夫一方变化论的具体化。
  • 与《非鞅》的商鞅评价前后呼应。
研读提示

注意「申韩」在此是论辩标签，不等于对法家的完整学术评述。

法度人物评价
卷六至卷十-57 周秦第五十七以周、秦对比论德教与刑政的成效，把历史周期引入制度评价。 ＋
要点拆解
  • 周秦之辨是汉代政论的常见框架。
  • 与《诛秦》《大论》共用同一组历史例证。
研读提示

注意区分「借史立论」与「史事陈述」，引用前宜另行核对。

历史例证德刑
卷六至卷十-58 诏圣第五十八论法度是否应随世更制，御史主「法弊而更制」，文学以「民之仰法，犹鱼之仰水」相责。 ＋
要点拆解
  • 「时世不同，轻重之务异也」是大夫一方最明确的变化论表述。
  • 文学把法的效力系于政治清明，而非条文增减。
关键原文
民之仰法，犹鱼之仰水，水清则静，浊则扰。
研读提示

与《复古》《遵道》遥相呼应，是全书「常与变」线索的收束处。

法度时势
卷六至卷十-59 大论第五十九接近全书总结：大夫讥文学「诵死人之语」，文学以「风俗使然」重申教化为本。 ＋
要点拆解
  • 大夫以「治民者，若大匠之斲」强调工具与时务。
  • 文学以「文王兴而民好善……非性之殊，风俗使然也」收束德治论。
关键原文
文王兴而民好善，幽、厉兴而民好暴，非性之殊，风俗使然也。
研读提示

正文论辩的最后一篇；紧接《杂论》转入编撰者声音，两篇务必连读。

德治总纲
卷六至卷十-60 杂论第六十桓宽借「客曰」追述与会六十余人、评议公卿与贤良文学，并交代「惜其议不尽行」的作书大旨。 ＋
要点拆解
  • 明确点出贤良茂陵唐生、文学鲁国万生等人物与「六十余人」的规模。
  • 对桑弘羊、车千秋「深著微词」，被《四库提要》视为作者倾向所在。
关键原文
公卿知任武可以辟地，而不知广德可以附远；知权利可以广用，而不知稼穑……
研读提示

这不是会议发言，而是整理者的后序。分清这一层，才不会把作者的褒贬当成史实结论。
