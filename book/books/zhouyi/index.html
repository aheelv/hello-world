01

导读 · 全书概览

从卦爻辞到十翼，一部关于变化结构的书如何成形，又该怎样分层去读

一、成书与版本

《易经》通行的面貌是「经」与「传」两层合编。「经」指六十四卦的卦辞与三百八十四爻的爻辞，卦爻辞多用简短的占断之语与取象之辞，其素材大约成形于西周早中期，作者已不可考；旧说有「人更三圣、世历三古」的讲法，把画卦、系辞、作传分别归于伏羲、文王、孔子，这是后起的追溯，不宜当作成书实录。「传」即《易传》，又称十翼，约在战国至汉初由儒家学者陆续整理成篇，用以解释卦爻辞，并把占筮之辞提升为一套论变化、时位与德性的论述。汉以后经传逐渐合编，魏王弼注本以义理为本、撇开汉易繁琐的象数，成为后世通行本的重要底本；宋程颐、朱熹又各立解释路数。本站以经传合本为阅读对象，但处处提醒读者分清「古经怎么说」「十翼怎么解」「注家怎么讲」「今人怎么看」四层，不把后来的哲学直接当成卦爻辞的原意。

二、结构与分部

通行本六十四卦依王弼本卦序编排，分上经三十卦、下经三十四卦两部分。上经自乾、坤起，至坎、离止，多取天地万物之象，偏重宇宙与根本秩序；下经自咸、恒起，至既济、未济止，多取人事、家国与变动之象。每卦六爻，爻位自下而上称初、二、三、四、五、上，阳爻称九、阴爻称六，于是有「初九」「六二」「上六」这类爻题。六十四卦共三百八十四爻，卦有卦辞、爻有爻辞，合为古经正文。第三部分「易传十翼」不另立卦目，而是十篇解经文字：彖上传、彖下传、象上传、象下传、文言传、系辞上传、系辞下传、说卦传、序卦传、杂卦传。彖、象、系辞各分上下，故七类而十篇，「十翼」之名即由此而来。彖释卦辞、象释卦爻之象与人事取法、文言专申乾坤、系辞通论大义、说卦列八卦取象与方位、序卦说明六十四卦的先后、杂卦以两两对举揭卦义相反相成。本站逐卦只列六十四卦，不把十翼拆成章节条目；十翼的内容放在核心理念、经典分析、思维导图与学习路径中集中讲清。

三、核心问题

全书反复回到几组互相扣连的命题。其一是变易、不易、简易：这是后世易家对「易」字三义的概括，变易言万物迁流，不易言变化之中有可循之则，简易言其理可约可执；三义属注家解释层，并非卦爻辞原有的一句话。其二是阴阳：一阴一阳之谓道、生生之谓易，皆出《系辞》，把奇偶二画读作对立而相济的两种势能。其三是时位：同一类爻辞因所处卦时、所居爻位而吉凶不同，时与位是读爻的基本语法，当位、得中、相应、承乘比应都是注家为这套语法立的名目。其四是乾坤健顺：乾象天、其德健，坤象地、其德顺，两卦被视为六十四卦的门户。其五是穷则变、物极则反与忧患意识：亢龙有悔、泰极而否、剥尽而复、既济之后继以未济，加上《系辞》「作《易》者，其有忧患乎」的设问，构成《易》对盛衰转化的独特敏感。象数与义理则是解《易》的两条大路，前者重卦象、爻位、卦气与数，后者重辞中义理与人事，本站设专篇辨析。

四、版本与校读

读《易经》最易踩的坑，是把不同层次、不同本子混为一谈。文本层次上，卦爻辞与十翼年代不同、语气不同，十翼内部各篇也非出自一手，故不宜把《系辞》的哲学命题直接回填为作卦辞时的想法。传本上，王弼本系统之外的出土材料提供了异文与异序：长沙马王堆帛书《周易》不以上下经分篇，卦序按八宫分组排列，与通行本次第大异；上海博物馆藏战国楚竹书《周易》、阜阳汉简《周易》为残本，可见卦爻辞异文与附属卜事之辞。本站逐卦以通行卦名为准，关键原文取短句并标卦名，读者可据书末所附古经全文、经传合本与百科条目复核；遇到「元亨利贞」「七日来复」一类聚讼纷纭的断句与训释，尽量并列两说而不轻断。

五、怎么读

建议按本站六栏目的动线走：先用学习路径五阶段建立坐标系，认清经传结构与十翼名目、精读乾坤与《文言》、通读上经三十卦、通读下经三十四卦、最后回到十翼并辨象数义理与出土本；再看思维导图把三大板块与阴阳、时位、卦爻、忧患穷变等概念挂到一张图上；以核心理念逐条拆开变易三义、时位、乾坤健顺、十翼立义与物极则反；用经典分析了解象数与义理两派、十翼非一人一时之作、卦序与出土本差异等公开争议；借名言警句记住最凝练的若干句；最后回到逐卦要点六十四卦逐一核校。右上角检索支持按卦名、要旨与关键词查找，章节区可按分部筛选与批量展开。

六、一点提醒

《易经》最诱人也最危险的读法，是把它读成一本处处藏着现成答案的预言书，或反过来读成一部体系严整的哲学著作而抹去其占筮出身。较稳妥的态度是分层：先承认卦爻辞本是简古的占断与取象，再承认十翼把它哲理化，再承认汉易象数、王弼义理、宋儒图书之学各是一时代的解释。观点评析务必区分文本依据、注家解释与今人看法。读六十四卦时不妨记住《序卦》以「物不可穷也，故受之以未济终焉」收尾：全书不以完成收束，而以未济收束，这本身或许就是关于变易最诚实的一句注解。

02

学习路径

五阶段路线：先认清经传结构与十翼名目，再以乾坤与《文言》学会读爻，按上下经通读六十四卦，最后回到十翼逐类核对并辨象数义理、卦序与出土本差异。每阶段标注建议篇目与可交付成果。

01

第一阶段 · 建立坐标系：经、传、卦、爻与十翼名目

建议 2—3 天

本阶段目标：分清古经与《易传》两层，记住六十四卦三百八十四爻的构造、上下经的分法、爻题的读法，以及十翼究竟是哪十篇。

  1. 画一张结构图把「经（卦辞、爻辞）」与「传（十翼）」分列，注明上经三十卦自乾、坤至坎、离，下经三十四卦自咸、恒至既济、未济，并记下六十四卦共三百八十四爻。本站导读·结构与分部 / 乾 / 坤 / 既济 / 未济
  2. 记住爻题语法六位自下而上为初、二、三、四、五、上，阳九阴六；能读出「初九」「六二」「上六」「用九」「用六」各指什么。乾 / 坤 / 本站术语速查

02

第二阶段 · 精读乾坤与《文言》：健顺、时位与读爻法

建议 1 周

本阶段目标：以乾、坤两卦为门户，掌握「卦时—爻位—占断」的读法，理解乾健坤顺、用九用六与六龙时位，并初识《文言》如何把卦爻辞德性化。

  1. 把乾卦六爻排成一条时位线从初九潜龙勿用、九二见龙在田、九五飞龙在天到上九亢龙有悔，逐爻记下所处之「位」与所值之「时」，看吉凶为何随位迁移。乾 / 乾·初九 / 乾·上九
  2. 对读坤卦与乾卦以「履霜，坚冰至」「直方大，不习无不利」「括囊」「黄裳元吉」对照乾之刚健，理解坤顺、承天、先迷后得的含义。坤 / 坤·初六 / 坤·六二
  3. 读《文言》的四德说《文言》以元、亨、利、贞配善之长、嘉之会、义之和、事之干，把占断之辞转为德性语汇；注意这是十翼的解释，不是卦辞本义。文言·乾 / 乾·卦辞
  4. 留意用九与用六乾、坤特有的「用九」「用六」提示全变之爻，与「亢龙有悔」合读，可见物极则反、纯刚不可久的思路。乾·用九 / 坤·用六

第三阶段 · 上经三十卦：从天地之象到泰否剥复

建议 2—3 周

本阶段目标：按王弼本卦序通读乾、坤至坎、离三十卦，看清上经多取天地万物之象，并在泰否、剥复、坎离几组里读出阴阳消息与物极则反。

  1. 初创与蒙养一组屯、蒙、需、讼、师、比依次写初生之难、启蒙、待时、争讼、师众与亲比，注意卦辞多含「利建侯」「利涉大川」一类行止判断。屯 / 蒙 / 需 / 师 / 比
  2. 小畜履泰否的往来以泰「小往大来」与否「大往小来」对读，看阴阳二气往来如何决定通塞；再接同人、大有、谦、豫，观察盛而能谦的转折。泰 / 否 / 谦 / 豫
  3. 剥复与无妄大畜剥「不利有攸往」之后继以复「反复其道，七日来复」，是物极则反最清楚的一组；读《复·彖》「见天地之心」时注意区分十翼义理与卦辞。剥 / 复 / 无妄 / 大畜
  4. 以坎离收束上经颐、大过之后以坎、离终上经，坎为险、离为明，象辞重「常德行」「继明照四方」；可做一张上经三十卦卦义迁移图。颐 / 大过 / 坎 / 离

第四阶段 · 下经三十四卦：人事、家国与既济未济

建议 2—3 周

本阶段目标：通读咸、恒至既济、未济三十四卦，理解下经多取人事之象，并在损益、革鼎、既济未济几组里读出穷则变与忧患意识。

  1. 咸恒与家道咸言感、恒言久，下经由夫妇之端起；接遁、大壮、晋、明夷、家人、睽，看进退、明晦、同异如何随卦时展开。咸 / 恒 / 遁 / 明夷 / 家人 / 睽
  2. 蹇解与损益蹇难、解缓之后，损「惩忿窒欲」与益「见善则迁」成对，是下经最见修养功夫的一组，宜与大象辞合读。蹇 / 解 / 损 / 益
  3. 夬姤萃升至革鼎夬决、姤遇、萃聚、升进、困、井、革、鼎依次写聚散与改制，革「治历明时」、鼎「正位凝命」把变化落到制度之象。夬 / 姤 / 革 / 鼎
  4. 以既济未济收束全书既济「初吉终乱」、未济「小狐汔济，濡其尾」提示成中有毁、终而未穷；与《序卦》「物不可穷也，故受之以未济终焉」对读。既济 / 未济 / 序卦

  4. 写一份不轻断的总结要求分别写出古经原本可能是什么、十翼新增了什么、注家与今人各争议什么，并列出一条本书未解决的开放问题。全部栏目 / 书末延伸阅读与出处

  • 象上下 — 大象取卦象立君子之则，如天行健、地势坤；小象逐爻释爻辞。（象传·乾、坤）

阴阳与三易全书最根本的两画与后世对「易」字的三义概括

01

变易、不易、简易：读《易》的三重眼光

三义是后世易家对「易」字的概括，不是卦爻辞里现成的一句话；分清层次才不会把注家话当成经文

变易

经文依据

古经本身并无「变易、不易、简易」的并列表述，这三义是汉唐以来易家对书名的概括，属注家解释层。经文中可据的是变动这件事：《系辞上》说「生生之谓易」「一阴一阳之谓道」，《系辞下》说「穷则变，变则通，通则久」，又说「《易》之兴也，其于中古乎」，把这部书与一个变动、多难的时代相连。卦爻辞一侧，乾卦六阳爻自初九「潜龙勿用」至上九「亢龙有悔」，以龙之潜、见、跃、飞、亢写同一物在不同时位的状态迁移，本身就是变易的演示；泰「小往大来」与否「大往小来」、复「反复其道，七日来复」也都以往来、反复立辞。读时须把「经文说到变」与「后人归纳出三义」分开，前者是文本依据，后者是解释框架。

逻辑结构

三义不是三种并列的学说，而是对同一部书的三个追问。变易答「世界如何」：六爻相杂、刚柔相推，一卦之内有位之迁，六十四卦之间有卦之序，没有一爻一卦是凝定不动的。不易答「变中何者可执」：变化并非无序，阴阳之对待、卦序之先后、时位之吉凶都有可循之则；「不易」不是不变，而是变之中恒常的条理。简易答「如何把握」：乾坤两卦立门户，八卦相重成六十四卦，繁变可约归为奇偶二画与健顺二德，故《系辞上》有「乾知大始，坤作成物」「易简而天下之理得矣」一类说法。三者叠合，正是「以约御繁」：因其变故须观时位，因其不易故可立辞断吉凶，因其简易故乾坤足以统摄全书。

常见误读

其一，把三义直接署为孔子或古经原话，引作「《易经》说变易不易简易」，这是把后起概括回填为经文；可靠的说法是「后世易家以三义释易名」。其二，把「不易」读成静止、不变、守旧，恰好错失原意——它指的是变中之常，而非不承认变。其三，把「简易」读成「容易、浅显」，于是以为《易》是一部通俗读物；其本义是「约而可执」，即以最简的阴阳结构统摄最繁的事象。其四，把「生生之谓易」与「变易」当作同义反复，前者强调新新不已的生成，后者强调状态的迁流，侧重点并不相同。

后世流变与阅读建议

三义之说在汉唐注家中渐成常谈，又被宋儒接去与「理」相配，成为解释易名的标准框架；王弼以义理扫落汉易繁琐象数，走的正是「简易」一路；今人多把三义视为一个有效的诠释框架，而非成书时代的自述。建议读时做一张三栏表：左栏抄一条经文或十翼原句，中栏标它属「文本依据」还是「注家解释」，右栏写这一命题在六十四卦里的对应例子，如泰否对应变易、卦序对应不易、乾坤对应简易。填完会发现，三义的价值不在替古人立体系，而在给读者一副分层阅读的眼镜。

02

时与位：卦爻如何说「处境」

卦以存时、爻以示变，同一句话吉凶不同，先因所值之时，再因所居之位

时位

经文依据

《系辞下》说「六爻相杂，唯其时物也」，又说「《易》之为书也，原始要终以为质也」，点明爻的意义须放回一卦之始终去看。最直观的例证是乾卦：初九「潜龙勿用」、九二「见龙在田」、九五「飞龙在天，利见大人」、上九「亢龙有悔」，同为龙、同为阳爻，却因自下而上的位次与所值之时而有勿用、利见、有悔之别。《彖传》解卦多以「时」立义，如赞「大矣哉」者多就一时之大势而言；《象传》大象辞则把卦象转成人事上的取法。《说卦》「立天之道曰阴与阳，立地之道曰柔与刚，立人之道曰仁与义」，又把六位分作初二为地、三四为人、五上为天的三才，位不只是序号，而有其所处的层次。

逻辑结构

读爻可拆成四层。卦时：一卦有一卦之整体处境，泰之时通、否之时塞、蹇之时难、解之时缓，先定卦时，再看单爻。爻位：六位自下而上为初、二、三、四、五、上，阳爻称九、阴爻称六；初三五为阳位、二四上为阴位，阳居阳位、阴居阴位称「当位」或「得正」。得中：二居内卦之中、五居外卦之中，既中且正者如乾九五，注家多断为吉。爻际：相邻为比、阴在阳下为承、阴在阳上为乘、初与四、二与五、三与上为应，合称承乘比应。四层叠加，才是「同一爻辞为何在此吉、在彼凶」的解释路径；时位不是给吉凶贴标签，而是说明吉凶所由的条件。

常见误读

其一，把爻辞当作可脱离卦体的独立格言，单引「潜龙勿用」劝人韬晦而不问它是乾之初九，于是同一部书里「飞龙在天」便无从安放。其二，把「当位即吉、不当位即凶」绝对化；当位只是注家归纳的判例之一，须合卦时、得中与应比同看，如卦时本塞，当位亦未必通。其三，把「中」理解成折中、调和、不走极端，其实它首先指二、五两个爻位，是一种结构位置而非处世态度。其四，把三才、当位、承乘比应都当成卦爻辞原有术语——这些是《彖》《象》以降注家逐步立出的分析名目，属解释层。

后世流变与阅读建议

汉易象数一派最重爻位，以位、应、互体推占验；王弼注《易》特重「卦以存时、爻以示变」，把时提到纲领位置；宋儒与今人则多从「处境」角度读，视六十四卦为六十四类典型情境，爻为情境中的不同位置。建议精读乾、坤两卦时做一张时位表：横轴列六位，纵轴记爻辞、阴阳、当位与否、得中与否、应与不应，再把泰、否、既济、未济各取一爻填入对照。表一填完便会明白，《易》的占断很少是无条件的断言，几乎总是「在此时、居此位、如此则吉，如彼则凶」的条件句。

03

乾健坤顺：六十四卦的门户

健与顺不是强与弱的等级，而是创始与承成两种功能；乾坤对读，才看得见阴阳如何相济

乾坤

经文依据

乾卦六阳爻，卦辞「元亨利贞」；坤卦六阴爻，卦辞「元亨，利牝马之贞」，并有「君子有攸往，先迷后得主」之语。爻辞一侧，乾自「潜龙勿用」至「亢龙有悔」写刚健之物的升进与过亢，坤自初六「履霜，坚冰至」、六二「直方大，不习无不利」至上六「龙战于野，其血玄黄」写柔顺者之积渐、守方与极而相争。十翼把这两卦明确升为纲领：《彖传·乾》「大哉乾元，万物资始，乃统天」，《彖传·坤》「至哉坤元，万物资生，乃顺承天」；《象传》以「天行健，君子以自强不息」与「地势坤，君子以厚德载物」相对；《系辞下》称乾坤为「《易》之门」，《系辞上》说「乾知大始，坤作成物」；《文言》更专就此二卦申发，以元亨利贞配四德。

逻辑结构

健与顺是一对功能描述，而非价值等级。乾之健是「资始」「统天」，主开创、发动、立其端；坤之顺是「资生」「顺承」，主承受、成物、终其事，故卦辞于乾言「元亨利贞」而于坤系以「利牝马之贞」，特意点出顺而能行、非柔弱不动。二者互为条件：有始而无成，则创始落空；有成而无始，则承载无端。由此可解几处对称设计：乾、坤各多出「用九」「用六」一条，提示六爻全变时的整体取向；乾上九「亢龙有悔」与坤上六「龙战于野」同写极处之失，见纯刚纯柔皆不可久；六十四卦以乾坤开篇，《序卦》「有天地，然后万物生焉」正是把这一对待铺成全书的起点。阴阳相济，不在平均，而在各当其用。

常见误读

其一，由「天尊地卑」推出尊卑等级，再引申为男尊女卑的宇宙依据；这属后世应用，不是乾坤卦爻辞本身的论断，读时须标为注家或后世解释。其二，把「顺」读成消极服从、毫无主动性，忽略坤六二「直方大，不习无不利」的自主与「牝马」之「行」的健动。其三，把「天行健，君子以自强不息」「地势坤，君子以厚德载物」当作乾、坤的卦辞；二者出《象传》大象，是十翼依卦象所立的君子之则，层次不同。其四，把「元亨利贞」四德说当成卦辞本义，忽略它是《文言》新增的德性解释。

后世流变与阅读建议

《文言》把乾坤彻底德性化，宋儒又以健顺配天理与气质，今人则多从功能分工理解二者：一为发动，一为完成，同属变化之两面。建议做一次严格对读：把乾、坤的卦辞、六爻爻辞、用九用六并列成表，再逐条标出《彖》《象》《文言》各新增了什么。这样既看得见古经中简古的占断与取象，也看得见十翼如何把它们织成一套关于创始与承成的哲学；遇到「自强不息」「厚德载物」一类熟语，也就能顺手说清它出自十翼而非卦爻辞。

04

十翼立义：从卦爻辞到一部变化哲学

彖、象、文言、系辞、说卦、序卦、杂卦七类十篇各司其职，合起来把占筮之辞转成语录式的义理

十翼

文本依据

《易传》称十翼，是七类文字因分篇而成十篇：彖上传、彖下传、象上传、象下传、文言传、系辞上传、系辞下传、说卦传、序卦传、杂卦传。各篇取一两句即可见其职分。彖释卦辞，《彖传·乾》「大哉乾元，万物资始，乃统天」即以卦德断全卦。象分大象与小象，大象取卦象立君子之则，如乾「天行健，君子以自强不息」、坤「地势坤，君子以厚德载物」，小象则逐爻释辞。文言专申乾坤，《文言·乾》以「元者，善之长也；亨者，嘉之会也；利者，义之和也；贞者，事之干也」把占断之辞转为四德。系辞通论大义，「一阴一阳之谓道」「生生之谓易」「形而上者谓之道，形而下者谓之器」「易有太极，是生两仪」「穷则变，变则通，通则久」「作《易》者，其有忧患乎」皆出上下两篇。说卦列八卦取象与三才之道，「立天之道曰阴与阳，立地之道曰柔与刚，立人之道曰仁与义」即在此篇。序卦逐卦说明先后，以「有天地，然后万物生焉」起、以「物不可穷也，故受之以未济终焉」收。杂卦两两对举揭卦义之反，开篇「乾刚坤柔，比乐师忧」即是。

逻辑结构

七类不是七篇互不相干的论文，而是一条由近及远的解释链。彖、象贴着经文走，一释卦辞、一释卦爻之象，属「随文作注」；文言在注的基础上专就乾坤申发德性，是从注释转向义理的关捩；系辞脱开单卦，通论阴阳、变化、时位、忧患与作《易》之由，把全书提升为一套世界观；说卦补出八卦取象与方位的目录，使象可检索；序卦把六十四卦排成一条有理由的序列，答「何以次此」；杂卦再以错综对举的方式打散重排，示人一卦之义常须借其对卦显出。由「释辞」到「立义」再到「排序」与「对举」，古经中零散的占断与取象，遂被织成一部论变化结构的书。

常见误读

其一，把十翼整体署为孔子一人一时之作，旧题如此，但各篇文风、术语与所涉概念并不齐一，今人多视为战国至汉初儒家陆续编成。其二，把《系辞》「一阴一阳之谓道」「易有太极」直接回填为文王系卦辞时的想法，抹去经与传的年代差。其三，混淆大象与卦辞，把「自强不息」「厚德载物」「思患而豫防之」当作卦爻辞原文；它们出《象传》。其四，把「十翼」想成十篇各自独立的论文，忽略彖、象、系辞各分上下、七类而成十篇的由来，也忽略《序卦》与王弼本卦序互为表里的关系。

后世流变与阅读建议

汉人渐以十翼附经，王弼注本把《彖》《象》《文言》分系于卦爻辞之下，形成经传合本的通行面貌；宋代欧阳修已疑《系辞》《文言》非孔子作，此后疑古渐多，今人更据文风、概念层累与出土材料论其非一人一时之作。建议读时先备一张十翼对照表：每类列篇名、所释对象、一句代表语、对应卦或卦序，再各选一条与卦爻辞并置，标出「经文说了什么」「传新增了什么」。经传分观之后再合观，既不会把十翼的哲学误当古经本义，也不会因古经简质而错过十翼真正建成的变化哲学。

05

忧患、穷变与物极则反

亢龙有悔、泰否剥复、既济未济与《系辞》的设问，合起来是《易》对盛衰转化的敏感

穷变

经文依据

这套意识散在经与传两层。古经一侧：乾上九「亢龙有悔」写一爻升到极处之失；泰「小往大来，吉亨」与否「大往小来」以阴阳往来写通塞相仍；剥「不利有攸往」之后紧接复「反复其道，七日来复」，是剥尽而复；既济「初吉终乱」与未济「小狐汔济，濡其尾」把成中有毁、行而未济写成一个收束。十翼一侧最为显豁：《系辞下》「穷则变，变则通，通则久」与「作《易》者，其有忧患乎」，《文言·乾》「亢之为言也，知进而不知退，知存而不知亡，知得而不知丧」；《象传·既济》「君子以思患而豫防之」；《序卦》「物不可以终通，故受之以否」「物不可以终尽，剥穷上反下，故受之以复」「物不可穷也，故受之以未济终焉」。三层文本彼此呼应，构成一条清楚的线索。

逻辑结构

同一件事有三种写法。以爻位写：一卦六位自下而上，上爻多居极，乾上九亢而有悔，是「盈不可久」在单卦内的缩影。以卦序写：《序卦》不说孤立的一卦，而说「物不可以终通」「剥穷上反下」，把泰与否则、剥与复、既济与未济排成相邻的对子，通久必塞、尽处反下、成后未穷，卦序本身即是盛衰相仍的论证。以通则写：《系辞》把上述经验抽成「穷则变，变则通，通则久」，于是变不是权宜，而是穷处自有的出路。忧患意识则是这套变化观在人事上的落点：既济已定而大象仍言「思患而豫防之」，说明《易》所忧不在变之将至，而在人于已安时忘其将变。

常见误读

其一，把物极则反读成宿命循环，以为盛必衰、衰必盛而人无可为；文本说的是「穷则变」，变有待于人之能通，非自动往返。其二，把忧患意识读成悲观厌世，忽略「思患而豫防之」的重心在豫防，是居安而先设其防，不是弃事不为。其三，把「穷则变」读成随机应变、无原则的权宜，忽略它承「变则通、通则久」而来，变仍以可通可久为度。其四，把《序卦》的卦序理由当作古经编排时的自述；《序卦》是十翼之一，属后起的解释，王弼本卦序与之互为表里但不等同。

后世流变与阅读建议

汉易象数一派以卦气、消息说十二消息卦，把阴阳盛衰配入岁时，是这套意识的数推化；《序卦》则给出义理化的卦序说明；今人多视之为一种关于「完成之不可执」的变化观。建议做一张三组对照表：爻位组列乾上九与坤上六，卦序组列泰否、剥复、既济未济，通则组列《系辞下》与《序卦》相应句，各栏注明属文本依据、注家解释还是今人看法。特别留意全书以未济而非既济终篇：若既济是「已完成」，未济便是「尚未穷」，把终点留在开放处，或许正是这套忧患与穷变最诚实的一笔。

流派ANALYSIS 01

象数与义理：解《易》两派的分歧与判别

一派重卦象爻位与数，一派重辞中义理与人事，争的是「象能否尽意」而非要不要经典

谈《易经》的读法，常说有象数、义理两派。这说法便于入门，却也容易把一部书的解释史压成两个阵营，仿佛汉儒只讲象数、宋儒只讲义理、彼此水火。回到文本与注本，分歧其实集中在一个更具体的问题上：卦爻之象与卦爻之辞，究竟哪一边才是意义所归，象能不能把意说尽。

争议的几方

象数一路以卦象、爻位、互体、卦气、纳甲、爻辰等为工具，认为卦爻辞的吉凶须由象与数推出；汉易注家多属此脉，后世又以河洛、先天之图补其系统。其长处是把六十四卦当成一个可推演的结构，短处是推演层层附加，易与经文渐远。义理一路以辞为本，认为卦爻辞说的是人事进退与德性，读《易》在明其理而不在逐象；王弼注本扫落繁琐象数、标举「得意忘象」，是其关捩，宋程颐、朱熹各以理与象数折中立说。其长处在简明可应用于人事，短处是尽落义理后，卦爻辞中简古的取象与占断便容易被读成格言。今人看法多不取二选一：象数明其结构，义理明其旨趣，二者是解《易》取向而非互斥学派；同一部注本里也常两法并用。

如何判别

读者可循三条自行复核。第一，看它从哪一层起讲：凡以卦气、互体、爻位起讲并推占验者偏象数，凡以「君子以」「利贞」「有悔」直接落到进退德性者偏义理；先标层，再评得失。第二，查经与传的对应：拿《彖》《象》《说卦》与卦爻辞并置，看某家之说究竟是经文所有、《易传》所增，还是注家自设的推演规则；王弼本把《彖》《象》分系经文之下，正便于做这件对照。第三，看是否声明所用工具：把「互体」「卦气」等解释为后起的分析名目，而非古经自带术语，是判断一篇解读是否分层清楚的最低标准。再进一步，可对照古经全文与经传合本两种在线底本，核其引文有无添改。

小结

与其追问自己该站象数还是义理，不如时时问一句：这句话是卦爻辞、十翼，还是注家的推演。两派的真正遗产，是把「象—数—辞—意」这条链上每一环都试过一遍；读六十四卦时若能逐条标出层次，便不须先选边，也能看出一卦之义如何在不同解释层里增减。

成书ANALYSIS 02

十翼作者与年代：为什么说《易传》非一人一时之作

旧题孔子作十翼，宋代以后疑古渐起，今人多据文风、概念与出土材料视其为战国至汉初陆续编成

《易传》十翼旧题孔子所作，汉以来的经学叙述几乎以此为前提；但把彖、象、文言、系辞、说卦、序卦、杂卦连读，语气、术语与关切并不齐一。于是「十翼是否一人一时之作」成为易学里一个反复被提出的问题。它不只是署名之争，更牵动读者该把哪一层当作古经本义。

争议的几方

旧题一派：汉代史籍有孔子晚而喜《易》的记载，后世遂以画卦、系辞、作传分属伏羲、文王、孔子，十翼归孔子几乎成为常谈；此说把经传连成一个完整的圣贤传授谱系，便于立教，却少有文本内证。疑古一派：宋代欧阳修已疑《系辞》《文言》非孔子手笔，理由是其间有自设问难、文辞繁衍、彼此重复之处，不像一人整洁之作；此后质疑渐及十翼他篇。今人看法：多据文风差异、概念层累与出土材料，主张十翼非一人一时之作，大约是战国至汉初儒家学者陆续整理、附益而成，各篇成篇先后不一；这已成为多数学者的通识，但对每篇的具体年代仍有分歧。还有一派较审慎，认为「非孔子亲笔」不等于「与孔子之学无关」，主张把作者问题与思想渊源分开。

如何判别

读者不必先信定论，可按三条自查。第一，对读文风：把《彖传》《象传》的短注式语句，与《系辞》的长篇通论、《文言》的设问申发、《杂卦》的两两对举并置，看是否像同一手笔；体例差异是最直接的内证。第二，查概念层次：「一阴一阳之谓道」「形而上者谓之道」「易有太极」等命题的抽象程度，明显高于卦爻辞的占断取象，把它们放回经传年代差里看，便知不可互训。第三，看出土材料的旁证：马王堆帛书《周易》所附传文与通行十翼篇目、次第不尽相同，说明解经文字在汉初仍流动未定；这一旁证支持「陆续编成」，却也提醒读者不宜据单件材料断代。可据经传合本全文逐篇复核篇目与文句。

小结

把十翼判为非一人一时之作，并不贬低它的价值，反而让它更可读：彖、象、文言、系辞、说卦、序卦、杂卦各是一时一题的解释，合起来才见儒家如何一步步把占筮之辞织成变化哲学。读时坚持区分文本依据、注家解释与今人看法，比争一个署名更能带走东西。

版本ANALYSIS 03

卦序与出土本：通行本次第是怎么排出来的

王弼本六十四卦与《序卦》互为表里，帛书、楚简、汉简却给出不同次第与异文，读时须分「传本」与「解释」

本站逐卦依王弼本卦序排列：上经三十卦自乾、坤至坎、离，下经三十四卦自咸、恒至既济、未济。这个次第并非天然，也不曾见于卦爻辞本身；《序卦》逐卦说明先后理由，以「有天地，然后万物生焉」起、以「物不可穷也，故受之以未济终焉」收，注家又归纳出「二二相耦、非覆即变」的编组规律。出土材料面世后，人们发现别的本子并不这样排，于是「通行卦序何时定型、又为何如此」成了可讨论的问题。

争议的几方

通行本一派以王弼注本与经传合本为据，认为今本次第有《序卦》作内证，两两相耦、或覆或变，首尾以乾坤、既济未济照应，本身即是一套有理由的编排，不宜轻改。出土本对照一派指出：长沙马王堆帛书《周易》不以上下经分篇，而以八宫分组、上卦固定而下卦轮换的方式排列，首宫为乾，次第与通行本大异；上海博物馆藏战国楚竹书《周易》与阜阳汉简《周易》皆为残本，可见卦爻辞异文、特殊符号乃至附系的卜事之辞，简残虽难复原全序，却足以说明汉初以前《易》的文本与次序仍在流动。审慎一派提醒：异序不等于更古、更正确，出土本多带地域与抄写特征，宜先称「某本次第」，再谈优劣。今人看法多主「层累定型」：今本卦序是某一传本系统被立为正统后的结果，与《序卦》的解释相辅而行。

如何判别

三条路径可自行复核。第一，先定传本：拿古经全文逐卦抄出六十四卦次第，再读《序卦》，看解释在哪几处顺畅、哪几处显得牵强（如相邻卦义的承接是否勉强）。第二，并列异文：把帛书、楚简、汉简释文所见的卦名异写与爻辞异文列成表，注意许多差异只是通假与抄写，未必是义理分歧；勿据一条异文便断言今本讹误。第三，分清两类问题：「卦序为何这样排」是解释问题，「某本怎样排」是版本问题，二者不可互相替代；本站逐卦以通行卦名为准，正是不把版本结论塞进卦义解读。读者可据古经全文与经传合本两种在线底本核对次第，再以百科条目查出土材料的年代与出土情况。

小结

卦序给我们的最好提醒，是「次序本身也是一种解释」：《序卦》把六十四卦读成一条由天地到未济的叙事，出土本则让人看见这条叙事之外还有别的排法。读六十四卦时记住今本次第只是一个传本系统的选择，既不抹杀《序卦》的义理，也不把出土异序当成定本，便算把版本与解释分清楚了。

定性ANALYSIS 04

卜筮之书还是义理之书：关于《周易》性质的长期争论

卦爻辞的占断出身与十翼的哲理化并存，定性之争其实在问「经与传该合读还是分观」

《易经》常被两种相反的口气介绍：一种说它是卜筮之书，六十四卦不过是占问吉凶的签辞；另一种说它是义理之书，讲的是阴阳变化与进退德性。两说都能从文本里找到支撑，也各自抹掉了对方的证据。争点其实不在「哪一说对」，而在经与传两层该合读还是分观，以及后人是否有权把后来长出的哲学算作本书本义。

争议的几方

卜筮出身一派指出：古经卦爻辞多为「亨」「利贞」「吉」「凶」「悔」「吝」「利涉大川」「不利有攸往」一类占断，附以取象之辞，句式简古、功能指向行止决断，阜阳汉简《周易》残简更在卦爻辞后系有卜事之辞，可见它确曾用于占问；这一层是文本依据，不因后世哲理化而消失。义理立书一派以十翼为据：《彖》《象》以卦德与君子之则解卦，《文言》以四德释元亨利贞，《系辞》提出「一阴一阳之谓道」「形而上者谓之道」「作《易》者，其有忧患乎」，把占辞提升为论变化、时位与德性的哲学；王弼注本与宋儒注本沿此路，遂使《易》居群经义理之要。今人看法多主分层而非定性：古经与十翼年代不同、功能不同，硬说「本是卜筮，毫无义理」或「本是哲学，与占筮无关」都过度；较稳妥的表述是「占筮之书，经十翼而哲理化」。

如何判别

第一，看引的是哪一层：凡引「元亨利贞」「小往大来」而只作占断解者，说的是古经；凡引「天行健」「一阴一阳之谓道」而论德性者，说的是十翼；把两者混引而不标出处，是最常见的跳跃。第二，查一个具体卦：以乾为例，把卦辞「元亨利贞」、初九「潜龙勿用」、上九「亢龙有悔」，与《文言》四德说、《象传》「自强不息」并列，逐条标明各属何层，看哲学命题究竟在何处才出现。第三，看是否承认年代差：《系辞》既设问「《易》之兴也，其于中古乎」「作《易》者，其有忧患乎」，便已把成书当作一个可追问的历史问题，读时自不宜再把十翼当作卦爻辞同时代的注脚。可用古经全文与经传合本对读核其引文。

小结

把《易》定死为卜筮或义理，都会削掉半部书。可带走的读法是分层：先按占断与取象读古经，再按变化哲学读十翼，再看注家如何把两层接起来，并始终标清「文本依据／注家解释／今人看法」。这样，「一阴一阳之谓道」不必被还原成签辞，「亢龙有悔」也不必被提前读成道德训诫，两者各在其层里成立。

释义往来反复循其道，七日而阳气来复。

评析剥卦「不利有攸往」之后紧接复卦，是物极则反在卦序上的落点；《复·彖》「见天地之心」则属十翼的义理提升。

物极则反复卦序
“
初吉终乱

— 《易经·既济·卦辞》

释义初始得吉，终则生乱。

评析既济六爻皆当位而成事已定，卦辞却戒以终乱；《象传》「思患而豫防之」即由此立，正是忧患意识的集中处。

忧患既济未济物极
“
小狐汔济，濡其尾

— 《易经·未济·卦辞》

释义小狐几乎渡到对岸，却沾湿了尾巴，未能竟功。

评析全书以未济终篇而不以既济终篇，《序卦》「物不可穷也，故受之以未济终焉」正为这个收束作解。

未济变易卦序
“
大哉乾元，万物资始，乃统天

— 《易经·彖传·乾》

释义伟大啊乾之元，万物由它开始，并由此统贯天道。

评析《彖传》专为解释卦辞而作，此句把乾卦辞的占断提升为关于创始的论述，是经传分层的好标本。

乾彖传十翼
“
天行健，君子以自强不息

— 《易经·象传·乾》大象

释义天道运行刚健不已，君子取法于此，自我振作而不停息。

评析《象传》大象依卦象立君子之则，与卦辞并非一层；常被引作《易经》原文，须标明出自十翼。

乾健象传德性
“
地势坤，君子以厚德载物

— 《易经·象传·坤》大象

释义地势柔顺宽厚，君子取法于此，以深厚之德承载万物。

评析与上句相对，健与顺是创始与承成两种功能，而非尊卑等级；二句同出《象传》，宜成对记忆。

坤顺象传乾坤
“
元者，善之长也；亨者，嘉之会也；利者，义之和也；贞者，事之干也

— 《易经·文言·乾》

释义元是众善之首，亨是众美之聚，利是义之和协，贞是事之主干。

评析《文言》专申乾坤，把「元亨利贞」由占断之辞转配四德，是十翼德性化最清楚的一例，不是卦辞本义。

文言元亨利贞十翼
“
一阴一阳之谓道

— 《易经·系辞上》

释义一阴一阳交替相济，就称作道。

评析把奇偶二画提升为全书根本原理，是《系辞》通论大义的代表句；属十翼的哲理，不宜回填为卦爻辞时代的自述。

阴阳系辞十翼
“
穷则变，变则通，通则久

— 《易经·系辞下》

释义穷极则生变，变而后能通，能通而后可久。

评析把泰否、剥复、既济未济里散见的盛衰经验抽成通则；变以可通可久为度，并非无原则的权宜。

穷则变变通系辞
“
作《易》者，其有忧患乎

— 《易经·系辞下》

释义作《易》的人，大概是有忧患的吧。

评析《系辞》自设问难，把成书与多难的时代相连；忧患的重心在「思患而豫防之」，不是悲观弃事。

忧患意识成书系辞
“
立天之道曰阴与阳，立地之道曰柔与刚，立人之道曰仁与义

— 《易经·说卦》

释义确立天道的是阴与阳，确立地道的是柔与刚，确立人道的是仁与义。

评析《说卦》以三才配六位，又把八卦取象与方位编成目录；此句是理解初二为地、三四为人、五上为天的关键。

三才说卦阴阳
“
物不可穷也，故受之以未济终焉

— 《易经·序卦》

释义事物不会穷尽，所以在既济之后接以未济，用它来收束全书。

评析《序卦》的结句，解释何以不以「已完成」的既济收尾；与未济卦辞「小狐汔济，濡其尾」互为表里。

未济卦序变易
“
乾刚坤柔，比乐师忧

— 《易经·杂卦》

释义乾是刚、坤是柔，比卦乐、师卦忧。

评析《杂卦》以两两对举揭卦义之相反相成，与《序卦》的线性叙事恰成两种读法，十翼七类至此齐备。

上经三十卦

30 卦

自乾、坤至坎、离，多取天地万物之象，偏重宇宙与根本秩序。

上经三十卦-01 乾六阳爻之卦，象天、其德健，卦辞「元亨利贞」；六爻以龙之潜、见、跃、飞、亢写时位迁流，为六十四卦之首。 ＋
要点拆解
  • 自初九「潜龙勿用」至上九「亢龙有悔」，同一阳爻因所居之位与所值之时而吉凶不同，是读全书时位语法的范本。
  • 「用九」提示六爻全变、纯刚不可久，与「亢龙有悔」同见物极则反之意。
  • 《彖传》「大哉乾元，万物资始」、《象传》「天行健，君子以自强不息」、《文言》四德说，皆十翼对卦辞的层层提升。
关键原文
元亨利贞
研读提示

必精读的一卦。先把六爻按初、二、三、四、五、上排成时位表，再分别标出卦辞、《彖》《象》《文言》各属何层，勿把「自强不息」当作卦辞原文。

乾健时位门户
上经三十卦-02 坤六阴爻之卦，象地、其德顺，卦辞「元亨，利牝马之贞」；与乾并为门户，写柔顺承成、积渐守方。 ＋
要点拆解
  • 初六「履霜，坚冰至」见微知著，六二「直方大，不习无不利」见顺而有方，上六「龙战于野」写极处相争。
  • 「先迷后得主」「利牝马之贞」表明顺非柔弱不动，而是顺而能行、承天以成物。
  • 「用六」与乾「用九」相对；《彖传》「至哉坤元，万物资生，乃顺承天」、《象传》「地势坤，君子以厚德载物」皆属十翼。
关键原文
元亨，利牝马之贞
研读提示

与乾卦对读最见功效。注意「厚德载物」出《象传》大象，非坤卦辞；健顺是创始与承成的分工，不宜读成尊卑等级。

坤顺积渐门户
上经三十卦-03 屯雷雨之动、初生艰难之卦，卦辞「元亨利贞，勿用有攸往，利建侯」，写草创之时宜立基而勿远行。 ＋
要点拆解
  • 「勿用有攸往」与「利建侯」一止一立，把创始阶段的时位判断并列，是《易》条件句的典型。
  • 《象传》「云雷，屯；君子以经纶」，把雷雨未洽之象转为经营筹划的人事取法。
  • 继乾坤之后为第三卦，《序卦》「有天地，然后万物生焉……故受之以屯」正说明其位置。
关键原文
勿用有攸往，利建侯
研读提示

与《序卦》开篇对读，可见卦序把屯放在万物始生之处；「经纶」是大象辞，勿混入卦辞层次。

创始时位卦序
上经三十卦-04 蒙山下出泉、蒙稚待启之卦，卦辞「亨。匪我求童蒙，童蒙求我」，写启蒙须由学者主动来求。 ＋
要点拆解
  • 「匪我求童蒙，童蒙求我」把教与学的关系定为「求」，与「初筮告，再三渎，渎则不告」同见对问者诚敬的要求。
  • 《象传》「山下出泉，蒙；君子以果行育德」，以泉之始达喻养正。
  • 《序卦》「物生必蒙，故受之以蒙」，承屯之始生而言。
关键原文
匪我求童蒙，童蒙求我
研读提示

「果行育德」出《象传》大象；读时留意卦辞中的「筮」字，可见古经与占问的关联，这在义理化解读中最易被略过。

启蒙养正卦序
上经三十卦-05 需云上于天、有待而成之卦，卦辞「有孚，光亨，贞吉，利涉大川」，写需待之时贵在诚信与守正。 ＋
要点拆解
  • 「需」非消极等待，卦辞以「利涉大川」收尾，说明待时正为济险而行。
  • 六爻多取「需于郊」「需于沙」「需于泥」等位次，愈近险愈戒惧，仍是时位语法。
  • 《象传》「云上于天，需；君子以饮食宴乐」，以养待时，属十翼取法。
关键原文
有孚，光亨，贞吉，利涉大川
研读提示

与讼卦对读，一待一争；「饮食宴乐」出大象辞，不宜误读成纵逸，其意在养其有待。

需待时济险
上经三十卦-06 讼天与水违行、争讼之卦，卦辞「有孚，窒惕，中吉，终凶」，戒人讼不可久、贵在谋始。 ＋
要点拆解
  • 「中吉，终凶」明言讼以中止为吉、究竟为凶，与《易》戒盈戒极的一贯思路相通。
  • 「利见大人，不利涉大川」再申宜求裁断而不可冒进，行止判断皆系于卦时。
  • 《象传》「天与水违行，讼；君子以作事谋始」，把争讼之因前移到事初。
关键原文
利见大人，不利涉大川
研读提示

与需卦为覆卦，一待一争；「作事谋始」出《象传》大象，属十翼的人事取法。

争讼作事谋始忧患
上经三十卦-07 师地中有水、师众之卦，卦辞「贞，丈人吉，无咎」，写兴众贵在正与老成之将。 ＋
要点拆解
  • 「贞」为师众之先决，「丈人吉」把胜负系于统帅之德与经验，非徒众寡。
  • 爻辞「师出以律」「在师中吉」等，多就纪律与位次立辞，仍可见时位语法。
  • 《象传》「地中有水，师；君子以容民畜众」，把兵众之象转为平时养民。
关键原文
贞，丈人吉，无咎
研读提示

与比卦相邻，《杂卦》「比乐师忧」正点出二卦一乐一忧；「容民畜众」是大象辞。

师众正忧患
上经三十卦-08 比地上有水、亲比之卦，卦辞「吉。原筮，元永贞，无咎」，写相亲贵在审择与恒正。 ＋
要点拆解
  • 「原筮」提示亲比之前须再审，「元永贞」则要求本于元、久于永、守于正。
  • 「不宁方来，后夫凶」以先后迟速立断，是时位在人事上的又一种用法。
  • 《象传》「地上有水，比；先王以建万国、亲诸侯」，把水附于地之象转为分封亲附。
关键原文
原筮，元永贞，无咎
研读提示

与师卦为覆卦，合《杂卦》「比乐师忧」对读；大象辞属十翼，勿与卦辞混。

亲比审择时位
上经三十卦-09 小畜风行天上、小有畜止之卦，卦辞「亨。密云不雨，自我西郊」，写畜之未充、暂未施行。 ＋
要点拆解
  • 「密云不雨」是最著名的取象之辞，以云聚而未雨状畜力未足、其施未行。
  • 一阴畜五阳，所畜者小，故卦名「小畜」；读时可留意「小」字限定了程度。
  • 《象传》「风行天上，小畜；君子以懿文德」，把未能远施转为内蓄文德。
关键原文
密云不雨，自我西郊
研读提示

与履卦相邻，《序卦》「物畜然后有礼，故受之以履」；「懿文德」出大象辞，属十翼取法。

小畜未施取象
上经三十卦-10 履上天下泽、履礼践行之卦，卦辞「履虎尾，不咥人，亨」，写以柔履刚、谨行而得亨。 ＋
要点拆解
  • 「履虎尾」以蹈危为象，「不咥人」以敬慎免祸，凶险与亨通并见一卦。
  • 爻辞「素履」「履道坦坦」「夬履」等，多就所履之位立辞，柔履刚为其主线。
  • 《象传》「上天下泽，履；君子以辨上下、定民志」，把尊卑之序转为礼的取法。
关键原文
履虎尾，不咥人，亨
研读提示

与小畜为覆卦，合读可见畜而后履的卦序；「辨上下、定民志」出大象辞。

履礼敬慎时位
上经三十卦-11 泰天地交、通泰之卦，卦辞「小往大来，吉亨」，写阴阳往来而成通。 ＋
要点拆解
  • 「小往大来」以往来写阴阳二气各归其位，是《易》以消息说通塞的显例。
  • 九三「无平不陂，无往不复」提示通中已含复之机，与物极则反相表里。
  • 《象传》「天地交，泰；后以财成天地之道、辅相天地之宜」，属十翼的推扩。
关键原文
小往大来，吉亨
研读提示

与否卦为覆卦，宜成对精读；「无平不陂，无往不复」出泰九三爻辞，非卦辞，引用须标爻位。

泰阴阳往来物极则反
上经三十卦-12 否天地不交、闭塞之卦，卦辞「否之匪人，不利君子贞，大往小来」，与泰相反而成对。 ＋
要点拆解
  • 「大往小来」与泰「小往大来」恰成反辞，通塞之别全在阴阳往来。
  • 「不利君子贞」非谓君子不当守正，而是说否时守正亦难行，须合卦时读。
  • 《象传》「天地不交，否；君子以俭德辟难，不可荣以禄」，把闭塞转为敛德避患。
关键原文
不利君子贞，大往小来
研读提示

泰否相邻，是读「时」最好的一组；「俭德辟难」出大象辞，勿与卦辞混层。

否闭塞时
上经三十卦-13 同人天与火、与人相同之卦，卦辞「同人于野，亨」，写旷远无私之同。 ＋
要点拆解
  • 「于野」与「于宗」相对，前者广而无私、后者狭而有系，爻辞正由此分高下。
  • 「利涉大川，利君子贞」说明同而能济险，且以君子之正为条件。
  • 《象传》「天与火，同人；君子以类族辨物」，在同中仍主分辨，非混然无别。
关键原文
同人于野，亨
研读提示

与大有为覆卦，《序卦》「与人同者物必归焉，故受之以大有」；「类族辨物」出大象辞。

同人公私分辨
上经三十卦-14 大有火在天上、所有者大之卦，卦辞「元亨」，写盛大之时以柔居尊而能有其众。 ＋
要点拆解
  • 一阴居五而五阳应之，是「大有」之体；盛大而不骄，故爻辞多戒「无交害」「匪其彭」。
  • 上九「自天祐之，吉无不利」为全卦收束，《系辞上》曾引而申之。
  • 《象传》「火在天上，大有；君子以遏恶扬善、顺天休命」，属十翼取法。
关键原文
元亨
研读提示

「元亨」二字极简，宜与同人、谦、豫连读，看盛大之后卦序如何接以谦；大象辞须标明层次。

大有盛戒盈
上经三十卦-15 谦地中有山、谦下之卦，卦辞「亨，君子有终」，写以谦持盈而能有终。 ＋
要点拆解
  • 「有终」是谦卦最吃紧处：谦非一时退让，而是能保其终，与「亢龙有悔」恰成对照。
  • 六爻多言「谦谦」「鸣谦」「劳谦」，谦随位而异，仍不脱时位语法。
  • 《象传》「地中有山，谦；君子以裒多益寡、称物平施」，把谦转为均平之则。
关键原文
亨，君子有终
研读提示

《序卦》「有大者不可以盈，故受之以谦」，正接大有；「裒多益寡」出大象辞，属十翼。

谦有终戒盈
上经三十卦-16 豫雷出地奋、顺以动而豫乐之卦，卦辞「利建侯行师」，写豫之可用在立君与出师。 ＋
要点拆解
  • 「利建侯行师」把豫乐与顺动相连，非纵逸之谓，故爻辞戒「鸣豫」「冥豫」。
  • 六二「介于石，不终日，贞吉」以知几为吉，《系辞下》曾就此申发。
  • 《象传》「雷出地奋，豫；先王以作乐崇德」，是十翼由乐象立礼乐之取法。
关键原文
利建侯行师
研读提示

与谦为覆卦，谦豫相邻可见一敛一舒；「介于石」出豫六二爻辞，非卦辞。

豫顺动知几
上经三十卦-17 随泽中有雷、随时而从之卦，卦辞「元亨利贞，无咎」，写随而能正乃得无咎。 ＋
要点拆解
  • 「元亨利贞」四德具备而系以「无咎」，暗示随之失正在所难免，须以正自持。
  • 爻辞「系小子，失丈夫」「随有求得」等，写所随对象与所居之位决定得失。
  • 《象传》「泽中有雷，随；君子以向晦入宴息」，以随时作息为取法。
关键原文
元亨利贞，无咎
研读提示

与蛊为覆卦，《序卦》「以喜随人者必有事，故受之以蛊」；「向晦入宴息」出大象辞。

随时正

与损为覆卦；《序卦》「损而不已必益，故受之以益」。「见善则迁，有过则改」出大象辞。

益迁善有为

  • 「孚号有厉」并列诚信、呼号与危惧，决非轻举，戒其恃众。

扬于王庭，孚号有厉
研读提示

夬决知危戒盈
下经三十四卦-44 姤天下有风、不期而遇之卦，卦辞「女壮，勿用取女」，写一阴初生而渐长之戒。 ＋
要点拆解
  • 「女壮，勿用取女」以一阴遇五阳为象，戒其微而渐盛，与「履霜，坚冰至」同一见微之理。
  • 爻辞「系于金柅」「包有鱼」「姤其角」等，遇之制与不制随位而异。
  • 《象传》「天下有风，姤；后以施命诰四方」，属十翼取法。

女壮，勿用取女
研读提示

与夬为覆卦；一阴初生即戒其壮，是阴阳消息与忧患意识相合的一例。

姤遇几微消息
下经三十四卦-45 萃泽上于地、聚集之卦，卦辞「亨，王假有庙，利见大人」，写聚贵在有主与有孚。 ＋
要点拆解
  • 「王假有庙」以宗庙之聚为正，「利见大人」以有主为聚之条件，聚非徒众。
  • 爻辞「有孚不终」「引吉」「萃如嗟如」等，聚之信否与位次相关。
  • 《象传》「泽上于地，萃；君子以除戎器，戒不虞」，属十翼取法。
关键原文
王假有庙，利见大人
研读提示

与升为覆卦，《序卦》「物相遇而后聚，故受之以萃」；「戒不虞」出大象辞，正见聚中之忧患。

萃聚有主戒备
下经三十四卦-46 升地中生木、积小以高大之卦，卦辞「元亨，用见大人，勿恤，南征吉」，写升进而勿忧。 ＋
要点拆解
  • 「用见大人，勿恤」把升进系于得其所见，非盲进；「南征吉」再以方向系之。
  • 爻辞「允升」「升虚邑」「冥升」等，升之信、渐与极随位而异。
  • 《象传》「地中生木，升；君子以顺德，积小以高大」，属十翼取法。
关键原文
元亨，用见大人，勿恤
研读提示

与萃为覆卦；「积小以高大」出大象辞，与「简易」之以约御繁可相参。

升进积渐顺德
下经三十四卦-47 困泽无水、困穷之卦，卦辞「亨，贞，大人吉，无咎，有言不信」，写困而能亨在守正之大人。 ＋
要点拆解
  • 「有言不信」点出困时言不足恃，与《彖传》「尚口乃穷也」相发，是困卦最峻的一句。
  • 爻辞「困于株木」「困于酒食」「困于葛藟」等，困之所在随位而迁。
  • 《象传》「泽无水，困；君子以致命遂志」，属十翼取法。
关键原文
亨，贞，大人吉，无咎
研读提示

与井为覆卦，《序卦》「升而不已必困，故受之以困」；「致命遂志」出大象辞。

困守正忧患
下经三十四卦-48 井木上有水、井养之卦，卦辞「改邑不改井，无丧无得，往来井井」，写井之为德恒常而不竭。 ＋
要点拆解
  • 「改邑不改井」以邑可迁、井不可迁写「不易」，是变中之常最贴切的一句卦辞。
  • 「汔至亦未繘井，羸其瓶，凶」以将成而败为戒，与未济「濡其尾」同一忧患笔法。
  • 《象传》「木上有水，井；君子以劳民劝相」，属十翼取法。
关键原文
改邑不改井，无丧无得
研读提示

与困为覆卦；「无丧无得」可与变易三义中的「不易」对读，但三义属注家概括，勿混层。

井不易恒常
下经三十四卦-49 革泽中有火、变革之卦，卦辞「巳日乃孚，元亨利贞，悔亡」，写改制动须待其信而后孚。 ＋
要点拆解
  • 「巳日乃孚」把变革之可信系于时至，非一令可成；《彖传》以「天地革而四时成」申之。
  • 爻辞「巩用黄牛之革」「大人虎变」「君子豹变」等，革之坚、文与成随位而异。
  • 《象传》「泽中有火，革；君子以治历明时」，属十翼取法。
关键原文
巳日乃孚，元亨利贞，悔亡
研读提示

与鼎为覆卦，《序卦》「井道不可不革，故受之以革」；「治历明时」出大象辞。革是「穷则变」落到制度之象的一卦。

革穷则变待时
下经三十四卦-50 鼎木上有火、鼎器之卦，卦辞「元吉，亨」，写烹饪成物、正位凝命之象。 ＋
要点拆解
  • 卦形取鼎：初为足、二三四为腹、五为耳、上为铉，是取象与卦体相扣的显例。
  • 爻辞「鼎颠趾」「鼎有实」「鼎折足」等，以器之用否随位立辞。
  • 《象传》「木上有火，鼎；君子以正位凝命」，属十翼取法。
关键原文
元吉，亨
研读提示

与革为覆卦，革去故而鼎取新；《序卦》「革物者莫若鼎，故受之以鼎」；「正位凝命」出大象辞。

鼎取新正位
下经三十四卦-51 震洊雷相继、震动之卦，卦辞「亨，震来虩虩，笑言哑哑，震惊百里，不丧匕鬯」，写惧而后安。 ＋
要点拆解
  • 「虩虩」之惧与「哑哑」之安相连，见《易》由戒惧得亨的一贯思路。
  • 「不丧匕鬯」以主祭者不失其守为象，与「恐惧修省」相表里。
  • 《象传》「洊雷，震；君子以恐惧修省」，属十翼取法。
关键原文
震来虩虩，笑言哑哑
研读提示

与艮为覆卦，一动一止；「恐惧修省」出大象辞，可与《系辞下》忧患之问对读。

震戒惧动静
下经三十四卦-52 艮兼山并立、艮止之卦，卦辞「艮其背，不获其身，行其庭，不见其人，无咎」，写止于所当止。 ＋
要点拆解
  • 「艮其背」以不获其身为止之极致，卦辞连下数语，写止非不动而是止其所。
  • 爻辞「艮其趾」「艮其腓」「艮其辅」等，止之部位随位而上，仍见时位语法。
  • 《象传》「兼山，艮；君子以思不出其位」，属十翼取法。
关键原文
艮其背，不获其身
研读提示

与震为覆卦；「思不出其位」出大象辞。震动艮止相邻，是读动静与忧患的一组。

艮止时位动静
下经三十四卦-53 渐山上有木、渐进之卦，卦辞「女归吉，利贞」，写进贵以渐、如女子之归必待礼备。 ＋
要点拆解
  • 「女归吉」以婚嫁之循序为象，与「利贞」并列，渐进仍须守正。
  • 爻辞「鸿渐于干」「鸿渐于磐」「鸿渐于陆」等，以鸿之所止由下而上写位之迁。
  • 《象传》「山上有木，渐；君子以居贤德善俗」，属十翼取法。
关键原文
女归吉，利贞
研读提示

与归妹为覆卦，一渐一遽；「居贤德善俗」出大象辞。渐进与「积小以高大」可相参。

渐循序时位
下经三十四卦-54 归妹泽上有雷、归妹之卦，卦辞「征凶，无攸利」，写失正而遽进则无所利。 ＋
要点拆解
  • 「征凶，无攸利」是古经中少见的纯戒之辞，与渐之「吉」恰成对照。

关键原文
征凶，无攸利
研读提示

与渐为覆卦；《序卦》「渐者进也，进必有所归，故受之以归妹」。「永终知敝」出大象辞，正见忧患。

归妹失正知敝
下经三十四卦-55 丰雷电皆至、丰大之卦，卦辞「亨，王假之，勿忧，宜日中」，写丰盛宜持于中如日之方中。 ＋
要点拆解
  • 「宜日中」以日中则昃为戒，丰大而忧其将亏，是物极则反的显例。

  • 《象传》「雷电皆至，丰；君子以折狱致刑」，属十翼取法。
关键原文
亨，王假之，勿忧，宜日中
研读提示

丰日中则昃物极则反

要点拆解

小亨，旅贞吉
研读提示

与丰为覆卦，一盛大一羁旅；《序卦》「穷大者必失其居，故受之以旅」，正见盛衰相仍。

旅守正盛衰
下经三十四卦-57 巽随风相入、巽顺之卦，卦辞「小亨，利有攸往，利见大人」，写以顺入而利有所往。 ＋
要点拆解
  • 「小亨」与两「利」并列，巽之亨有限，须有所往、有所见乃成。
  • 爻辞「进退，利武人之贞」「巽在床下」等，巽之过与不及随位而异。
  • 《象传》「随风，巽；君子以申命行事」，属十翼取法。

小亨，利有攸往，利见大人
研读提示

与兑为覆卦，一入一悦；「申命行事」出大象辞。巽为八经卦之一，《说卦》列其取象。

巽顺入申命
下经三十四卦-58 兑丽泽相连、兑悦之卦，卦辞「亨，利贞」，写悦贵在正。 ＋
要点拆解
  • 卦辞仅「亨，利贞」三字，悦而系以利贞，戒其流于苟悦。
  • 爻辞「和兑」「孚兑」「来兑」「引兑」等，悦之和、孚与外求随位而异。
  • 《象传》「丽泽，兑；君子以朋友讲习」，属十翼取法。

亨，利贞

与巽为覆卦；「朋友讲习」出大象辞。兑为八经卦之一，可与《说卦》八卦取象对读。

兑悦利贞讲习
下经三十四卦-59 涣风行水上、涣散之卦，卦辞「亨，王假有庙，利涉大川，利贞」，写散而能聚、险而可济。 ＋
要点拆解
  • 「王假有庙」以宗庙聚其散，「利涉大川」以济险用其散，散非纯凶。
  • 爻辞「涣其躬」「涣其群」「涣汗其大号」等，所涣之大小随位而异。
  • 《象传》「风行水上，涣；先王以享于帝立庙」，属十翼取法。
关键原文
王假有庙，利涉大川
研读提示

与节为覆卦，《序卦》「说而后散之，故受之以涣」；「享于帝立庙」出大象辞。

涣散聚济险
下经三十四卦-60 节泽上有水、节度之卦，卦辞「亨，苦节不可贞」，写节贵得中、过苦则不可守。 ＋
要点拆解
  • 「苦节不可贞」是《易》少见的自我限定：节可亨，而节之过苦反不可恒守。
  • 爻辞「不出户庭」「不出门庭」「甘节」「苦节」等，节之当与过随位而异。
  • 《象传》「泽上有水，节；君子以制数度、议德行」，属十翼取法。
关键原文
亨，苦节不可贞
研读提示

与涣为覆卦；「制数度、议德行」出大象辞。「苦节不可贞」与「中」的尺度意识可相参。

节得中限度
下经三十四卦-61 中孚泽上有风、中心诚信之卦，卦辞「豚鱼吉，利涉大川，利贞」，写孚之感物虽微而吉。 ＋
要点拆解
  • 「豚鱼吉」以诚信及于微物为象，与「利涉大川」相连，孚可济险。
  • 爻辞「鸣鹤在阴，其子和之」「或鼓或罢」等，孚之应与否随位而异。
  • 《象传》「泽上有风，中孚；君子以议狱缓死」，属十翼取法。
关键原文
豚鱼吉，利涉大川，利贞
研读提示

与小过为覆卦；「议狱缓死」出大象辞。中孚、小过相邻，是下经末段论「信」与「过」的一组。

中孚诚信感物
下经三十四卦-62 小过山上有雷、小有所过之卦，卦辞「亨，利贞，可小事，不可大事」，写过宜小不宜大、宜下不宜上。 ＋
要点拆解
  • 「可小事，不可大事」与「飞鸟遗之音，不宜上，宜下，大吉」同申过之限度与方向。
  • 爻辞「飞鸟以凶」「过其祖，遇其妣」「弗过防之」等，过与不及随位而异。
  • 《象传》「山上有雷，小过；君子以行过乎恭、丧过乎哀、用过乎俭」，属十翼取法。
关键原文
可小事，不可大事
研读提示

与中孚为覆卦；《序卦》「有其信者必行之，故受之以小过」。大象辞三「过乎」正见小过之「小」。

小过限度宜下
下经三十四卦-63 既济水在火上、事已成之卦，卦辞「亨小，利贞，初吉终乱」，写六爻皆正而成中已伏乱。 ＋
要点拆解
  • 「初吉终乱」是既济最吃紧处：成非终点，既成而恃之则乱，正合物极则反。
  • 六爻阴阳各居其位，是注家所谓「当位」最整齐的一卦，却仍系以终乱。
  • 《象传》「水在火上，既济；君子以思患而豫防之」，属十翼取法。
关键原文
亨小，利贞，初吉终乱
研读提示

与未济为覆卦，必成对精读；「思患而豫防之」出大象辞，是忧患意识最集中处。

既济初吉终乱忧患
下经三十四卦-64 未济火在水上、事未成之卦，卦辞「亨，小狐汔济，濡其尾，无攸利」，写几成而败、终而未穷。 ＋
要点拆解
  • 「小狐汔济，濡其尾」以将济未济为象，与既济「初吉终乱」同为戒盈之辞。
  • 六爻皆不当位而未相济，故名未济；《序卦》以「物不可穷也，故受之以未济终焉」作全书收束。
  • 《象传》「火在水上，未济；君子以慎辨物居方」，属十翼取法。
关键原文
小狐汔济，濡其尾
研读提示

全书六十四卦终篇。以未济而非既济收束，把终点留在开放处，是读变易、穷则变与忧患意识的最后一句注解。

术语速查

读《易经》最容易卡住的术语，一词一解

卦六十四卦的基本单位，由六爻叠成，各有卦名、卦象与卦辞；通行本依王弼本卦序分上经三十卦、下经三十四卦。《易经·乾》《易经·序卦》
爻构成卦的奇偶二画，阳爻称九、阴爻称六，六爻自下而上为初至上的六个位；六十四卦共三百八十四爻。《易经·乾》《易经·坤》
卦辞系于一卦之下、总断全卦的辞，如乾「元亨利贞」、泰「小往大来，吉亨」；《彖传》即专为解释卦辞而作。《易经·乾》《易经·彖传·乾》
爻辞系于每一爻之下、就该爻之时位作占断的辞，如乾初九「潜龙勿用」、坤初六「履霜，坚冰至」。《易经·乾·初九》《易经·坤·初六》
阴阳奇偶二画所代表的两种势能，对立而相济；《系辞上》「一阴一阳之谓道」把这一对关系提升为全书根本原理。《易经·系辞上》
八卦乾、坤、震、巽、坎、离、艮、兑八经卦，两两相重为六十四卦；《说卦》专列其取象与方位。《易经·说卦》
乾六阳爻之卦，象天、其德健，卦辞「元亨利贞」；《彖传》称「大哉乾元，万物资始，乃统天」，《象传》称「天行健」。《易经·乾》《易经·彖传·乾》
坤六阴爻之卦，象地、其德顺，卦辞「元亨，利牝马之贞」；《象传》称「地势坤，君子以厚德载物」，与乾并为六十四卦门户。《易经·坤》《易经·象传·坤》

象卦爻所取之物象与事象，如乾为天、坤为地；《系辞上》言「立象以尽意」，《象传》即依象立君子之则。《易经·系辞上》《易经·象传》
