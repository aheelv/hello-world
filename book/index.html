EXTENSIBLE BY DESIGN

持续加书，只需三步

架构借鉴 VitePress 的文件即路由与自动发现机制。

01

复制模板

把 data/books/_template/ 复制为 data/books/<你的书>/，填写 meta.json 的书名、作者、原书字数与配色。

02

填内容

按既有栏目补 overview.md、concepts/*.md、analyses/*.md、quotes/*.json、chapters/*.json。章节可拆成任意多个 JSON 分片，构建时自动归并排序。

03

执行构建

运行 npm run build。首页书架卡片、书籍详情页、目录、检索索引、字数统计全部自动生成，旧书不受影响。
