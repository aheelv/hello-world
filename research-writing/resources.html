字段含义
等级A 官方规范与法规 / B 学术机构与学协会共识 / C 同行评议文献 / D GitHub 社区项目与工具。等级描述来源性质，不描述结论正确性。
阶段标签该资源在选题、设计、写作、投稿、评审、发表中的适用场景；一项可对应多阶段。
适用对象具体角色或场景，用于判断是否与你相关；不表示「适用于所有学科」。
时效版本、发布日期、更新频率或跳转情况。易变信息（字数、周期、录用率）本站刻意不固化。
核验 的核验状态：「可达」＝自动 HTTP 请求返回 200；「跳转」＝会重定向到新地址；「反爬拦截」＝自动请求返回 403/412，但正文已通过内容抓取确认。三种状态都不等于对内容的背书。
★ 星数仅对 GitHub 项目给出，通过 GitHub 官方 REST API 读取，标注读取日期；星数是流行度，不是权威性、正确性或同行评议结论。
适用边界本站认为最容易误用的地方，含学科范围、版本差异与时效风险。
筛选过程留痕：检索后未列为主资源的候选项目（含星数不足、链接 404、域名变更等）公开记录在维护与更新页，便于复核本站的取舍标准。
