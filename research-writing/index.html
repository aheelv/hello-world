先说清楚三件事

「SCI」不是质量等级

SCI（Science Citation Index）是 Web of Science 的文献索引，不是论文质量分级。「一区」「顶刊」「UTD24」「FT50」来自不同评价体系，彼此不等价，也不能替代对单篇研究的评价。DORA 明确反对用期刊层面指标衡量单篇论文或个人贡献。

本站不承诺任何录用结果

同行评审由编辑与审稿人独立判断。本站只整理「有依据、可执行、有边界」的做法，不提供录用率、中稿技巧或任何形式的保证，也不提供规避检测、去除 AI 痕迹、伪造数据与来源的方法。

二手译介，不替代原文

所有中文内容为依据官方原文的整理与摘译，不是官方中文版。字数、格式、署名、AI 政策、数据要求一律以目标期刊投稿当日官网为准；法规以发布机关现行文本为准。

证据分级：来源不是一律等价的

资源库为每一项标注等级。等级描述来源性质，不描述「结论有多正确」；高星 GitHub 项目尤其只代表流行度。

关于「GitHub 高星」：星数通过 GitHub 官方 REST API 于 读取，会随时间变化。社区项目可能很实用，但没有同行评议背书，也可能只适用于特定学科（例如本库最高星的写作技能包仅面向 ML/CV/NLP）。请把它当工具，不要当规范。

怎么使用本站

  1. 按阶段读正文：六篇教程给出可执行步骤与常见误区，均标注依据资源编号。
  2. 按编号查资源：所有 Rnn 编号（当前共 项）跳转到资源库对应卡片，卡上有来源机构、原始链接、适用对象、时效与适用边界。
  3. 看原文再决策：涉及署名、AI 披露、数据、重复发表等判断时，打开摘译页对照英文原文，并回到官方页面确认当期版本。
  4. 用清单收尾：合规与红线把做法分成「合规技巧 / 非正规高风险 / 学术不端」三类；术语表统一中英表述。

适用与不适用

本站适用范围：

适用

  • 以 SCI 索引期刊及学科高水平期刊为目标的实证研究作者；
  • 需要建立选题—设计—报告—投稿—评审的可追溯工作流的课题组；
  • 需要区分「合规提效」与「学术不端」的科研诚信培训场景。

不适用 / 需另行查证

  • 具体期刊的字数、版式、审稿周期、录用率——本站刻意不固化这类易变数字；
  • 医学临床试验等强监管研究的完整合规要求（须由伦理与法规专业人员审核）；
  • 法律意见、机构内部纪律认定、投稿纠纷仲裁。
可追溯性：每项资源记录了来源机构、原始 URL、适用对象、时效/版本说明与核验状态。核验方法与筛选时被剔除的候选资源，公开记录在维护与更新页。
