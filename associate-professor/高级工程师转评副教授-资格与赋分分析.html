一、结论摘要（两版对照）

直接回答你的疑问：旧版（2023）没有"校级教学比赛二等奖1/三等奖2 或 主持市级以上纵向项目"这道门槛。 该强制门槛是 2026修订版新增。2023版仅要求"任现职以来同时具备下列条件中的任意 3 项"（3选6，无单独门槛）。
决定你今年够不够格的，是"今年评审适用哪套规则"这一变量：
  • 若适用 2023版（很可能，因修订版2027-01-01才施行）：无门槛，你只需满足"3选6"。当前已稳满足 ⑤指导学生省二等奖、⑥软著转化；③校级教改（1结项+1在研）临界、①期刊旧分级待核——大概率已具备参评资格。
  • 若适用 2026修订版：仍缺门槛（校级教学比赛奖 或 市级以上纵向项目），需补齐后方可参评。
转评性质：同级转评（系统分析师·软考高级＝高级工程师，属《国家职业资格目录》）
高校教师资格证：已具备 ✓
双师双能：需先入教师系列才能办→对平转不构成前置阻碍（moot）
当前可确认得分（仅2026新版口径）：约 65 分
头号待确认项：2026修订版自 2027-01-01 施行。若今年评审的申报截止日早于该日，依法适用 2023版（对你更有利）；若在之后，则适用新版。务必向人事处（职称办）确认本周期适用版本、转评通道，以及你的论文在2023版下的期刊分级。

二、新旧版 副教授（教学科研型）条件 逐条对比

2023版（试行）第二十一条(三)

结构："同时具备下列条件中的任意 3 项"（无单独门槛）

  • 1. 二级B以上刊物3篇 / 二级A 2篇
  • 2. 专著/规划教材1部
  • 3. 省级以上纵向1 或 省级以上教改1 或 校级教改2项
  • 4. 前3 获省级以上教学/科研奖
  • 5. 省级教学竞赛二等奖以上/市级教学竞赛一等奖，或专业竞赛省级二等奖以上，或第一指导教师指导学生省级二等奖以上
  • 6. 科技开发/转化取得较为显著经济效益

注：2023版使用"二级B/二级A/三级"期刊分级体系（定义在科研工作量办法中）。

2026修订版 第二十一条(三)

结构：强制门槛 + "同时具备下列条件中的任意 4 项"

门槛（二选一）：校级教学比赛二等奖1/三等奖2，或主持市级以上纵向项目1项

  • 1. C2以上3篇 或 B2以上2篇
  • 2. 专著/规划教材1部
  • 3. 省级以上纵向1 或 省级以上教改1 或 校级教改2项
  • 4. 前3 省级以上奖
  • 5. 省级教学竞赛二等奖以上/市级教学竞赛一等奖，或专业竞赛省级二等奖以上，或第一指导教师指导学生省级二等奖以上
  • 6. 科技开发/转化显著效益
  • 7. 主持纵向/横向课题，每年到账经费2万以上

注：2026版改用 A1/A2/B1/B2/C1/C2/C3 分级，并新增"课题经费每年2万"项。

核心差异一句话：2023版是"3选6、无门槛"；2026修订版把"校级教学比赛/市级以上纵向"升级为强制门槛，并把数量从"3选6"提高到"门槛+4选7"。你之前被告知的"唯一硬缺口"，仅在 2026修订版 下存在。

六、关键风险与行动建议

  • 决定性问题（头号）：今年评审适用 2023版 还是 2026修订版？修订版自2027-01-01施行；若申报截止早于该日则依法用旧版（对你更有利）。立即问职称办确认版本、转评名额通道。
  • 期刊旧分级映射：你给的"B2/C3"是2026版分级；若走2023版，须按旧版"二级B/二级A/三级"重核论文定级，以判定条件①。
  • 在研校级教改计数：确认2023版下"校级教改2项"是否含在研/立项即计，以坐实条件③。
  • 若确认走2026修订版：仍须补门槛——校级教学比赛奖 或 市级以上纵向项目（大连市社科联/市科技局/省教育厅）。
  • 资格已齐备项：高校教师资格证✓、班导师1年✓、系统分析师＝高级工程师（目录内、专业相近）✓、教学科研满1年✓。
  1. 向职称办确认：①本周期适用规则版本；②转评是否有单独名额；③你的论文在2023版下的期刊定级；④系统分析师转评资历认定口径。
  2. 若走2023版：整理"3选6"佐证（重点确认①或③），基本可直接参评。
  3. 若走2026修订版：报名校级教学比赛 或 主持市级以上纵向项目（双保险）。
  4. 继续增厚：增B2/C2论文、参编教材、省级奖、提升竞赛等级、教学建设项目。
