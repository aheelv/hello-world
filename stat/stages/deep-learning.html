04 · 深度学习

把深层模型训练出来。掌握深层网络的训练方法论，能独立诊断并稳定一次训练。本页给出该阶段的完整学习路径、先修知识、难度层级、核心概念、目标能力、实践任务、评估标准与进阶衔接。

阶段定位

2006 年至今 · 训练范式与规模化。全站按「统计学 → 大数据分析 → 机器学习 → 深度学习 → 神经网络 → 生成式AI」组织。本路线按「先掌握方法与训练范式，再深入网络结构与机制，最后进入生成式系统」的认知顺序组织。深度学习与神经网络互为表里：阶段四聚焦如何把深层模型训练好，阶段五拆解网络结构本身为何有效，因此顺序上先四后五。

4 · 核心概念

反向传播

链式法则在计算图上的高效实现；本质是复用中间梯度而非重复求导。

梯度消失 / 爆炸

连乘导致梯度量级失衡；残差、归一化与初始化是三大对策。

自适应优化器

Adam 用一阶/二阶矩估计调整每参数步长；与统计中的自适应估计相通。

归一化

稳定激活分布，使更大学习率与更深网络可行。

混合精度与并行

FP16/BF16 换吞吐，数据/张量/流水并行换规模。

缩放定律

损失随参数量、数据量、算力呈幂律；训练预算分配的理论依据。

损失设计

交叉熵 = 负对数似然 = KL 相关量，把阶段一的 MLE 贯穿到底。

5 · 目标能力

完成本阶段后，你应当能够：

  • 能从零写出可训练的 MLP 与反向传播，并用梯度检查验证
  • 能读懂训练日志，定位不收敛、loss spike、过拟合与数值溢出
  • 能设计消融实验，区分「结构贡献」与「调参贡献」
  • 能用缩放定律做数量级估算：给定算力如何分配 N 与 D
  • 能在有限显存下用混合精度/累积/检查点完成一次完整训练

6 · 实践任务

任务按基础 → 进阶 → 挑战分层，均要求提交可复现产物，而非只看结论。

基础 实现 + 梯度检查报告

NumPy 实现 MLP

不依赖框架实现两层网络、交叉熵与反向传播，用数值梯度校验解析梯度。

进阶 消融表 + 曲线图

CIFAR-10 训练与消融

训练一个小 CNN，逐一消融数据增强、weight decay、warmup，记录验证曲线。

进阶 对比实验

优化器对比

在相同预算下比较 SGD+动量、AdamW、调度策略，解释收敛速度与泛化差异。

挑战 拟合代码 + 外推验证

缩放定律拟合

在 3 个以上模型尺度上拟合 L(N) 幂律，预测第 4 个尺度并验证误差。

挑战 故障手册

训练故障复盘

故意制造 FP16 溢出、错误归一化位置、数据泄漏，记录症状与定位过程。

7 · 评估标准

达标再进阶
维度可检验标准
实现正确性手写反向传播通过数值梯度检查（相对误差 < 1e-6 量级）。
诊断能力对给定训练曲线能给出至少 2 个可检验假设与对应验证操作。
实验规范消融实验只变一个因素，记录种子、预算与完整超参。
理论连接能说明交叉熵损失与最大似然估计的等价关系。
衔接 readiness训练已稳定后，能提出「为什么这个结构有效」的问题，自然进入架构剖析。
