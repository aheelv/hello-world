02 · 大数据分析

当推断遇上规模。在 TB 级、流式、分布式环境下仍能做出统计上可信的分析。本页给出该阶段的完整学习路径、先修知识、难度层级、核心概念、目标能力、实践任务、评估标准与进阶衔接。

阶段定位

2000 年代至今 · 分布式与流式范式。全站按「统计学 → 大数据分析 → 机器学习 → 深度学习 → 神经网络 → 生成式AI」组织。本路线按「先掌握方法与训练范式，再深入网络结构与机制，最后进入生成式系统」的认知顺序组织。深度学习与神经网络互为表里：阶段四聚焦如何把深层模型训练好，阶段五拆解网络结构本身为何有效，因此顺序上先四后五。

4 · 核心概念

分区与 shuffle

分布式聚合的成本中心；理解它才能解释作业为何慢、为何 OOM。

批式 vs 流式

有界数据与无界数据的语义差异，决定窗口、状态与迟到数据处理。

列式存储与向量化

只读取需要的列；Parquet/Arrow 让单机也能做十亿行聚合。

近似算法与误差界

用可控误差换内存与时间；必须能写出误差概率/相对误差上界。

分流与可交换性

哈希分桶保证组间独立；这是大规模 A/B 测试统计有效性的前提。

数据漂移与血缘

分布随时间变化会让校准好的模型与阈值静默失效。

可扩展统计估计

分治合并、在线更新、随机梯度；把估计量改造成可并行的形式。

5 · 目标能力

完成本阶段后，你应当能够：

  • 能估算一个分析作业的数据量、内存与网络 shuffle 成本
  • 能为同一指标选择精确算法或近似算法，并说明误差与资源权衡
  • 能设计分层随机分流与护栏指标，避免网络效应与提前窥探
  • 能用 DuckDB/Polars/Spark 完成十亿行级聚合与可复现报告
  • 能识别并定位数据倾斜、重复计数、迟到数据导致的统计偏差

6 · 实践任务

任务按基础 → 进阶 → 挑战分层，均要求提交可复现产物，而非只看结论。

基础 基准脚本 + 对比表

十亿行聚合

生成 1 亿行以上合成日志，分别用 pandas、DuckDB、Polars 完成分组统计，记录耗时与峰值内存。

进阶 实现/调用 + 误差曲线

近似去重

实现 HyperLogLog 或用现有库，与精确集合对比，画出相对误差随基数变化的曲线。

进阶 Spark UI 截图说明 + 前后对比

Spark 倾斜诊断

构造长尾 key 数据，观察 stage 耗时分布，用 salting / 两阶段聚合修复并量化改进。

挑战 流式作业 + 语义说明

流式窗口统计

用事件时间与水位线计算 5 分钟滑动均值，注入迟到事件并解释结果变化。

挑战 分流器 + 平衡性检验

分层 A/B 分流

实现哈希分桶，验证各层正交性与组间协变量平衡，写一份分流校验报告。

7 · 评估标准

达标再进阶
维度可检验标准
规模意识能在写 SQL 前估算数据量、shuffle 体积与内存占用，并据此选择引擎。
误差可解释对任何近似结果能给出误差界或置信陈述，而不是只报一个数。
统计有效性能说明大样本下 p 值失效的原因，改用效应量/置信区间/序贯方法。
可复现作业参数、数据版本、随机种子与口径全部记录，结果可重跑一致。
衔接 readiness能把清洗好的特征稳定产出为训练/验证/测试集，理解数据泄漏在管线层面的来源。
