03 · 机器学习

从推断到预测。独立完成端到端建模，并给出统计上可辩护的评估结论。本页给出该阶段的完整学习路径、先修知识、难度层级、核心概念、目标能力、实践任务、评估标准与进阶衔接。

阶段 3 L2 → L4 第 11–15 周 40 学时 2 个专题 更新 2026-11-07
阶段定位

1950 年代至今 · 统计学习范式。全站按「统计学 → 大数据分析 → 机器学习 → 深度学习 → 神经网络 → 生成式AI」组织。本路线按「先掌握方法与训练范式，再深入网络结构与机制，最后进入生成式系统」的认知顺序组织。深度学习与神经网络互为表里：阶段四聚焦如何把深层模型训练好，阶段五拆解网络结构本身为何有效，因此顺序上先四后五。

4 · 核心概念

经验风险最小化

训练即估计：用样本平均损失逼近期望损失。

偏差-方差分解

把泛化误差拆成系统性偏差、估计方差与不可约噪声。

正则化

L1/L2 既是复杂度惩罚，也可理解为拉普拉斯/高斯先验（呼应阶段一）。

交叉验证与数据泄漏

任何在切分前用到全数据的操作都会让评估失真。

集成与Boosting

Bagging 降方差、Boosting 降偏差，是偏差-方差权衡的工程化。

双重下降

过参数化后测试误差再次下降，修正经典 U 型曲线认知。

校准

预测概率是否可信；准确率之外必须检查 Brier 分数与可靠性图。

5 · 目标能力

完成本阶段后，你应当能够：

  • 能把业务目标翻译成可优化的损失函数与可解释的评估指标
  • 能设计无泄漏的训练/验证/测试协议并说明每一折的用途
  • 能对同一问题比较 3 类以上模型，并给出带不确定性的结论
  • 能诊断过拟合、欠拟合、类别不平衡与分布偏移
  • 能解释正则化、集成与超参选择背后的统计动机

6 · 实践任务

任务按基础 → 进阶 → 挑战分层，均要求提交可复现产物，而非只看结论。

基础 Notebook + 模型卡

表格数据端到端

在一份公开表格数据集上完成特征管线、3 类模型对比、5 折分层 CV 与 Bootstrap 置信区间。

进阶 对照实验 + 说明

数据泄漏诊断

复现「先全量标准化再切分」「时间序列随机切分」两类泄漏，量化评估虚高幅度并修正。

进阶 计算 + 系数路径图

AIC/BIC 与正则化路径

手算两个模型的 AIC/BIC，绘制 Ridge/Lasso 系数随 λ 变化路径，解释差异。

挑战 可靠性图 + 决策分析

校准评估

比较未校准与 Platt/等距回归校准后的 Brier 分数与可靠性图，讨论阈值决策。

挑战 实验脚本 + 数值核对

偏差-方差数值实验

对同一 x₀ 重复采样训练，实测分解式中的三项并验证等式成立。

7 · 评估标准

达标再进阶
维度可检验标准
评估严谨性能说明验证集与测试集不得互相污染，且能主动检查泄漏。
结论带不确定性模型对比给出置信区间或显著性检验，而非只比大小。
统计动机能解释每个方法对应哪个统计假设、违背时会怎样。
工程可复现随机种子、版本、特征口径固定，结果可复跑。
衔接 readiness能说清「特征工程成为瓶颈」为何自然导向表示学习与深层网络。
