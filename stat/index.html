关于顺序的说明

本路线按「先掌握方法与训练范式，再深入网络结构与机制，最后进入生成式系统」的认知顺序组织。深度学习与神经网络互为表里：阶段四聚焦如何把深层模型训练好，阶段五拆解网络结构本身为何有效，因此顺序上先四后五。

如何使用本站

① 先看路线图与阶段页

先确定自己该从哪一阶段进入。每个阶段页都写清先修、难度、目标能力与可检验的评估标准——达标再进阶，避免盲目刷章节。

② 概念 → 公式 → 例题

专题章节沿用统一结构：直觉解释 → 严格定义 → 公式 → 分步例题 → 易错点 → 练习。例题解答默认折叠，先自己动笔再展开对照。

③ 用资源库与时间线校验

资源库可按类型、阶段、年代、核验状态筛选；时间线按时间与阶段筛选。所有外部链接指向官方一手来源，年份与出处不确定者明确标为待核验。
