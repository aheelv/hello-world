03 · 概率论基础

概率是描述「不确定性有多大」的通用语言。从明天会不会下雨，到医学检测是否可信， 再到 AI 模型输出的 0.97 是什么意思，背后都是同一套运算规则。 本模块只用初中代数，建立样本空间、条件概率、独立性与贝叶斯的完整工具箱—— 这些规则直觉上常常是反的，务必用例子把它们钉死。

入门 8 学时 前置：模块 01–02，初中代数 阶段一 · 入门筑基
学习目标
  • 写出简单试验的样本空间与事件，用组合数 $\binom{n}{k}$ 算古典概型
  • 说清概率三条公理，理解频率稳定于概率（大数定律直觉）
  • 熟练运用并、交、补、互斥、对立与加法法则
  • 掌握条件概率与乘法法则，彻底分清「互斥」与「独立」
  • 用全概率公式与贝叶斯公式解决检测类问题，看穿基础比率谬误
  • 计算期望 $E(X)$、方差 $Var(X)$，并用线性性质化简 $E(aX+b)$、$Var(aX+b)$

1 · 随机试验、样本空间与概率

1.1 基本词汇

  • 随机试验（Random experiment）：事先不能确定结果、且可重复进行的过程。如掷一枚骰子、抽一名用户、观测明天气温。
  • 样本空间 $\Omega$（Sample space）：试验所有可能结果的集合。
  • 样本点 $\omega$：$\Omega$ 中的单个结果（如「掷出 3 点」）。
  • 事件 $A$（Event）：样本空间的子集，即「某些结果的集合」（如「点数为偶数」$\{2,4,6\}$）。事件发生 = 试验结果落在该子集内。
直觉：样本空间是「舞台」，事件是「剧情」

概率的所有讨论都相对于某个样本空间。「明天是否下雨」的样本空间是 $\{\text{下雨}, \text{不下雨}\}$；若细化为 $\{\text{晴}, \text{多云}, \text{小雨}, \text{大雨}\}$，同一个问题的概率数字会变化。定义样本空间是建模的第一步。

1.2 频率与概率：大数定律直觉

在相同条件下重复试验 $n$ 次，事件 $A$ 发生 $m$ 次，则频率为 $m/n$。频率会随试验波动，但试验次数极多时会稳定下来：

大数定律（直觉形式）
$$ \bar{f}_n(A) = \frac{m}{n} \ \xrightarrow[\ n \to \infty\ ]{}\ P(A) $$
频率稳定值就是概率 $P(A)$。抛硬币 10 次可能 7 次正面，抛 10000 次几乎必然接近 50%。这是「用频率估计概率」（也是机器学习中用经验频率拟合分布）的理论根据。

1.3 概率的三条公理

1933 年柯尔莫哥洛夫把概率严格化为三条公理。设 $A$、$A_i$ 为事件：

  1. 非负性：$P(A) \geq 0$；
  2. 规范性：$P(\Omega) = 1$（必然事件概率为 1）；
  3. 可列可加性：若 $A_1, A_2, \dots$ 两两互斥（不能同时发生），则
可列可加性
$$ P\left(\bigcup_{i=1}^{\infty} A_i\right) = \sum_{i=1}^{\infty} P(A_i) \qquad (\text{当 } A_i \cap A_j = \varnothing,\ i \neq j) $$
由此可推出：$P(\varnothing) = 0$、$0 \leq P(A) \leq 1$、$P(A^c) = 1 - P(A)$（补事件公式，解题利器）。

1.4 古典概型：等可能情形

当样本空间有限且每个样本点等可能时，概率就是「数个数」：

古典概型
$$ P(A) = \frac{|A|}{|\Omega|} = \frac{\text{A 包含的样本点数}}{\text{样本点总数}} $$
只适用于等可能假设成立的情形。「数个数」常用排列组合：不计顺序的取法用组合数 $\binom{n}{k} = \frac{n!}{k!(n-k)!}$。
例 1.1 掷两枚骰子：样本空间与点数和

同时掷两枚均匀骰子。求（a）样本点总数；（b）点数和为 7 的概率；（c）点数和为 8 的概率。

查看解答

（a）每枚骰子 6 种结果，由乘法原理 $|\Omega| = 6 \times 6 = 36$（把结果写成有序对 $(i,j)$）。

（b）点数和为 7 的组合：$(1,6),(2,5),(3,4),(4,3),(5,2),(6,1)$ 共 6 种，

$$ P(\text{和为 }7) = \frac{6}{36} = \frac{1}{6} \approx 16.7\% $$

（c）点数和为 8：$(2,6),(3,5),(4,4),(5,3),(6,2)$ 共 5 种，$P = 5/36 \approx 13.9\%$。

要点：样本空间写成有序对（区分「第一枚」「第二枚」）才能保证等可能。若错误地把「和」当作样本点（$\{2,3,\dots,12\}$ 共 11 个），会得到 $1/11$ 的错误答案——因为「和为 7」与「和为 8」并不等可能。

2 · 事件的运算与加法法则

2.1 并、交、补

  • 并（Union）：$A \cup B$ = 「$A$ 或 $B$ 至少一个发生」。
  • 交（Intersection）：$A \cap B$ = 「$A$ 与 $B$ 同时发生」。
  • 补（Complement）：$A^c$ = 「$A$ 不发生」。

2.2 互斥与对立

  • 互斥（Mutually exclusive）：$A \cap B = \varnothing$，两者不能同时发生。
  • 对立（Complementary）：更强的关系——$A$ 与 $B$ 互斥且必有一个发生，即 $B = A^c$（如「下雨」与「不下雨」）。

对立一定互斥，互斥不一定对立（「掷出 1 点」与「掷出 2 点」互斥，但可以掷出 3 点）。

2.3 加法法则

加法法则
$$ P(A \cup B) = P(A) + P(B) - P(A \cap B) $$
$P(A \cap B)$ 被加了两次，必须减掉一次。若 $A$、$B$ 互斥，则 $P(A \cap B) = 0$，公式简化为 $P(A \cup B) = P(A) + P(B)$。
易错点：「或」不是简单相加

「选修数学或物理的学生占多少」不能直接把两个百分比相加——两科都选的人会被数两遍。除非确认互斥，否则必须减去交集。反过来，把互斥误当独立（或反之）是概率题最常见的翻车点，见 3.4 节。

例 2.1 加法法则：从「至少满足其一」到互斥特例

（a）某电商平台 10000 名用户中，30% 下过单，20% 使用过优惠券，其中 8% 两者都做过。求「至少做过一件」的比例，以及「只下单不用券」「只用券没下单」「两件都没做」的比例。
（b）掷一颗均匀骰子，$A$ =「点数为偶数」，$B$ =「点数大于 4」。求 $P(A \cup B)$，并说明 $A$ 与 $B$ 是互斥还是独立。

查看解答

（a）用加法法则，注意减掉交集：

$$ P(A \cup B) = P(A) + P(B) - P(A \cap B) = 0.30 + 0.20 - 0.08 = 0.42 $$

即 42% 的用户至少做过一件（对应 4200 人）。四个互不重叠的区域分别是：

  • 只下单不用券：$P(A \cap B^c) = P(A) - P(A \cap B) = 0.30 - 0.08 = 0.22$；
  • 只用券没下单：$P(A^c \cap B) = P(B) - P(A \cap B) = 0.20 - 0.08 = 0.12$；
  • 两件都没做：$P(A^c \cap B^c) = 1 - P(A \cup B) = 1 - 0.42 = 0.58$。

校验：$0.22 + 0.12 + 0.08 + 0.58 = 1.00$，四个区域正好把样本空间填满。常见错误是直接写 $0.30 + 0.20 = 0.50$——这会把「两者都做过」的 8% 重复计算一次，高估了 8 个百分点。

（b）先算交集，再套公式：点数为偶数是 $\{2,4,6\}$，$P(A) = 3/6 = 1/2$；点数大于 4 是 $\{5,6\}$，$P(B) = 2/6 = 1/3$；同时满足的是 $\{6\}$，$P(A \cap B) = 1/6$。

$$ P(A \cup B) = \frac{1}{2} + \frac{1}{3} - \frac{1}{6} = \frac{3 + 2 - 1}{6} = \frac{4}{6} = \frac{2}{3} $$

用补事件验证：「既不是偶数又不大于 4」只剩下 $\{1,3\}$，概率 $2/6 = 1/3$，所以 $P(A \cup B) = 1 - 1/3 = 2/3$。✓

互斥还是独立？$P(A \cap B) = 1/6 \neq 0$，说明掷出 6 点时两个事件同时发生，所以不互斥。再看独立性：$P(A)P(B) = \frac{1}{2} \times \frac{1}{3} = \frac{1}{6}$，恰好等于 $P(A \cap B) = 1/6$——按 $P(A \cap B) = P(A)P(B)$ 的判据，$A$ 与 $B$ 竟然独立。

这个结果值得停下来想一想，因为直觉上它们应该不独立：$B$ 发生意味着点数是 5 或 6，此时「偶数」发生的概率是 $1/2$（只有 6 是偶数）……听起来变小了？让我们用条件概率算一遍：

$$ P(A \mid B) = \frac{P(A \cap B)}{P(B)} = \frac{1/6}{1/3} = \frac{1}{2} = P(A) $$

果然一点没变！原因在于：$B$ 的两个结果 $\{5,6\}$ 里，恰好有一个是偶数——而 $A$ 本身也恰好覆盖 6 个点中的 3 个（一半）。「$B$ 发生后 $A$ 的概率」与「$A$ 本身的概率」都是 $1/2$，所以「知道 $B$ 发生」确实没有给 $A$ 带来任何新信息。同理 $P(B \mid A) = \frac{1/6}{1/2} = \frac{1}{3} = P(B)$。

这个「巧合」来自「偶数」这个分类恰好把 $\{5,6\}$ 中的 6 号点分给了两边，使得联合分布恰好等于边缘分布的乘积——这是小样本空间的特殊巧合，不是普遍规律。判定独立必须用数值验证，不能靠直觉（3.4 节的「互斥且概率为正必不独立」是必背的结论，但「不互斥」并不意味着「独立」）。

易错提示：① 「至少一个」直接相加而不减交集——这是加法法则最经典的翻车点；② 互斥与独立混用（把 $P(A \cap B) = 0$ 写成 $P(A)P(B)$）；③ 漏掉「都不满足」这一块，导致四块加起来不等于 1；④ 认为 $P(A \cap B) = 0$ 就一定是互斥（$P(A \cap B) = 0$ 也可能只是概率为 0 的巧合）；⑤ 把「至少一个」（并集）与「恰好一个」（对称差）搞混——「恰好一个」是 $P(A) + P(B) - 2P(A \cap B)$，本例为 $0.30 + 0.20 - 0.16 = 0.34$。

应用/AI 关联：「至少一个」在工程与 AI 中无处不在：推荐系统的覆盖率（至少被一个策略召回的用户占比）、模型评估中的至少命中一个缺陷类别的样本比例、用户行为的留存或付费（两件事做了任一即算留存）、以及 A/B 实验里「至少有一个指标显著」的判定。日常写代码时也常犯同一个错：把两个集合的size 直接相加来当并集大小，忘了减去交集——数据库里的 UNION 会自动去重，而 UNION ALL 不会，这个差异正是概率里的加法法则。

3 · 条件概率、乘法法则与独立性

3.1 条件概率

「已知某事件发生」会改变我们对另一事件的判断。设 $P(B) > 0$：

条件概率定义
$$ P(A \mid B) = \frac{P(A \cap B)}{P(B)} $$
竖线 $\mid$ 读作「在……发生的条件下」。直觉：把样本空间缩小到 $B$（新的分母是 $P(B)$），问其中有多大比例同时也属于 $A$。

3.2 乘法法则

把条件概率定义式两边同乘 $P(B)$，立刻得到：

乘法法则
$$ P(A \cap B) = P(A \mid B)\, P(B) = P(B \mid A)\, P(A) $$
求「同时发生」的概率 = 一路连乘。概率树（tree diagram）正是按这条规则一枝一枝乘出来的。

3.3 独立性

若「$B$ 是否发生」不影响「$A$ 的概率」，称 $A$、$B$ 独立（Independent）：

独立的定义与判据
$$ A \text{ 与 } B \text{ 独立} \iff P(A \cap B) = P(A)\, P(B) $$
等价表述：$P(A \mid B) = P(A)$（且 $P(B) > 0$）。判定独立不能靠感觉，要用数据或机制（如放回抽样）验证。

3.4 互斥 vs 独立：必须讲透的一对概念

对比互斥独立
含义不能同时发生一个是否发生不影响另一个
数学表达$P(A \cap B) = 0$$P(A \cap B) = P(A)P(B)$
知道 $B$ 发生后$P(A \mid B) = 0$$P(A \mid B) = P(A)$
典型例子一次投掷「出 1 点」与「出 2 点」两次独立抛硬币「都是正面」
关键结论：互斥且概率都为正的两个事件，必然不独立

若 $A$、$B$ 互斥且 $P(A) > 0$、$P(B) > 0$，则 $P(A \cap B) = 0 \neq P(A)P(B) > 0$。直觉上更好记：互斥是「一发生另一个就不可能」，独立是「一个发生另一个完全不受影响」——两者正相反，绝不可以混用。考试高频陷阱：把「互不相容」当成「相互独立」而写成 $P(A \cap B) = P(A)P(B)$。

例 3.1 判断独立还是互斥（三小问）

（a）连抛两次均匀硬币，$A$ =「第一次正面」，$B$ =「第二次正面」；
（b）袋中 3 红 2 白，不放回连抽两球，$A$ =「第一球红」，$B$ =「第二球红」；
（c）一颗骰子，$A$ =「出 1 点」，$B$ =「出 2 点」。分别判断 $A$、$B$ 是独立还是互斥。

查看解答

（a）独立且不互斥。$P(A) = P(B) = 1/2$，$P(A \cap B) = 1/4 = 1/2 \times 1/2$。第一次的结果不改变第二次的概率（可同时发生：两次都是正面）。

（b）不独立、也不互斥。$P(A) = 3/5$；$P(A \cap B) = \frac{3}{5}\times\frac{2}{4} = \frac{3}{10} = 0.3$（不放回，第二球概率已被第一次影响）。若独立应有 $(3/5)^2 = 0.36 \neq 0.3$，故不独立。两球可同为红，故不互斥。

（c）互斥且不独立。一次投掷不可能既是 1 点又是 2 点，$P(A \cap B) = 0$；而 $P(A)P(B) = 1/36 \neq 0$，故不独立。这正是「互斥 ⇒ 不独立」的典型。

例 3.2 链式法则与独立性判定：把三个事件串起来

某内容平台做用户调研，定义三个事件：$A$ =「用户点击了推荐内容」，$B$ =「用户此前有活跃行为」，$C$ =「用户完成了观看」。已知：

  • $P(A) = 0.60$（60% 的用户点击了推荐内容）；
  • $P(B \mid A) = 0.40$（点击的用户中 40% 此前有活跃行为）；
  • $P(B \mid A^c) = 0.05$（没点击的用户中只有 5% 此前有活跃行为）；
  • $P(C \mid B) = 0.70$（此前有活跃行为的用户中 70% 完成观看）；
  • $P(C \mid B^c) = 0.10$（此前无活跃行为的用户中 10% 完成观看）。

求：（a）$P(A \cap B)$ 与 $P(B)$；（b）$P(A \mid B)$，并判断 $A$ 与 $B$ 是否独立；（c）$P(A \cap B \cap C)$ 与 $P(C)$。

查看解答

第 1 步 用乘法法则算交集：

$$ P(A \cap B) = P(B \mid A)\, P(A) = 0.40 \times 0.60 = 0.24 $$

第 2 步 用全概率公式算 $P(B)$（这里 $A$ 与 $A^c$ 构成一个划分）：

$$ P(B) = P(B \mid A)P(A) + P(B \mid A^c)P(A^c) = 0.40 \times 0.60 + 0.05 \times 0.40 = 0.24 + 0.02 = 0.26 $$

第 3 步 求条件概率 $P(A \mid B)$：

$$ P(A \mid B) = \frac{P(A \cap B)}{P(B)} = \frac{0.24}{0.26} \approx 0.923 $$

第 4 步 判断独立性：用两种判据交叉验证。

  • 判据一（乘积判据）：$P(A \cap B) = 0.24$，而 $P(A)P(B) = 0.60 \times 0.26 = 0.156$。$0.24 \neq 0.156$ ⟹ 不独立。
  • 判据二（条件概率不变）：$P(A \mid B) \approx 0.923$，而 $P(A) = 0.60$。$0.923 \neq 0.60$ ⟹ 不独立。

两个判据结论一致，这正是它们的等价性。直观解释：「用户点了推荐」这件事，极大提高了「此前有活跃行为」的概率（从 60% 升到 92.3%）——反过来看，知道用户此前活跃，就能把他点击推荐的概率从 60% 上调到 92.3%。两者强正相关，绝不是独立事件。

第 5 步 三事件链式法则：

$$ P(A \cap B \cap C) = P(C \mid B)\, P(B \mid A)\, P(A) = 0.70 \times 0.40 \times 0.60 = 0.168 $$

这是「一枝一枝连乘」的直接应用：先算「$A$ 且 $B$」的概率，再乘上「在此基础上还发生 $C$」的条件概率。

第 6 步 求 $P(C)$：以 $B$ 与 $B^c$ 为划分用全概率公式。

$$ P(C) = P(C \mid B)P(B) + P(C \mid B^c)P(B^c) = 0.70 \times 0.26 + 0.10 \times 0.74 = 0.182 + 0.074 = 0.256 $$

交叉验证：$P(B \cap C) = P(C \mid B)P(B) = 0.70 \times 0.26 = 0.182$；于是 $P(B \mid C) = \frac{0.182}{0.256} \approx 0.711$，远高于 $P(B) = 0.26$——「完成观看」同样强烈暗示「此前有活跃行为」。

第 7 步 把样本空间完整拆成八格（深度校验）：先用 $A$ 与 $A^c$ 划分：$P(A \cap B) = 0.24$、$P(A \cap B^c) = 0.60 - 0.24 = 0.36$、$P(A^c \cap B) = 0.05 \times 0.40 = 0.02$、$P(A^c \cap B^c) = 0.40 - 0.02 = 0.38$。再对每一格按 $C$ 与 $C^c$ 细分：

一个必须点破的隐含假设：在 $A \cap B^c$ 那一格里，我用的是 $P(C \mid A \cap B^c) = 0.10$，这等于 $P(C \mid B^c)$。但严格来说，题面只给了 $P(C \mid B)$ 与 $P(C \mid B^c)$，它默认了「$C$ 的条件概率只取决于 $B$，与 $A$ 无关」（即 $C$ 与 $A$ 在给定 $B$ 后条件独立）。若这个假设不成立——比如「不点击的用户里，有活跃行为的人完成观看的比例远高于没活跃行为的人」——那么 $A^c \cap B \cap C$ 这一格就不能填 0.014，$P(C)$ 也就不能仅凭题面信息算出。

这是本例最重要的一课：全概率公式和链式法则都不是「自动成立」的公式，而是带着假设的工具。用之前要问一句：「我用的这个条件概率，真的只依赖于我划分时用的那个事件吗？」这与模块 01 里「混杂因素」的判断是同一件事——$A$ 之所以「不干扰」$C$ 的条件概率，正是因为 $A$ 不是 $B$ 与 $C$ 之间的混杂因素。

易错提示：① 用全概率公式时，选的划分必须穷尽且互斥，且每一格的条件概率必须是真实已知的——本例若 $P(C \mid A^c \cap B)$ 与 $P(C \mid B)$ 不同，$P(C)$ 就算不出来；② 判断独立时两个判据要交叉验证（$P(A \cap B) = P(A)P(B)$ 与 $P(A \mid B) = P(A)$），只用一个容易出错；③ 把 $P(A \mid B)$ 与 $P(B \mid A)$ 搞反（$0.923$ vs $0.40$），这是条件概率最常见的混淆；④ 链式法则中每个条件概率的分母要对准已经发生的那件事；⑤ 在分解样本空间时偷换假设——第 7 步之所以能填出八格，正是因为默认了「$C$ 的条件概率只取决于 $B$」；⑥ 把「不独立」误解为「负相关」——本例是强正相关。

应用/AI 关联：① 特征工程中的共线性诊断：「点击」和「此前活跃」高度相关（$P(A \mid B) = 0.92$），同时放进模型会导致系数不稳定——这就是共线性的概率学根源（模块 06 的 VIF）；② 漏斗分析：曝光 → 点击 → 完播的每一层转化率，正是链式法则 $P(\text{完播}) = P(\text{完播} \mid \text{点击}) \times P(\text{点击} \mid \text{曝光}) \times P(\text{曝光})$ 的直接应用；③ 归一化与校准：模型输出的概率只有在「联合分布 = 边缘分布乘积」时才是校准的，若训练数据有偏（各特征间存在依赖），模型就会系统性高估或低估——这正是贝叶斯公式与共形预测（模块 10）要解决的问题；④ A/B 实验：如果处理组和对照组在「用户此前活跃」这一基线特征上分布不同，实验结果就会被混杂污染（模块 08）。

4 · 全概率公式与贝叶斯公式

4.1 划分

设 $A_1, A_2, \dots, A_m$ 两两互斥，且它们的并是整个样本空间 $\Omega$，则称 $\{A_i\}$ 是一个划分（Partition）——把世界切成互不重叠、加起来完整的情形。

4.2 全概率公式

全概率公式
$$ P(B) = \sum_{i=1}^{m} P(B \mid A_i)\, P(A_i) $$
直觉：「$B$ 发生的总概率」= 按各种情形分别算再加权求和。像把一杯混合果汁按配方还原：每种果汁（$A_i$）占的比例 $\times$ 该果汁里含果肉的比例（$P(B|A_i)$）。

4.3 贝叶斯公式

把条件概率定义与全概率公式结合，就得到本课程最重要的公式之一：

贝叶斯公式
$$ P(A_i \mid B) = \frac{P(B \mid A_i)\, P(A_i)}{\displaystyle\sum_{j=1}^{m} P(B \mid A_j)\, P(A_j)} $$
记忆口诀：后验 = 似然 × 先验 ÷ 证据。$P(A_i)$ 是先验（看到证据前的判断），$P(B \mid A_i)$ 是似然（在 $A_i$ 下看到证据 $B$ 的可能性），$P(A_i \mid B)$ 是后验（看到证据后的更新判断），分母是证据 $P(B)$。
直觉：贝叶斯就是「用新证据改主意」

先验是旧认识，似然衡量「如果旧认识为真，新证据有多常见」，后验是更新后的认识。垃圾邮件过滤、医学诊断、AI 的概率校准、法庭上的 DNA 证据，全是这一条公式的应用。

4.4 基础比率谬误：为什么直觉会错

易错点：忽略先验（基础比率）

听到「检测准确率 90%」，多数人直觉认为阳性者「九成真的患病」。错在哪里？忽略了患病率（基础比率）本身极低。当健康人基数远大于病人时，即便假阳性率只有 5%，假阳性的绝对人数也会淹没真阳性。必须先算全概率（分母 $P(B)$），再算后验。

例 4.1 疾病检测：经典的贝叶斯算例

某病人群患病率 $1\%$。检测方法：患者呈阳性的概率（灵敏度）为 $90\%$，健康者呈阳性（假阳性率）为 $5\%$。若某人检测阳性，他真正患病的概率是多少？

查看解答

设 $D$ = 患病，$D^c$ = 健康，$+$ = 检测阳性。已知：$P(D) = 0.01$，$P(+ \mid D) = 0.90$，$P(+ \mid D^c) = 0.05$。

第 1 步 全概率算「阳性」的总概率：

$$ P(+) = P(+ \mid D)P(D) + P(+ \mid D^c)P(D^c) = 0.90\times 0.01 + 0.05\times 0.99 = 0.009 + 0.0495 = 0.0585 $$

第 2 步 贝叶斯算后验：

$$ P(D \mid +) = \frac{P(+ \mid D) P(D)}{P(+)} = \frac{0.009}{0.0585} = \frac{2}{13} \approx 15.4\% $$

第 3 步 用「10000 人表格」验证（推荐）：

585 个阳性者中只有 90 人真患病：$90/585 = 2/13 \approx 15.4\%$。直觉错在哪：人们盯着「灵敏度 90%」，却忘了健康人是病人的 99 倍——495 个假阳性在人数上压倒了 90 个真阳性。这就是基础比率谬误。

实践启示：罕见病筛查阳性后不要恐慌，应做更特异的复检（复检会大幅更新先验）；同理，AI 内容审核、欺诈检测中「高准确率模型」在低基率场景下也会产生大量误报。

例 4.2 挑战题：贝叶斯公式的多次更新（复检与翻案）

承接例 4.1。某病人群患病率 $P(D) = 1\%$，初检的灵敏度为 90%、假阳性率为 5%。初检阳性后，病人可以做一次更精确的复检（灵敏度 99%、假阳性率 1%）。请回答：

（a）初检阳性者中，真正患病的概率是多少？（b）若复检也阳性，此时真正患病的概率是多少？（c）若复检阴性呢？（d）为什么两次检测的组合会出现如此巨大的差别？

查看解答

第 1 步 初检阳性后的后验（回顾例 4.1）：

$$ P(+) = 0.90\times 0.01 + 0.05 \times 0.99 = 0.009 + 0.0495 = 0.0585 $$ $$ P(D \mid +) = \frac{0.009}{0.0585} = \frac{2}{13} \approx 15.4\% $$

第 2 步 复检也阳性：把复检当作新的证据，更新后验。现在把「已经初检阳性」当作已知条件（此时患病的后验是 15.4%），再套一次贝叶斯公式：

$$ P(D \mid +,+) = \frac{P(+ \mid D)\, P(D \mid +)}{P(+ \mid D)\, P(D \mid +) + P(+ \mid D^c)\, P(D^c \mid +)} = \frac{0.99 \times 0.153846}{0.99 \times 0.153846 + 0.01 \times 0.846154} $$ $$ = \frac{0.152308}{0.152308 + 0.008462} = \frac{0.152308}{0.160769} \approx 94.7\% $$

第 3 步 用「10000 人表格」验证（推荐用这个方法自查）：

人群人数初检阳性复检阳性（灵敏度 99% / 假阳性 1%）
患病（1%）1009089.10
健康（99%）99004954.95
合计1000058594.05

复检阳性者共 94.05 人，其中真患病 89.10 人：$89.10/94.05 \approx 94.7\%$ ✓ 与公式结果一致。

第 4 步 复检阴性：

$$ P(- \mid D, +) = 1 - 0.99 = 0.01, \qquad P(- \mid D^c, +) = 1 - 0.01 = 0.99 $$ $$ P(D \mid +, -) = \frac{0.01 \times 0.153846}{0.01 \times 0.153846 + 0.99 \times 0.846154} = \frac{0.001538}{0.001538 + 0.837692} = \frac{0.001538}{0.839231} \approx 0.18\% $$

表格验证：初检阳性的 585 人中，真患病 90 人里复检阴性 $90 \times 0.01 = 0.9$ 人；假阳性 495 人里复检阴性 $495 \times 0.99 = 490.05$ 人，共 490.95 人复检阴性，其中真患病仅 0.9 人：$0.9/490.95 \approx 0.18\%$ ✓

第 5 步 顺序更新法（更简洁的算法）：贝叶斯更新可以反复迭代——每次拿到新证据，就用当前后验当作下一次的先验：

  • 初始先验：$p_0 = 1\%$；
  • 初检阳性后：$p_1 = \frac{0.90 \times 0.01}{0.90 \times 0.01 + 0.05 \times 0.99} = 15.4\%$；
  • 复检阳性后：$p_2 = \frac{0.99 \times 0.153846}{0.99 \times 0.153846 + 0.01 \times 0.846154} = 94.7\%$。

注意 $p_1$ 既扮演「初检的后验」，又扮演「复检的先验」——贝叶斯更新就是这样一棒接一棒地推下去的（模块 07 会系统展开这个框架）。

第 6 步 为什么会差这么多？关键在「似然比」。把贝叶斯公式改写成优势比（odds）的形式就一目了然：

$$ \frac{P(D \mid E)}{P(D^c \mid E)} = \frac{P(E \mid D)}{P(E \mid D^c)} \times \frac{P(D)}{P(D^c)} $$

先验优势比 $\frac{0.01}{0.99} \approx 0.0101$。

  • 初检的似然比 $= \frac{0.90}{0.05} = 18$：$0.0101 \times 18 \approx 0.182$，转回概率 $\approx 15.4\%$。似然比 18 看着大，但乘上极小的先验优势比后仍然很小——基础比率在起作用。
  • 复检的似然比 $= \frac{0.99}{0.01} = 99$：$0.182 \times 99 \approx 18.0$，转回概率 $\approx 94.7\%$。这次似然比足够大，一举扭转了局面。
  • 复检阴性的似然比 $= \frac{0.01}{0.99} \approx 0.0101$：$0.182 \times 0.0101 \approx 0.00184$，转回概率 $\approx 0.18\%$。阴性证据的似然比远小于 1，等于强力地把概率往 0 推。

结论：复检之所以能把 15.4% 拉到 94.7%，是因为复检的灵敏度与假阳性率都远优于初检（似然比 99 vs 18）；而复检阴性之所以能把概率压到 0.18%，是因为「患病却复检阴性」的概率极低（1%），这 1% 的灵敏度损失是极其有力的反向证据。

易错提示：① 把「复检阳性」当成新的独立事件重新从头算（那样会用 1% 的原始患病率，得出 $0.99\times 0.01/(0.99\times 0.01 + 0.01\times 0.99) = 50\%$，错得离谱）——第二次检测必须用第一次的后验作为先验；② 复检阴性就完全排除患病（0.18% 虽低但非 0，且这里假设两次检测结果相互独立，若同一次采血同时做两项检测则不独立）；③ 认为「复检阳性 = 确诊」（94.7% 仍不是 100%，且这里假设检测在技术上无系统性偏差）；④ 忽略检测本身的假阳性率——本例复检的假阳性率只有 1%，如果复检设计得同样粗糙（假阳性 5%），似然比仍是 18，效果就会小得多；⑤ 假设两次检测相互独立——若两次检测存在同源偏差（如同一批试剂、同一操作者），似然比会被高估。

应用/AI 关联：① 多轮标注与仲裁：多个标注员逐条标注并逐轮修正，等价于这里的多次贝叶斯更新——每一轮用上一轮的后验作为先验，用本轮标注者的可靠性（似然比）更新；② 垃圾邮件过滤：先按「含关键词」粗筛（弱证据，似然比小），再用贝叶斯分类器给出更精细的似然比（如「发件人是否在通讯录」「链接是否短链」），联合起来才能把后验推高；③ 医学影像 AI 辅助诊断：模型输出的「恶性概率」不是终点，而是需要与影像科医生判断做贝叶斯组合的证据之一——关键同样是似然比（模型在良恶性上的区分能力）与基础比率（该科室的患病率）；④ LLM 自我改进：用模型自己的输出作为反馈信号时，若反馈来自的分布与目标分布不同，会把后验推向错误方向——这正是分布偏移在概率层面的表现（模块 10）。

5 · 期望、方差与协方差

5.1 期望

期望（expectation）是随机变量的概率加权平均——长期重复试验的平均结果：

离散型随机变量的期望
$$ E(X) = \sum_{k} x_k \, P(X = x_k) $$
对所有可能取值 $x_k$ 求和。连续型对应积分 $E(X) = \int x f(x)\,dx$（模块 04）。期望可以不是任何实际取值（如「期望点数 3.5」）。

5.2 方差

方差
$$ Var(X) = E\left[(X - \mu)^2\right] = E(X^2) - [E(X)]^2 $$
$\mu = E(X)$。方差衡量取值围绕期望的波动，单位是原单位的平方；标准差 $\sigma = \sqrt{Var(X)}$ 与原单位一致。右侧的计算式通常更易算。

5.3 期望与方差的性质

线性性质
$$ E(aX + b) = a\,E(X) + b, \qquad Var(aX + b) = a^2\, Var(X) $$
$a$、$b$ 为常数。注意方差对平移不敏感（加常数 $b$ 不改变波动），缩放 $a$ 倍则方差变为 $a^2$ 倍。
两个随机变量
$$ E(X + Y) = E(X) + E(Y), \qquad Var(X + Y) = Var(X) + Var(Y)\ \ (\text{当 } X, Y \text{ 独立}) $$
期望对任意 $X,Y$ 都可加；方差只有独立时才可加。一般情形：$Var(X+Y) = Var(X) + Var(Y) + 2Cov(X,Y)$。

5.4 协方差

协方差
$$ Cov(X, Y) = E\left[(X - E(X))(Y - E(Y))\right] = E(XY) - E(X)E(Y) $$
$Cov(X,Y) > 0$ 同向变动，$< 0$ 反向变动。若 $X,Y$ 独立，则 $Cov(X,Y) = 0$（反之不成立：不相关未必独立）。相关系数是标准化后的协方差（模块 02）。
例 5.1 求期望、方差，并化简 $E(3X-2)$、$Var(2X+5)$

随机变量 $X$ 的分布为 $P(X=0)=0.2$，$P(X=1)=0.5$，$P(X=2)=0.3$。求 $E(X)$、$Var(X)$，以及 $E(3X-2)$、$Var(2X+5)$。

查看解答

第 1 步 期望：

$$ E(X) = 0\times 0.2 + 1\times 0.5 + 2\times 0.3 = 1.1 $$

第 2 步 二阶矩：

$$ E(X^2) = 0^2\times 0.2 + 1^2\times 0.5 + 2^2\times 0.3 = 1.7 $$

第 3 步 方差：

$$ Var(X) = E(X^2) - [E(X)]^2 = 1.7 - 1.1^2 = 1.7 - 1.21 = 0.49 $$

第 4 步 用性质化简：

$$ E(3X - 2) = 3\times 1.1 - 2 = 1.3 $$ $$ Var(2X + 5) = 2^2 \times Var(X) = 4 \times 0.49 = 1.96 $$

要点：平移（$-2$、$+5$）影响期望但不影响方差；缩放使方差乘以系数的平方。常见错误是写成 $Var(2X+5) = 2 Var(X)$。

关键观察：两种抽样方式的期望完全相同（都是 0.8），但方差不同（0.4267 vs 0.48）。为什么？

  • 期望只取决于边际概率：不论放不放回，每一球是红球的概率都是 0.4，两球红球数的期望自然都是 $2 \times 0.4 = 0.8$。
  • 方差取决于两球是否独立：不放回时，抽走一个红球会降低第二球为红的概率（$P(\text{第二球红} \mid \text{第一球红}) = 3/9 < 0.4$），两球负相关，这会「对冲」掉一部分波动，使总方差变小。

用协方差精确验证：令 $X_1, X_2$ 分别指示第一、二球是否为红。两种方式下 $Var(X_1) = Var(X_2) = 0.4 \times 0.6 = 0.24$。

易错提示：① 不放回抽样时套用二项分布——二项分布要求独立且概率不变，不放回时第二球概率会变，正确的分布是超几何分布（本例 $P(X=1) = \frac{8}{15} \approx 0.533$ 而二项给出 $0.48$，差别明显）；② 把「不放回」和「放回」的期望记混（两者期望确实相同，但方差不同，容易误以为完全一样）；③ 计算方差时直接用 $Var(X_1 + X_2) = Var(X_1) + Var(X_2)$ 而忘了不独立时要加 $2Cov$ 项；④ 把 $Var(aX+b)$ 写成 $a\,Var(X)$（忘了平方）；⑤ 混淆「一次抽 2 球」与「抽 2 次各 1 球」——前者 2 次抽取不独立，后者若每次放回则独立；⑥ 用 $E(X^2) - [E(X)]^2$ 时把 $E(X^2)$ 算成 $E(X)^2$（前者是平方的期望，后者是期望的平方，一般不等）；⑦ 忘记 $Var$ 不可加的例外：独立才可加。

应用/AI 关联：① 小样本上的 softmax / 采样：从 10 个候选中不放回抽 2 个（top-2 采样）与放回抽 2 次，期望相同但方差不同——放回版本会重复选中同一个候选，导致结果分布「过于集中」，这就是需要在采样时加温度或用 Gumbel top-k 修正的原因；② 训练集构造：从标注池中「不放回」抽样本 vs 「放回」（bootstrap）抽样，后者会使部分样本被重复抽取、另一些缺席，直接影响集成模型（bagging）的误差结构；③ 模型评估中的多轮采样：LLM 用温度 $\tau > 0$ 生成 $n$ 个样本时本质是放回式的独立重复，方差随 $n$ 缩小——这正是自洽性（self-consistency）方法有效的原因；④ 有限总体校正因子：不放回抽样时标准误要乘 $\sqrt{\frac{N-n}{N-1}}$，本例即 $\sqrt{\frac{10-2}{10-1}} = \sqrt{\frac{8}{9}} \approx 0.943$——抽得越多，这个校正越接近 1（抽完全体时方差为 0），而在 AI 领域「用尽整个池子」与「反复抽同一池子」的区别正是模块 08 中「探索/利用」权衡的具体体现。

例 6.1 抽球问题：用组合数算古典概型

袋中有 5 个红球、3 个白球，除颜色外完全相同。从中一次随机取出 3 个（不放回），求恰好取到 2 红 1 白的概率。

查看解答

第 1 步 分母：从 8 个球中任取 3 个的等可能取法共 $\binom{8}{3} = \frac{8\times 7\times 6}{3\times 2\times 1} = 56$ 种。

第 2 步 分子：从 5 红中取 2 个有 $\binom{5}{2} = 10$ 种，从 3 白中取 1 个有 $\binom{3}{1} = 3$ 种，由乘法原理共 $10 \times 3 = 30$ 种。

第 3 步 相除：

$$ P(\text{2 红 1 白}) = \frac{\binom{5}{2}\binom{3}{1}}{\binom{8}{3}} = \frac{10 \times 3}{56} = \frac{30}{56} = \frac{15}{28} \approx 53.6\% $$

对比（逐个取的乘法视角）：「红红白」顺序概率 $\frac{5}{8}\times\frac{4}{7}\times\frac{3}{6}$，而 2 红 1 白有「红红白、红白红、白红红」3 种顺序，合计 $3\times\frac{60}{336} = \frac{180}{336} = \frac{15}{28}$——两种方法结果一致。组合数法把顺序打包，更不易漏。

例 6.2 全概率 + 贝叶斯：产品来自哪个车间

某厂两个车间产量分别占 60% 与 40%，次品率分别为 2% 与 5%。（a）随机抽一件产品，是次品的概率？（b）若抽到次品，它来自一车间的概率？

查看解答

设 $A_1$、$A_2$ 为「来自一/二车间」，$D$ =「次品」。已知 $P(A_1)=0.6$，$P(A_2)=0.4$，$P(D \mid A_1)=0.02$，$P(D \mid A_2)=0.05$。

（a）全概率公式：

$$ P(D) = 0.02\times 0.6 + 0.05\times 0.4 = 0.012 + 0.02 = 0.032 $$

（b）贝叶斯公式：

$$ P(A_1 \mid D) = \frac{P(D \mid A_1)P(A_1)}{P(D)} = \frac{0.012}{0.032} = 0.375 $$

解读：虽然一车间次品率更低（2% < 5%），但因产量占比大，次品中仍有 37.5% 来自一车间。若二车间产量占比升到 80%，后验会明显转向二车间——先验（产量构成）在贝叶斯推理中始终起作用。

深度专题一 · 基础率谬误：为什么「99% 准确」的检测仍会大量误报

DEEP 01

把阳性预测值写成基础率的函数，并解出可用的阈值

对应本章第 3 节（#s3）「条件概率为什么不能互换」与第 4 节（#s4）「全概率公式如何拆分」，并回答本章提问「基础率极低时，为什么高灵敏度的检测仍会产生大量误报」。正文例 4.1 已用患病率 1%、灵敏度 90%、假阳性率 5% 算出后验 15.4%，例 4.2 讲了复检与似然比；这里换一组更极端的数字，把结论写成一般函数与可操作的阈值公式。

背景：一个让医生也翻车的问卷

1978 年 Casscells 等人给哈佛医学院的学生与医生出了一道题：某病患病率 $1/1000$，检测对患者 100% 阳性、对健康人仍有 5% 假阳性，问「检测阳性者真患病的概率」。多数人答 95%，正确答案约 2%。此后 Gigerenzer 等人用「自然频数」（把概率改写成「1000 人里有几人」）反复证明：只要把数字换成人数，错误率大幅下降。问题不在算术，而在人们默认把 $P(+\mid D)$ 当成了 $P(D\mid +)$，并且忽略了那个极小的先验。

正文已经演示过一次（15.4%），本专题要再推一步：即便把检测做到「灵敏度 99%、特异度 99%」这种近乎完美的水平，只要基础率足够低，阳性里绝大多数仍会是误报。这不是检测不行，是乘法结构决定的。

直觉（先不用公式）

「检测准确率 99%」听起来像是「阳性者九成九真患病」，但这句广告词其实混了两个方向的概率：它说的是病人有多大概率被检出、健康人有多大概率被误报；你真正想要的是反过来那个——阳性的人里有多大比例真患病。方向一反过来，中间就隔着一个基础率。

打个比方：在一百万粒白沙里找一粒红沙，筛子再准，只要它每筛一百粒白沙就误留一粒，漏进来的白沙也是一万粒，远多过那一粒红沙。病人极少、健康人极多时，健康人的巨大基数乘以一个很小的假阳性率，乘出来的人数照样淹没真阳性。所以提高灵敏度（别漏掉红沙）帮助有限，提高特异度（别误留白沙）才是关键——因为它直接缩小那个巨大的乘数。

于是「这个检测准不准」根本没有唯一答案：必须连同「在什么样的人群里用」一起回答。同一个检测，在专科门诊（基础率高）很可靠，在全民筛查（基础率极低）就会制造海量误报。

形式化

记号：$D$ = 患病，$D^c$ = 健康，$+$ = 检测阳性。基础率（患病率）$p=P(D)$，灵敏度 $Se=P(+\mid D)$，特异度 $Sp = P(-\mid D^c)$，假阳性率 $FPR = 1 - Sp$。下面每个公式配一句白话。

全概率：所有阳性从哪来
$$ P(+) = Se\cdot p + (1-Sp)(1-p) $$
白话：阳性总数 = 病人里被检出的（真阳性）+ 健康人里被误报的（假阳性）；第二项里 $(1-p)$ 是健康人的巨大占比。
贝叶斯：阳性预测值 PPV
$$ \mathrm{PPV} = P(D\mid +) = \frac{Se\cdot p}{Se\cdot p + (1-Sp)(1-p)} $$
白话：真阳性占全部阳性的比例。分子分母都含 $p$，但分母还额外挂着一个乘着 $(1-p)$ 的假阳性项；$p$ 越小，这一项越压倒分子。
优势比形式：基础率如何「压倒」检测
$$ \frac{P(D\mid +)}{P(D^c\mid +)} = \underbrace{\frac{Se}{1-Sp}}_{\text{似然比 } LR_+}\ \times\ \underbrace{\frac{p}{1-p}}_{\text{先验优势比}} $$
白话：后验优势比 = 似然比 × 先验优势比。检测只贡献一个乘数 $LR_+$，基础率贡献被乘的那个数；后者极小，乘积就仍然小。这也解释了正文例 4.2 里「似然比 18 看着大、乘上 0.0101 后仍然很小」。
可操作的阈值：阳性更可能是真病的条件
$$ \mathrm{PPV} \gt \tfrac12 \iff Se\cdot p \gt (1-Sp)(1-p) \iff p \gt \frac{1-Sp}{Se + 1 - Sp} $$
白话：解一次不等式就得到基础率的最低门槛。当 $Se=Sp=0.99$ 时门槛为 $0.01/1.00 = 0.01$，即患病率必须超过 1%，一次阳性才更可能是真病而非误报。

数值演示见代码实验 Part 1：$Se=Sp=0.99$ 给出 $LR_+=99$、先验优势比阈值 $0.010101$、患病率门槛 $0.010000$。表中 $p$ 从 $0.0001$ 升到 $0.5$，PPV 从 $0.009804$ 升到 $0.990000$；$p=0.01$ 时恰好 $0.500000$，逐位验证阈值；而 $p=0.001$（千分之一）时 PPV 只有 $0.090164$——约 91% 的阳性是误报，比正文例 4.1 的 15.4% 更极端。这说明「把灵敏度从 90% 提到 99%」并不能解决问题，真正起作用的是把假阳性率从 5% 压到 1%。

关键结论阳性预测值不是检测的固有属性，而是「检测性能 × 基础率」的联合结果：$P(D\mid +) = \dfrac{Se\,p}{Se\,p + (1-Sp)(1-p)}$。基础率通过先验优势比进入后验，且存在硬门槛 $p \gt \dfrac{1-Sp}{Se+1-Sp}$；低于门槛时，无论灵敏度多高，阳性里都是误报占多数。低基础率场景下，提升特异度比提升灵敏度有效得多。

边界条件：在基础率已知且稳定、灵敏度／特异度可从标定人群迁移到待筛人群（无谱偏倚 spectrum bias）、且多次检测相互独立的条件下，本结论成立；在待筛人群基础率与标定人群不同、两次检测同源相关（同批试剂、同一操作者）、或存在未观测亚群异质性的条件下，本结论不成立，应改用分层基础率下的贝叶斯更新、带协变量的 logistic 校准模型，或直接估计各亚群的条件概率，而不是套用单一的 $Se$／$Sp$。

深度专题二 · 独立 vs 互斥，以及「在什么条件下独立」

DEEP 02

两个几乎相反的概念，和一个必须说清的「给定谁」

对应本章第 2 节（#s2）「独立与互斥在什么条件下可能同时成立」与第 3 节（#s3）「条件概率为什么不能互换」。正文 2.2 / 3.4 节已给出「互斥且概率为正 ⇒ 必不独立」，并用骰子展示了「不互斥也可能独立」的巧合；这里补齐三处留白：两者究竟何时能共存、条件独立的严格定义、以及「边缘相关但给定 $Z$ 独立」的数值构造。

背景：一个高频混淆，以及它背后的因果结构

「互斥」（mutually exclusive）与「独立」（independent）是概率题里最常被互换的一对词，连教材都常要靠「必背结论」来压住。它们其实来自两种完全不同的提问：互斥问「能不能一起发生」，独立问「知道一个发生，会不会改变另一个的概率」。1933 年柯尔莫哥洛夫公理化之后，独立被定义为乘积关系，而互斥只是交集为空；二者的张力用一行代数就能讲清。

更深的留白是「条件独立」。正文例 3.2 第 7 步曾点破一个隐含假设：「$C$ 的条件概率只取决于 $B$，与 $A$ 无关」——那其实就是条件独立。把它写清楚，才能明白为什么全概率公式和链式法则不是自动成立的公式，而是带着假设的工具；这也正是模块 01 混杂因素在概率层面的对应物。

直觉（先不用公式）

互斥说的是「两件事不能一起发生」——一旦知道 A 发生，就能断定 B 绝不可能发生。这明明是 A 对 B 产生了最强的影响，怎么可能叫「毫无影响」？所以只要两件事都有可能发生（概率为正），互斥就一定不独立。唯一的例外是某件事概率为 0（几乎不会发生）：此时「不能一起发生」和「乘积相等」在数值上都是 0，两个定义可以同时满足，但这是退化情形，没有实际意义。

条件独立则要换个问法：「在什么条件下、相对哪个变量独立？」冰淇淋销量与溺水事故整体上高度相关，只是因为气温这个共同原因同时推高了两者；一旦把气温固定住（只看同为 35℃ 的日子），两者就互不相干了——这叫「给定气温条件独立」。反过来也成立：边缘上互不相干的两个变量，一旦以它们的共同结果作为条件（对撞结构），反而会表现出相关。所以「独立」永远不是一个可以默认的事实，而是需要写明条件集合、并用数据或机制验证的假设。

形式化

两个定义
$$ A\cap B = \varnothing \iff P(A\cap B) = 0, \qquad A \perp B \iff P(A\cap B) = P(A)P(B) $$
白话：互斥是「交集为空」；独立是「交集的概率恰好等于两个边缘概率的乘积」。前者是集合关系，后者是数值关系。
两者何时能同时成立
$$ P(A\cap B) = 0 \ \text{且}\ P(A\cap B) = P(A)P(B) \iff P(A) = 0 \ \text{或}\ P(B) = 0 $$
白话：两式同时成立，只能是至少一个事件概率为 0。只要 $P(A) \gt 0$ 且 $P(B) \gt 0$，就有 $P(A)P(B) \gt 0 = P(A\cap B)$，于是必定不独立——这正是正文 3.4 的必背结论，也精准回答了本章第 2 节的提问。
条件独立的严格定义
$$ A \perp B \mid Z \iff P(A\cap B\mid Z) = P(A\mid Z)\,P(B\mid Z) $$
白话：把样本空间缩小到「$Z$ 发生」之后，再在这个缩小后的空间里判定 A、B 是否独立。边缘独立与条件独立互不蕴含。
链式法则与条件独立带来的简化
$$ P(A\cap B\cap C) = P(A)\,P(B\mid A)\,P(C\mid A\cap B) $$ $$ C \perp A \mid B \ \Longrightarrow\ P(A\cap B\cap C) = P(A)\,P(B\mid A)\,P(C\mid B) $$
白话：一般情形要一路连乘；若已知「给定 $B$ 后 $C$ 与 $A$ 无关」，最后一项就能从 $P(C\mid A\cap B)$ 简写成 $P(C\mid B)$。正文例 3.2 第 7 步之所以能填满八格表，靠的正是这个假设；假设不成立时 $P(C)$ 就算不出来。
边缘相关、给定 $Z$ 却独立（共同原因）
$$ P(X{=}1,Y{=}1\mid Z{=}0) = 0.04 = 0.2\times 0.2, \qquad P(X{=}1,Y{=}1\mid Z{=}1) = 0.64 = 0.8\times 0.8 $$ $$ P(X{=}1,Y{=}1) = \tfrac12(0.04) + \tfrac12(0.64) = 0.34 \ \neq\ 0.25 = P(X{=}1)P(Y{=}1) $$
白话：两层内部都严格独立，合并后却出现相关。$Z$ 是同时影响 $X$ 与 $Y$ 的共同原因——这正是模块 01 混杂因素的概率版本，也说明「相关」本身并不足以判断机制。

数值演示见代码实验 Part 3：两层各 6000 人，层内 $X,Y$ 独立（$0.2\times0.2=0.04$、$0.8\times0.8=0.64$ 逐层精确成立），合并后 $P(X{=}1)=P(Y{=}1)=0.5$ 而 $P(X{=}1,Y{=}1)=0.34\neq0.25$，程序对三层分别打印 indep=True / True / False。不需要任何随机数，全部是整数计数，可逐格复核。

关键结论互斥且概率为正必定不独立；两者只在零概率事件上能共存。「独立」必须指明条件集合：给定 $Z$ 独立与边缘独立互不蕴含，共同原因会让「层内独立、合并相关」，对撞结构会让「边缘独立、条件相关」。因此全概率公式、链式法则与朴素贝叶斯都必须先声明所依赖的条件独立假设，再用分层列联表验证。

边界条件：在事件概率严格为正、且讨论无条件（边缘）独立时，「互斥 ⇒ 不独立」成立；在存在零概率事件、或改用条件独立（给定 $Z$）、或涉及对撞（collider）结构的条件下，本结论不成立，应改用条件独立判据 $P(A\cap B\mid Z)=P(A\mid Z)P(B\mid Z)$ 与链式法则逐项写出假设，并用分层列联表或因果图验证，而不是凭直觉套用乘积公式。

独立性从来不是可以默认的事实。下图是模块 05 的假设检验决策流程，它把「独立、正态性、方差齐性」明确列为前置假设条件，并要求任一条不成立时换用非参数或重抽样方法；本专题正是把其中「独立」这一条拆到最细粒度来审视。

经典算法详解 · 全概率公式与贝叶斯公式作为一套可照做的流程

本算法位于「建模 → 评估」链条的概率推理层：上游契约是「一组完备互斥的情形划分 + 每类情形下的条件概率」，下游契约是「归一化后的后验概率或优势比」，供模块 07 贝叶斯更新、模块 08 因果推断与模块 12 的分类器使用。

一、原理：先拆证据，再翻转条件

设 $A_1,\dots,A_m$ 是样本空间 $\Omega$ 的一个划分（两两互斥且并为全集），$B$ 是观测到的证据。全概率公式先按情形把 $B$ 拆开求和，贝叶斯公式再用这个和作分母把 $P(B\mid A_i)$ 翻转成 $P(A_i\mid B)$。

划分与全概率公式
$$ A_i\cap A_j = \varnothing\ (i\neq j),\qquad \bigcup_{i=1}^{m} A_i = \Omega $$ $$ P(B) = \sum_{i=1}^{m} P(B\mid A_i)\,P(A_i) $$
白话：把「$B$ 发生的总概率」按各种情形分别算出来再加权求和；划分必须穷尽且互不重叠，否则分母会漏项或重复。
贝叶斯公式
$$ P(A_i\mid B) = \frac{P(B\mid A_i)\,P(A_i)}{\displaystyle\sum_{j=1}^{m} P(B\mid A_j)\,P(A_j)} = \frac{P(B\mid A_i)P(A_i)}{P(B)} $$
白话：后验 = 似然 × 先验 ÷ 证据；分母「证据」正是全概率公式算出的 $P(B)$，它保证所有后验加起来等于 1。
优势比形式与序贯更新
$$ \frac{P(A_i\mid B)}{P(A_i^c\mid B)} = \frac{P(B\mid A_i)}{P(B\mid A_i^c)}\times\frac{P(A_i)}{P(A_i^c)} $$
白话：每来一条证据，就把当前优势比乘上一个似然比；上一轮的后验直接充当下一轮的先验。正文例 4.2 的「初检阳性 → 复检阳性」用的就是这条迭代。

几何解释：把样本空间画成单位正方形，按划分 $A_i$ 切成若干竖条，条宽是 $P(A_i)$（先验）；每条里按 $P(B\mid A_i)$ 的比例涂色；涂色总面积就是证据 $P(B)$；第 $i$ 条里的涂色占全部涂色的比例，就是后验 $P(A_i\mid B)$。面积图一眼就能看出「基础率极小的竖条再怎么涂色，占总涂色的比例也大不了」。

二、编号步骤（可逐条照做）

  1. 写下目标方向。先明确要的是 $P(A\mid B)$ 还是 $P(B\mid A)$，并把两者分别写出来；方向上搞反是本节最高频的错误。
  2. 构造划分。列出 $A_1,\dots,A_m$，检查两两互斥、加起来穷尽；给每块标注先验 $P(A_i)$，并校验 $\sum_i P(A_i)=1$。
  3. 写似然。对每块给出 $P(B\mid A_i)$；确认它只依赖于该块。若有多条证据，必须先声明「给定类别后各证据条件独立」，否则不能连乘。
  4. 算证据。用全概率公式求 $P(B)=\sum_i P(B\mid A_i)P(A_i)$，顺手校验 $0\le P(B)\le 1$。
  5. 算后验。逐块代入 $P(A_i\mid B)=P(B\mid A_i)P(A_i)/P(B)$；分母对所有块相同，只需算一次。
  6. 双重校验。① 归一化：$\sum_i P(A_i\mid B)=1$；② 自然频数表：把概率改写成「$N$ 人里各有几人」，逐格数一遍复核。
  7. 敏感性与报告。改动先验或似然看重算后验，报告基础率的来源与不确定度；多条证据时做一次「似然比连乘 ↔ 后验」的闭环校验。

三、适用条件

  • 划分：完备且互斥；每块的先验可靠（或至少能做敏感性分析）。
  • 条件概率：来自与待推断对象同质的标定人群，灵敏度／特异度可迁移（无谱偏倚）。
  • 多条证据：需满足给定类别下的条件独立；否则朴素贝叶斯会重复计数，后验过度自信。
  • 数值：先验不能全为 0（否则后验恒为 0，无法被证据更新），似然不能同时为 0（否则分母为 0）。

四、复杂度（时间与空间）

估计（训练） 从 $N$ 条记录统计列联表 $O(N)$ 时间、$O(m)$ 空间（$m$ 为划分数）；推理（单次查询） 全概率求和 $O(m)$ + 逐块后验 $O(m)$，合计 $O(m)$；序贯 $T$ 轮 $O(mT)$；空间 仅存先验／似然／后验三个长度 $m$ 的向量，$O(m)$。

白话：这套流程本身极轻，成本几乎全在「从数据里把各条件概率统计出来」那一步；一旦表建好，每次推理只是几乘几加，适合在线实时更新。

五、优缺点

优点

  • 把「逆概率」问题化成一套四则运算，方向清晰、可手算、可复核。
  • 显式暴露先验，迫使分析者交代基础率来源，天然对抗基础率谬误。
  • 优势比形式支持序贯更新：新证据来了不必从头重算。
  • 归一化与「自然频数表」提供两道独立校验，工程上容易审计。
  • 复杂度 $O(m)$，可嵌入在线服务做实时概率校准。

局限

  • 结论对先验敏感；先验错（谱偏倚）时，证据再强也可能纠不回来。
  • 多条证据的条件独立假设常被违背，导致后验过度自信。
  • 划分块数 $m$ 大且数据稀疏时，$P(B\mid A_i)$ 估计极不稳定，需要平滑。
  • 只能给出「关联更新」，不能单独支持因果结论（需模块 08 的实验设计）。
  • 连续变量或高维特征下，$m$ 爆炸，必须改用参数化模型或共轭结构。

六、示例推演（手算到底）

用全站共用的知学云 2×2 表：按「每周学习时长高／低」划分，观察是否完课。四格计数为

$$ \begin{array}{c|cc} & \text{完课} & \text{未完课}\\ \hline \text{高时长} & 3939 & 2071 \\ \text{低时长} & 2028 & 3962 \end{array} $$

注意：这里用的是正文未出现的新算例（正文例题用的是疾病检测与车间次品），且所有数字与案例文件一致，可跨章对照。设 $A_1$ = 高时长、$A_2$ = 低时长、$B$ = 完课。

写出已知并校验划分。$N = 3939+2071+2028+3962 = 12000$；$n_{A_1} = 6010$，$n_{A_2}=5990$。$P(A_1)=6010/12000=0.500833$，$P(A_2)=5990/12000=0.499167$，两者之和 $=1$，且 $A_1\cap A_2=\varnothing$——划分合法。
写似然。$P(B\mid A_1)=3939/6010=0.655408$，$P(B\mid A_2)=2028/5990=0.338564$。二者差距明显，说明「学习时长」携带关于完课的信息。
全概率算证据。$P(B)=0.655408\times0.500833 + 0.338564\times0.499167 = 3939/12000 + 2028/12000 = 5967/12000 = 0.497250$，与案例 completed_rate = 0.49725 逐位一致。这里公式自然退化成「把完课人数数一遍」，正是全概率公式的正确性自检。
贝叶斯算后验。$P(A_1\mid B) = (3939/12000)/(5967/12000) = 3939/5967 = 0.660131$；$P(A_2\mid B)=2028/5967=0.339869$。
归一化校验。$0.660131+0.339869 = 1.000000$ ✓；用人数表复核：完课者共 5967 人，其中高时长 3939 人，占比 $3939/5967$，与公式一致。
方向对照（关键）。$P(B\mid A_1)=0.655408$ 而 $P(A_1\mid B)=0.660131$，数值接近但绝不相等。此处接近是因为基础率几乎 50%、两组规模几乎相等；换成深度专题一的低基础率场景，二者会差出几十倍（$p=0.001$ 时 $Se=0.99$ 而 PPV 仅 $0.0902$）。绝不能因为「看起来差不多」就混用。
优势比闭环校验。先验优势比 $P(B)/P(B^c)=5967/6033=0.989060$；似然比 $LR = P(A_1\mid B)/P(A_1\mid B^c) = (3939/5967)/(2071/6033) = 0.660131/0.343278 = 1.923017$；后验优势比 $=0.989060\times1.923017 = 1.901980$；转回概率 $=1.901980/2.901980 = 0.655408 = P(B\mid A_1)$ ✓，与第 2 步完全吻合。
顺带核对优势比 OR。$\mathrm{OR} = (3939\times3962)/(2071\times2028) = 3.7158$，$\ln\mathrm{OR}=1.3126$，$\mathrm{se}_{\ln\mathrm{OR}}=\sqrt{1/3939+1/2071+1/2028+1/3962}=0.0385$，三项都与案例 high_study_2x2 给出的 OR=3.7158、se=0.0385 一致。

import math

print("=== Part 1: 基础率决定阳性预测值（灵敏度=特异度=0.99） ===")
sens, spec = 0.99, 0.99
fpr = 1 - spec
print(" prevalence   P(+)       PPV=P(D|+)   1-PPV")
for p in [0.0001, 0.001, 0.01, 0.02, 0.05, 0.10, 0.50]:
    pp = sens*p + fpr*(1-p)
    ppv = sens*p/pp
    print("   %8.4f  %9.6f   %9.6f   %9.6f" % (p, pp, ppv, 1-ppv))
thr = fpr/(sens+fpr)
print(" PPV > 0.5 需要患病率 > %.6f  (= (1-spec)/(sens+1-spec))" % thr)
print(" 似然比 LR+ = sens/(1-spec) = %.2f ; 先验优势比阈值 = %.6f" % (sens/fpr, fpr/sens))

print()
print("=== Part 2: 全概率 + 贝叶斯（复用知学云 2x2：高/低学习时长 x 完课） ===")
a,b,c,d = 3939, 2071, 2028, 3962
n = a+b+c+d
p_high = (a+b)/n
p_low = (c+d)/n
p_c_given_high = a/(a+b)
p_c_given_low = c/(c+d)
p_comp = p_c_given_high*p_high + p_c_given_low*p_low
p_high_given_comp = p_c_given_high*p_high/p_comp
p_high_given_not = b/(b+d)
print(" 2x2 = [[%d,%d],[%d,%d]]  N=%d" % (a,b,c,d,n))
print(" P(high)=%.6f  P(low)=%.6f  P(complete|high)=%.6f  P(complete|low)=%.6f" % (p_high,p_low,p_c_given_high,p_c_given_low))
print(" LTP: P(complete)=%.6f = %d/%d" % (p_comp, a+c, n))
print(" Bayes: P(high|complete)=%.6f = %d/%d" % (p_high_given_comp, a, a+c))
print(" inverse: P(complete|high)=%.6f vs P(high|complete)=%.6f (不相等)" % (p_c_given_high,p_high_given_comp))
orv = (a*d)/(b*c)
print(" OR=(a*d)/(b*c)=%.4f  logOR=%.4f  se_logOR=%.4f" % (orv, math.log(orv), math.sqrt(1/a+1/b+1/c+1/d)))
prior_odds = (a+c)/(b+d)
lr = p_high_given_comp/p_high_given_not
post_odds = prior_odds*lr
print(" odds check: %.6f x %.6f = %.6f -> P=%.6f" % (prior_odds, lr, post_odds, post_odds/(1+post_odds)))

print()

show("Z=0 层内", Z0)

表格七行：$p=0.0001$ 时 $\mathrm{PPV}=0.009804$，即 1-PPV=0.990196——约 99% 的阳性是误报，尽管检测「99% 准确」；$p=0.001$ 时仍只有 $0.090164$（约 91% 误报）；$p=0.01$ 恰好 $0.500000$，逐位验证阈值；$p=0.5$ 时才升到 $0.990000$。P(+) 一列从 0.010098 升到 0.500000，说明低基础率下「阳性」几乎全部由假阳性贡献（$p=0.0001$ 时 $0.0099$ 的假阳性对 $0.000099$ 的真阳性）。这比正文例 4.1 的 15.4% 更极端，正是「提高特异度比提高灵敏度更有效」的数值证据。

Part 2 的 2x2：$[3939,2071,2028,3962]$ 即案例 high_study_2x2.table，$N=12000$ 与案例 n 一致。P(high)=0.500833、P(low)=0.499167 是划分的两块先验，和为 1；P(complete|high)=0.655408、P(complete|low)=0.338564 是两块似然。

LTP: 0.497250 = 5967/12000：全概率公式算出的证据，与案例 completed_rate=0.49725 逐位吻合；这里公式自然退化成「把完课人数数一遍」，是正确性自检。Bayes: 0.660131 = 3939/5967 是后验 $P(\text{高时长}\mid\text{完课})$；inverse 一行显示 $0.655408$ 与 $0.660131$ 接近却绝不相等——接近只是因为本例基础率几乎 50%，换成 Part 1 的低基础率场景二者会差出几十倍，这正是本章第 3 节「不能互换」的定量版。

OR=3.7158、logOR=1.3126、se_logOR=0.0385：与案例给出的 OR=3.7158、se=0.0385 一致，说明同一份数据在不同章节可对照。odds check：先验优势比 $0.989060$ 乘似然比 $1.923017$ 得后验优势比 $1.901980$，转回概率 $0.655408$ 恰等于 $P(\text{complete}\mid\text{high})$，构成「先验 → 证据 → 后验」的闭环校验；改动任一格计数，四个数会一起变，但闭环恒等式始终成立。

Part 3 三行 indep：$Z=0$ 层内 $0.0400 = 0.2\times0.2$、$Z=1$ 层内 $0.6400 = 0.8\times0.8$，两层都严格条件独立（True / True）；合并后 $P(X{=}1)=P(Y{=}1)=0.5$ 但 $P(X{=}1,Y{=}1)=0.3400 \neq 0.2500$（False）。两层人数各 6000、各格均为整数，可逐格复核，无需随机数。何时会变：若两层人数不等，合并的联合概率会随之改变；若在层内引入相关，两层的 indep 都会变成 False。这个构造说明「相关」本身无法区分「直接作用」与「共同原因」——与模块 01 的混杂是同一结构。

功能规格与工程边界

项目说明
功能说明把「已知 $P(B\mid A_i)$ 求 $P(A_i\mid B)$」化为一套可照做的流程：构造划分 → 列先验与似然 → 全概率算证据 → 贝叶斯算后验 → 归一化与频数表双重校验；不做因果识别、不做参数拟合、也不自动验证证据间的条件独立。
输入 / 输出输入：完备互斥的划分 $\{A_i\}$、先验 $P(A_i)$、似然 $P(B\mid A_i)$（均无量纲、取值 $[0,1]$）、可选的多轮证据；输出：证据 $P(B)$、后验 $P(A_i\mid B)$（和为 1）、后验优势比与每轮似然比。输出恒为概率，无量纲。
适用场景医学／质检筛查的阳性解读、垃圾邮件与欺诈检测、逆概率类问题（「高分学员更可能完课」反过来怎么算）、A/B 结果的贝叶斯解读、多轮标注仲裁、以及模块 07 的序贯更新与模块 12 朴素贝叶斯分类器。
关键参数先验 $P(A_i)$（基础率，最敏感，错则后验系统性偏移）；似然 $P(B\mid A_i)$（灵敏度／特异度，须来自同质标定人群）；划分数 $m$（越大越需平滑）；平滑系数（零格时避免后验恒为 0）；证据间条件独立假设（多条证据时决定能否连乘）。
边界条件在划分完备互斥、先验可靠、条件概率可迁移、且多条证据给定类别后条件独立时，本方法适用；在谱偏倚（标定人群与待筛人群基础率不同）、证据同源相关、先验全为 0、或似然同时为 0 的条件下不适用，应改用分层基础率下的贝叶斯更新、带协变量的 logistic 校准、或显式建模证据间的依赖结构。
常见问题① 把 $P(B\mid A)$ 直接当 $P(A\mid B)$；② 划分不穷尽导致分母漏项、后验和不为 1；③ 多条证据不做条件独立检验就连乘似然比；④ 复检时误用原始基础率当先验；⑤ 忽略患病率变化对 PPV 的影响。详见下方 FAQ。
$P(A\mid B)$ 和 $P(B\mid A)$ 什么时候数值很接近？可以互相代替吗？
当 $P(A)\approx P(B)$ 且两类的似然差别不大时会接近——代码 Part 2 里 $0.655408$ 与 $0.660131$ 只差约 $0.005$，就是因为基础率几乎 50%、两组人数几乎相等。但概念上永远不能代替：严格相等要求 $P(A)=P(B)$ 或似然恒等。换成 Part 1 的 $p=0.001$，$Se=0.99$ 而 PPV 只有 $0.0902$，差了十倍以上。任何时候先写下你要的方向（算法第 1 步）。
划分漏掉一种情形会怎样？
分母 $P(B)=\sum_i P(B\mid A_i)P(A_i)$ 会缺项，被低估；于是各后验 $P(A_i\mid B)$ 被系统性高估，且 $\sum_i P(A_i\mid B)$ 可能大于 1（若你只归一化已列出的块）。所以第 2 步必须显式校验「两两互斥 + 并为全集 + $\sum P(A_i)=1$」。实践中常见漏项是「其他／未知」这一类，务必单独留出一块。
两条证据能把似然比直接连乘吗？
只有在「给定类别后两条证据条件独立」时才可以。若两条证据同源相关（同一批试剂、同一标注员、同一段文本里的重复特征），连乘会把同一份信息数两遍，后验会过度自信（概率被推得过分接近 0 或 1）。这正是朴素贝叶斯的经典失效模式；正确做法是先做条件独立检验，或改用能表达依赖的结构（模块 07、12）。
复检阳性时，为什么不能用原始患病率当先验？
因为初检阳性已经把信息带进来了：此时人群不再是「全体」，而是「初检阳性者」，其患病率已更新为 15.4%（正文例 4.1）。序贯更新的规则是「上一轮后验充当下一轮先验」；若退回 1% 的原始基础率，会得出约 50% 的错误答案。优势比形式把这件事写得很清楚：每轮只是在当前优势比上再乘一个似然比，不会重置。
检测没变、只是筛查人群换了，PPV 会变吗？
会，而且可能剧烈变化，因为 PPV 是「检测 × 基础率」的联合结果。代码 Part 1 里同一组 $Se=Sp=0.99$，患病率从 $0.0001$ 到 $0.5$ 时 PPV 从 $0.0098$ 升到 $0.9900$。所以任何「准确率 99%」的宣传都必须附带适用人群的基础率；把专科门诊的指标直接搬到全民筛查，是谱偏倚的典型表现。

动笔练习
  1. 掷两枚均匀骰子，求（a）点数和为 7 的概率；（b）点数和为 8 的概率；（c）两枚骰子点数相同的概率。
  2. 设 $P(A) = 0.3$，$P(B) = 0.4$，$P(A \cap B) = 0.1$。求 $P(A \cup B)$、$P(A \mid B)$，并判断 $A$、$B$ 是否独立。
  3. 袋中 4 红 6 白，（a）放回连抽两球，两球都红的概率；（b）不放回连抽两球，两球都红的概率。两种情形下「第二次抽到红球」的概率是否都等于 0.4？说明含义。
  4. 某垃圾邮件过滤器：邮件中约 1% 是垃圾邮件；某关键词出现在 80% 的垃圾邮件、但只出现在 5% 的正常邮件中。收到一封含该关键词的邮件，它是垃圾邮件的概率？
  5. 已知 $E(X) = 5$，$Var(X) = 3$，求 $E(2X+1)$ 与 $Var(3X-4)$。若 $X, Y$ 独立且 $Var(Y) = 2$，求 $Var(X+Y)$。
查看答案与提示

1. 用 36 个等可能有序对。（a）和为 7：6 种，$6/36 = 1/6$；（b）和为 8：5 种，$5/36$；（c）相同：$(1,1),\dots,(6,6)$ 共 6 种，$6/36 = 1/6$。

2. $P(A \cup B) = 0.3 + 0.4 - 0.1 = 0.6$；$P(A \mid B) = 0.1/0.4 = 0.25 \neq P(A) = 0.3$，故不独立（也不互斥，因为交集概率非零）。

3. （a）放回：$0.4 \times 0.4 = 0.16$，此时两次独立；（b）不放回：$\frac{4}{10}\times\frac{3}{9} = \frac{12}{90} \approx 0.133$，不独立。放回时第二次抽到红球的概率恒为 0.4（不受影响）；不放回时第二次的无条件概率仍是 0.4（对称性），但条件概率会随第一次结果改变——这正是独立与不独立的差别所在。

4. 设 $S$ = 垃圾邮件，$K$ = 含关键词。$P(K) = 0.8\times 0.01 + 0.05\times 0.99 = 0.0575$，$P(S \mid K) = 0.008/0.0575 = 16/115 \approx 13.9\%$。仍是基础比率效应：绝大多数邮件是正常的，仅凭一个词不足以断定。

5. $E(2X+1) = 2\times 5 + 1 = 11$；$Var(3X-4) = 9\times 3 = 27$；$Var(X+Y) = 3 + 2 = 5$（独立）。

8 · 本章小结

概念要点
样本空间与事件事件是 $\Omega$ 的子集；古典概型 $P(A) = |A|/|\Omega|$（须等可能）
概率公理非负、规范、可列可加；推出 $P(A^c) = 1 - P(A)$
加法法则$P(A \cup B) = P(A) + P(B) - P(A \cap B)$；互斥时可直接相加
条件概率$P(A \mid B) = P(A \cap B)/P(B)$；乘法法则求「同时发生」
互斥 vs 独立互斥：不能同发生；独立：互不影响。互斥且概率为正 ⇒ 必不独立
全概率与贝叶斯全概率拆分求总概率；贝叶斯后验 = 似然 × 先验 ÷ 证据，警惕基础比率谬误
期望与方差$E(aX+b) = aE(X)+b$，$Var(aX+b) = a^2 Var(X)$；独立时 $Var(X+Y) = Var(X)+Var(Y)$
