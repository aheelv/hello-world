# 《穷查理宝典》实践三问法

本 Skill 基于公开书评与作者公开表达的原创综合，用于实践辅导，不是原著全文，也不替代购买与阅读正版图书。

## 用途

用多元思维模型、逆向思考与能力圈三层过滤，帮用户在复杂决策里先排除愚蠢，再谈收益

## 原则

1. 事实必须挂在模型上：孤立的记忆无法调用，先建多学科模型，再把经验挂上去
2. 一个学科解释一切，等于没有解释：同一个问题至少用三个不同学科的视角看一遍
3. 先问「怎么会失败」，再问「怎么能成功」：逆向思考的产出是一张负面清单
4. 把「太难」当作正式答案：能力圈的边界比面积重要，圈外不下重注
5. 把心理倾向做成检查表：激励、社会认同、避免不一致、被剥夺感，逐条过一遍
6. 生意质量优先于价格便宜：好生意的时间是朋友，差生意的时间是敌人

## 三个易翻车点

- 模型收集癖：读了一堆模型却从不用于具体决定，格栅退化成书单
- 逆向变成犬儒：只会论证「这事必败」，不给可执行的替代方案
- 能力圈自欺：把「听说过」当成「看得懂」，在圈外下重注

## 工作流

1. 把问题写成一句可判断的命题
2. 找出三个能用上的学科模型，各写一句解释
3. 反向列出「怎样保证失败」，形成负面清单
4. 判断是否在能力圈内，不在就归入「太难」
5. 过一遍心理倾向清单，标出最可能被触发的三条
6. 给出结论与「不做什么」，并写下验证信号

## 实践清单

- [ ] 挑一个你正在做的判断，写出它背后用了哪三个学科的模型；少于两个就先别下结论
- [ ] 把手上所有待办分进三个筐：能做、不能做、太难。把「太难」筐里的事正式划掉
- [ ] 对你最重要的一项投资或职业选择，列出三种最可能的失败方式，标出哪一种你无法承受
- [ ] 找一个人在你要判断的领域比你更懂，明确请他反驳你，并把他的话记下来
- [ ] 检查你最近一个结论背后的利益结构：如果结论成立，谁获益？包括你自己
- [ ] 为一项重大决定做一张「反过来想」清单：要保证这件事失败，我会怎么做
- [ ] 写下你能力圈的边界：三个你确实懂的领域，三个你以为懂但说不清的领域
- [ ] 选一家你持有的公司，判断它能否连续十年提价而不流失客户，写出理由
- [ ] 回顾一次你「跌倒后没有立刻起来」的经历，写出当时真正卡住的是什么
- [ ] 把每天的阅读固定成二十分钟，只读能提供模型的书，不做摘抄只写一句「这个模型能解释什么」
- [ ] 检查你最近一次公开表态：你现在还在为它辩护吗？如果是，找出你忽略的新证据
- [ ] 给自己定一条规则：任何超过月收入 30% 的支出或投入，必须隔 72 小时再决定

## 引用边界

- 「反过来想，总是反过来想」原为数学家雅可比的话，「诉诸利益而非理性」原为富兰克林的话；芒格是引用者，转引时不要归到他名下。
- 书中对学术界、对同行的批评属于芒格的个人立场与时代语境，不宜当作定论。
- 方法高度依赖长期跨学科阅读，不能简化为「只看几个模型就重仓」。
