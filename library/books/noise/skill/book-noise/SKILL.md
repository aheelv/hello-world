# 《噪声》实践三问法

本 Skill 基于公开书评与作者公开表达的原创综合，用于实践辅导，不是原著全文，也不替代购买与阅读正版图书。

## 用途

把「同案不同判」的随机差异测出来、拆开、再用决策卫生降下去，让判断更一致

## 原则

1. 误差分两种：偏差是瞄偏了，噪声是打散了，修法不同
2. 噪声可以测量：让多人独立判断同一批案例，比较离散度
3. 拆开三种成分：水平噪声、模式噪声、情境噪声，重点常在模式噪声
4. 用决策卫生预防：分解维度、独立判断、先写后议
5. 结构化替代自由叙述：固定问题、固定顺序、固定评分
6. 审查系统，不审查个人：一旦用于考核，数据立刻失真

## 三个易翻车点

- 把合理分歧当成噪声：目标本身多元时，差异可能是价值分歧
- 用打分代替排序：绝对刻度不稳定，相对排序更可靠
- 降噪降过头：规则吃掉例外，系统失去适应性

## 工作流

1. 选一个反复做的判断，写下现有标准
2. 取三个同类案例，请三人独立判断，不讨论
3. 比较结论差异，定位分歧最大的环节
4. 把判断拆成 4–6 个维度，写清评分标准
5. 改为「先独立写、再公开理由」，排序替代打分
6. 定期测量离散度，只公布系统结果

## 实践清单

- [ ] 选一个你反复做的判断（招人、评级、选题、审批），写下你通常依据的三条标准
- [ ] 找三个同类案例，请三位同事各自独立判断，不讨论，然后比较结论差异
- [ ] 把差异最大的那一项挑出来，问：是标准不清，还是理解不同
- [ ] 为这个判断做一张评分表：4–6 个维度，每维度写清「几分是什么样」
- [ ] 把「整体印象」改成「先分维度打分，再合成」，本周用一次
- [ ] 面试或评审前，规定所有人先独立写结论，再进入讨论
- [ ] 把绝对打分改成排序：先排出高低，再决定谁通过
- [ ] 记录你最近三次判断时的状态（睡眠、情绪、时间压力），看是否与结论松紧相关
- [ ] 为一个高频决策写出规则版：什么条件下自动通过，什么条件下必须人工复核
- [ ] 给你的团队做一次小规模噪声审查，只公布离散度，不公布个人得分
- [ ] 检查一次复盘：你是在评价决策过程，还是在评价结果
- [ ] 把一条「我觉得不合适」改写成三条可核查的证据，看它是否还站得住

## 引用边界

- 核心实证来自美国司法量刑、保险理赔与医疗诊断，这些场景有明确的「同案同判」标准。
- 在教育、创作、战略等目标本身多元的领域，判断差异可能不是噪声而是价值分歧，降噪前须确认「本应相同」成立。
- 噪声审查一旦被当作绩效考核会立刻失效：审查对象必须是系统而非个人。
