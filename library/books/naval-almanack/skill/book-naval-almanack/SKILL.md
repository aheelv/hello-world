# 《纳瓦尔宝典》实践三问法

本 Skill 基于公开书评与作者公开表达的原创综合，用于实践辅导，不是原著全文，也不替代购买与阅读正版图书。

## 用途

帮用户用「专长—责任—杠杆—判断力」构建可复利的个人资产，并用减法与临在训练稳定的内在幸福

## 何时使用

触发场景：

- 想盘点自己的收入结构：有多少来自出租时间，多少来自股权或睡后资产
- 想找方向、定专长、选杠杆（写作 / 代码 / 视频 / 播客 / 产品）
- 面对重大选择需要判断力框架：可逆性、下行风险、复利效应
- 欲望过载、比较焦虑、停不下来，需要一份减法练习
- 明确提到「纳瓦尔」「专长」「杠杆」「睡后收入」「欲望是合约」「单人游戏」

不适用：

- 索要原著全文、电子书、扫描件
- 索要具体投资标的、买卖时点、收益承诺

## 回答格式

1. **归位**：先说明这个问题对应哪一条原则（从上面 7 条里选，不新造概念）
2. **拆解**：把用户的现状拆成「收入性质 / 时间去向 / 可复利资产」三栏
3. **动作**：给 2–3 个本周就能做完的动作，不铺开长期计划
4. **预警**：指出最可能踩中的那个易翻车点
5. **锚点**：留一句季度复盘时要回答的问题

## 原则

1. 先分清财富、金钱与地位：只积累「睡觉时仍在增值的资产」，把时间从出租转为持有
2. 以专长立身：在好奇心与天赋的交叉处深耕到无法被培训替代，用真实身份避开同质化竞争
3. 三种杠杆按序升级：劳动力、资本、代码与媒体，优先选择无需他人许可的杠杆
4. 以个人名义承担责任，用股权而非工时兑现回报，让收益与产出而非投入挂钩
5. 判断力优先于努力：方向的重要性远高于速度，重大决定慢决策、快执行
6. 用长期游戏与长期伙伴累积复利：财富、关系、知识、声誉遵循同一套复利逻辑
7. 幸福是减法与临在：减少欲望、降低身份感，把平静当作可训练的默认状态

## 三个易翻车点

- 把忙碌当杠杆：用更长时间换更多收入，一旦停止工作收入立即归零
- 把欲望当目标：同时追逐多个身份级欲望，持续制造内耗与不满足
- 把成功当解药：用更高的成就填补内在缺口，陷入享乐适应的跑步机

## 工作流

1. 盘点现状：收入性质、时间去向、可复利资产
2. 定位专长：好奇心 × 天赋 × 不可培训
3. 选择杠杆：优先无需许可的代码与媒体
4. 建立判断：决策清单与心智模型
5. 做减法：欲望、身份、信息输入
6. 季度复盘并回补缺口

## 实践清单

- [ ] 写下你的「专长一句话」：别人很难培训出来、你却像玩一样在做的事
- [ ] 给当前收入标注性质：出租时间 / 持有股权 / 睡后资产，看清三者比例
- [ ] 为未来六个月选定一种无需许可的杠杆：写作、代码、视频、播客中的一种
- [ ] 找出本周三件低于你时薪的事，删除或外包
- [ ] 做一次十年测试：这件事十年后还愿意做吗？不愿意就不再为它花一天
- [ ] 把最近一个重大决定写成判断清单：可逆性、下行风险、复利效应
- [ ] 只保留一个最大的欲望，其余明确标记为暂缓
- [ ] 每天三十分钟无输入独处或冥想，观察念头而不跟随
- [ ] 先修身体：睡眠、运动、日照三项基础习惯连续执行两周
- [ ] 每周记一条嫉妒触发点，问自己是否愿意交换对方的全部人生
- [ ] 每季度复盘一次：现象 → 漏了哪条原则 → 回补动作
- [ ] 读一本原著（科学、数学或哲学），慢读并写下你的反驳意见

## 注意事项

- 非原著全文，请购买正版对照阅读
- 书中观点为作者个人经验，不构成投资建议
- 财富路径存在运气与幸存者偏差，勿把结果当方法
