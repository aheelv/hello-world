# 《超预测》实践三问法

本 Skill 基于公开书评与作者公开表达的原创综合，用于实践辅导，不是原著全文，也不替代购买与阅读正版图书。

## 用途

把模糊判断改写成可结算的概率问题，拆解、更新、校准，并用记录替代「我早就说过」

## 原则

1. 用数字代替形容词：把「可能」换成 55%、63%
2. 细颗粒度：区分 55/45 与 60/40，说明你分辨了证据强度
3. 先取基准率，再用内视角调整
4. 拆成费米式小问题，定位最不确定的一环
5. 小幅频繁更新：既不过度反应，也不固守原判
6. 事前写下概率：没有记录，就会事后修改记忆

## 三个易翻车点

- 追求精确的错误：给 87.3% 却没有依据
- 只更新不校准：频繁改数字，但从不结算命中率
- 把校准当成决策：概率对了，行动仍可能错

## 工作流

1. 把问题写成事件、时间、判定标准三要素齐全的句子
2. 给出个位数颗粒度的初始概率
3. 写下基准率与该案例的偏离理由
4. 拆成三到五环，定位最不确定的一环
5. 设复核日期，小幅更新并记录
6. 结算后只评估校准，不评估单次输赢

## 实践清单

- [ ] 选一个你正在关心的判断（行业、项目、政策），把它写成可结算的问题：事件、时间、判定标准
- [ ] 先给出一个概率，颗粒度到个位（例如 63%，而不是「六成」）
- [ ] 写下你的内外视角：同类事情的基准率是多少，这个案例凭什么偏离
- [ ] 把问题拆成三到五环，标出哪一环的不确定性最大
- [ ] 为你的判断找两个先行指标，写清「出现什么说明我错了」
- [ ] 设一个复核日期，到点必须更新一次，变化不超过 10 个百分点
- [ ] 把最近五个判断列出来，标注发生 / 未发生，计算你的实际命中率
- [ ] 找出你最近一次「我早就说过」的时刻，问当时有没有写下概率
- [ ] 与一个观点不同的人交换理由（不是结论），只记录他提供了什么新证据
- [ ] 为你的团队设计一次「先独立写、再公开理由」的流程，本周用一次
- [ ] 把一个你坚信的宏大叙事，改写成三个可检验的小预测
- [ ] 复盘一次失败：区分哪部分是判断错，哪部分是运气差

## 引用边界

- 结论建立在 Good Judgment Project 的赛制上：问题可结算、有即时反馈、胜负可量化；现实战略判断往往缺少结算。
- 预测准确不等于决策正确：决策还涉及代价、后果与价值判断。
