# 《终身成长》实践三问法

本 Skill 基于公开书评与作者公开表达的原创综合，用于实践辅导，不是原著全文，也不替代购买与阅读正版图书。

## 用途

把「能力是判决」换成「能力可发展」，并把这种信念落到策略、反馈与表扬方式上

## 原则

1. 能力是起点不是判决：相信可发展，行为才会变
2. 努力要配策略：换方法、找反馈、求助，比重复更有效
3. 把失败从身份判断降级为行为信息
4. 表扬过程而非天赋：标签会把人锁进固定型坐标
5. 关系也需要练习：冲突是待调整的信号
6. 改变靠识别触发点、命名、教育，而不是靠「积极一点」

## 三个易翻车点

- 伪成长型思维：把努力当成新的证明方式，失败时依然羞耻
- 把成长型思维当万能药：忽略元分析显示的效应很小
- 只鼓励不教方法：告诉学生「你可以」却不给策略

## 工作流

1. 找出三个最容易退回固定型的情境
2. 把一个「我不行」改写成「哪一步方法不对」
3. 给那个固定型人格命名，下次先叫出它
4. 为弱项设计练习：目标、反馈来源、频次
5. 检查表扬方式：夸过程还是夸天赋
6. 接受起点，写下可观察的进步指标

## 实践清单

- [ ] 写下三个你最容易退回固定型思维的情境（被批评、遇到更强的同行、进入陌生领域）
- [ ] 回想最近一次失败，把「我不行」改写成「哪个环节的方法不对」
- [ ] 给那个在压力下出现的自己起一个名字，下次它出现时先叫出它
- [ ] 把一句你常说的「我不会」改成「我还没学会」，本周说三次
- [ ] 找一件你一直回避的事，只做十五分钟，目标定为「试一次」而非「做好」
- [ ] 检查你对孩子或学生的表扬：这周有几次是夸天赋，几次是夸过程
- [ ] 把一次批评重新翻译成「可操作的改进点」，写出三条
- [ ] 为自己的一个弱项设计练习：目标、反馈来源、每周次数
- [ ] 在一段关系里，把一句身份指控改成行为描述，试着说出来
- [ ] 列出你所在的组织奖励什么：看起来聪明，还是暴露问题并改进
- [ ] 复盘一次「我很努力但没进步」，检查是否缺了策略、反馈或求助
- [ ] 问自己：我现在是想证明自己，还是想变强？如果是前者，先停一下

## 引用边界

- 「成长型思维」被通俗化最严重：它不是「只要努力就能做到一切」，也不是「夸努力就行」。
- 2018 年 Sisk 等的元分析（Psychological Science）发现，成长型思维干预对学业成绩的平均效应很小，且高度依赖情境。
- 书中案例多来自访谈与个案，缺乏对照设计，存在「成功者都具备成长型思维」的事后归因风险。
