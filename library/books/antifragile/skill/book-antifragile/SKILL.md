# 《反脆弱》实践三问法

本 Skill 基于公开书评与作者公开表达的原创综合，用于实践辅导，不是原著全文，也不替代购买与阅读正版图书。

## 用途

先判断结构是脆弱还是反脆弱，再用杠铃、凸性与冗余，把不确定性从威胁变成燃料

## 原则

1. 先判断结构，再预测事件：不问黑天鹅何时来，只问它来了我是被压垮还是被抬高
2. 用杠铃替代中庸：一端确保生存，一端保留暴击可能，避开中等风险
3. 找凸性：损失有限、收益不设上限的事，值得多做几次
4. 保留冗余：现金、时间、备选方案不是浪费，是吸收冲击的结构件
5. 先做减法：不确定时，去掉明确的坏，比加上想象的好更安全
6. 只信有切身利害的人：不为建议承担后果的人，判断没有被校准过

## 三个易翻车点

- 把杠铃做成全仓激进：90% 的安全垫其实不存在，只剩 100% 的赌
- 把「反脆弱」当鸡汤：以为受苦就会变强，忽略压力需要上限与恢复期
- 用塔勒布的论战代替论证：嘲讽专家不等于建立了自己的判断

## 工作流

1. 列出最依赖的三件事，估算 30% 冲击下的损失
2. 给每项标注脆弱 / 坚韧 / 反脆弱
3. 只对脆弱项动手：先算最坏情况还剩什么
4. 设计杠铃：安全端与激进端各占多少
5. 留出冗余并写下触发条件
6. 找凸性机会：成本很低、上限很高的尝试

## 实践清单

- [ ] 列出你现在最依赖的三件事（收入、平台、关系），分别标注：如果遭遇 30% 冲击，我会损失多少
- [ ] 给每一项标出「脆弱 / 坚韧 / 反脆弱」，只对「脆弱」那几项动手
- [ ] 把可支配资金分成两段，写下两段的用途与最大可承受亏损
- [ ] 为你的职业设计一个杠铃：一份稳定现金流 + 一项成本极低、上限很高的探索
- [ ] 本周做一次「成本低于一顿饭钱」的尝试：投一个稿、做一个原型、约一个人
- [ ] 从待办清单里删掉三件事，删之前不问「有没有用」，只问「不做会怎样」
- [ ] 给你的系统留出冗余：现金、时间、备份方案各一份，并写下触发条件
- [ ] 检查你最近采纳的一条建议：给建议的人自己有没有为这个判断承担后果
- [ ] 写一份「反向讣告」：如果要让这门生意/这个项目一年内垮掉，最有效的三步是什么
- [ ] 把一个你已经做了三年的事，用林迪效应判断：它在十年后还存在吗
- [ ] 回顾最近一次预测，只记录判断与结果，不解释；连续记录十次再看校准
- [ ] 对一项正在犹豫的干预（换工作、做手术、上新系统），先问：不干预会怎样

## 引用边界

- 书中医学与营养学主张（如对补充剂、他汀类的质疑）争议很大，不能作为个人医疗决策依据。
- 对预测者、记者、经济学家的批评带有强烈论战色彩，论据多为轶事与修辞，需与结构性判断区分开。
- 「反脆弱」不等于「受苦就会变强」：压力需要上限与恢复期。
