# 《巴菲特致股东的信》实践三问法

本 Skill 基于公开书评与作者公开表达的原创综合，用于实践辅导，不是原著全文，也不替代购买与阅读正版图书。

## 用途

用所有者视角看生意：先判断护城河与定价权，再算资本配置与复利，最后才谈价格

## 原则

1. 先把自己当所有者：关心企业十年后还在不在，而不是下个季度的报价
2. 市场是报价源，不是判断依据：波动提供机会，不提供答案
3. 护城河决定你愿意付多少倍：要持久，且保护投入资本回报率
4. 定价权是唯一可靠的检验：能提价而不流失客户，才叫护城河
5. 复利靠时间不靠爆发：避免大额亏损与杠杆，别打断曲线
6. 资本配置是管理层的第一工作：每留存一美元，至少创造一美元市值

## 三个易翻车点

- 把「长期持有」当教条：对差生意，时间同样是敌人
- 用价格便宜代替生意质量：捡烟蒂的最后一口往往是亏的
- 把名言当成巴菲特原创：价格与价值、投票机与称重机都出自格雷厄姆

## 工作流

1. 用一句话说清这门生意靠什么赚钱
2. 列出护城河来源，判断它过去五年是变宽还是变窄
3. 检验定价权：提价 10% 会不会流失客户
4. 看自由现金流与净利润的差额来自哪里
5. 检查一美元原则：留存利润有没有创造等值市值
6. 最后才给估值区间与买入价格上限

## 实践清单

- [ ] 挑一家你持有的公司，用一句话说清它靠什么赚钱，说不清就先减仓到能说清为止
- [ ] 列出这家公司的护城河来源，并写下过去五年它是变宽了还是变窄了
- [ ] 判断它能不能在不流失客户的前提下提价 10%，写出依据
- [ ] 算出它过去五年的自由现金流，与净利润对比，看差额来自哪里
- [ ] 检查它留存的每一美元利润，是否创造了至少一美元的市值
- [ ] 写下一份「我不投什么」清单，至少五条，贴在能看见的地方
- [ ] 为你想买的一家公司算出内在价值区间，并写下你愿意买入的价格上限
- [ ] 回顾最近一次因为恐慌卖出的决定，问当时是价格变了还是价值变了
- [ ] 检查一家公司最近三年的「非经常性损益」，如果每年都有，把它当经常性成本重算利润
- [ ] 把你所有持仓按「懂 / 半懂 / 不懂」分成三堆，把「不懂」那堆清掉
- [ ] 给一个正在考虑的并购或扩张项目算：如果它失败，公司要几年才能恢复
- [ ] 重读一遍你三年前的买入理由，只判断它对不对，不判断赚没赚

## 引用边界

- 「价格是你付出的，价值是你得到的」与「短期投票机、长期称重机」均出自格雷厄姆，巴菲特在信中明确引用。
- 结论建立在美股长期向上的背景上，含明显时代与市场红利；移植到其它市场须重验前提。
- 致股东信带有向股东解释的修辞目的，需与年报数字、实际持仓变动对照阅读。

## 注意事项

- 非原著全文，请购买正版对照阅读
- 信中名言多引自格雷厄姆，引用时请标注原始出处
- 结论包含美国市场长期向上的时代红利，移植需重验前提
