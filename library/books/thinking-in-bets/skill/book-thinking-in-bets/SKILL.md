# 《对赌》实践三问法

本 Skill 基于公开书评与作者公开表达的原创综合，用于实践辅导，不是原著全文，也不替代购买与阅读正版图书。

## 用途

把决策与结果分开：用概率与期望值评估下注质量，用求真小组和事前验尸校准判断

## 原则

1. 决策与结果分开：好决策可能坏结果，坏决策可能赢
2. 警惕 resulting：不要从结果倒推决策质量
3. 把信念换成赔率：「你敢赌多少」比「你有多确定」更真实
4. 用期望值而非单次结果判断
5. 组求真小组：目标是一起更接近真相，不是赢争论
6. 事前验尸与 10-10-10：把未来具体化，剥离短期情绪

## 三个易翻车点

- 用「过程好」为坏结果免责：需要同时保留结果问责
- 把扑克类比用过头：现实很多决策不可重复、无法结算
- 只复盘不记录：事后仍会自动重写记忆

## 工作流

1. 把结果与决策分开打分
2. 列出当时可用的信息与忽略的线索
3. 把判断写成赌注：愿意押多少
4. 做一次事前验尸，写出三个失败原因
5. 用 10-10-10 检查时间尺度
6. 在求真小组里公开判断与理由

## 实践清单

- [ ] 选一个最近的结果（好或坏），把「决策质量」与「结果质量」分开打分
- [ ] 找出一个「用错方法但赢了」的经历，写下它固化了什么坏习惯
- [ ] 把你在做的一个判断写成赌注：我愿意为它押多少钱？这个数字说明我有多确定
- [ ] 为一项重要决定做一次事前验尸：假设已失败，写出三个最可能原因
- [ ] 用 10-10-10 检验一个正在纠结的选择，分别写下三个时间尺度的感受
- [ ] 列出三个能指出你错误的人，本周主动向他们暴露一个判断
- [ ] 在下次表达观点时，加上一句「我大概几成确定，可能忽略了……」
- [ ] 翻出你曾说过「我早就说过」的事，检查当时有没有写下判断
- [ ] 为一项重复性决策设一个下注上限，防止情绪上头时押太重
- [ ] 回顾一次亏损或失败，把原因拆成「判断」与「运气」两部分
- [ ] 把你的一个重要判断写给朋友，请他给出反对理由，只记录不辩解
- [ ] 问自己：这件事我是在评估，还是在为已经做出的决定找理由

## 引用边界

- 扑克有明确赔率、可重复局数与清晰结算；现实多数决策不可重复也不可结算，期望值只能作思考框架。
- 「结果与决策分离」若被滥用，会成为「业绩差但过程好」的免责话术，需同时保留结果问责。
