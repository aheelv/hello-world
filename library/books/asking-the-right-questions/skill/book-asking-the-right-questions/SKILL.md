# 《学会提问》实践三问法

本 Skill 基于公开书评与作者公开表达的原创综合，用于实践辅导，不是原著全文，也不替代购买与阅读正版图书。

## 用途

用十一问拆解论证：论题、理由、歧义、假设、谬误、证据等级、替代原因、数据与遗漏

## 原则

1. 先找论题与结论，再谈对错
2. 把论证画成结构：结论 ← 理由
3. 关键词要可操作：换一种理解，结论会不会变
4. 找出「一旦不成立、结论就崩」的假设
5. 给证据标等级：直觉 < 证词 < 专家 < 单一研究 < 多项研究
6. 找替代原因、查数据基数、问被省略的信息

## 三个易翻车点

- 只拆不建：批判到最后没有给出更稳的判断
- 把谬误清单当武器：用来赢辩论而不是校准自己
- 停在形式检查：论证形式对了，事实前提可能是假的

## 工作流

1. 写出论题，标明描述性还是规定性
2. 圈出结论与全部理由，画成结构图
3. 找出关键词并给可操作定义
4. 写出最脆弱的假设，找反例
5. 逐条检查谬误与证据等级
6. 列出替代原因、数据基数与缺失信息
7. 给出多个合理结论及其条件

## 实践清单

- [ ] 拿一篇你最近读的文章，用一句话写出它的论题，并标明是描述性还是规定性
- [ ] 圈出它的结论，检查：这是作者最想让你相信的那一句吗
- [ ] 把理由编号列出，逐条问：它真的能支撑这个结论吗
- [ ] 找出三个关键词，各写一种替代解释，看结论是否还成立
- [ ] 写出这个论证依赖的两个假设，标出哪个是价值观假设、哪个是描述性假设
- [ ] 用「如果不成立，结论会不会崩」筛出最脆弱的那个假设
- [ ] 逐条检查是否有谬误：人身攻击、诉诸权威、诉诸公众、滑坡、虚假两难
- [ ] 给每条证据标等级：直觉 / 经验 / 证词 / 专家 / 单一研究 / 多项研究
- [ ] 为作者给出的因果关系想两个替代原因
- [ ] 检查文中所有百分比：基数是多少？绝对数是多少？
- [ ] 列出三个「要判断这件事，我还需要知道」的信息
- [ ] 把结论改写成「如果……那么……」，并写出至少一个其它合理结论

## 引用边界

- 本书训练的是论证形式的识别，不能替代对事实本身的核查：形式完美的论证，前提可能是假的。
- 过度使用会带来副作用：把所有表达都当作待拆解的论证，会让人难以被说服、也难以建立信任。
- 谬误名称与分类在不同版本间略有调整，引用具体条目时请核对所用版本。

## 注意事项

- 非原著全文，请购买正版对照阅读
- 形式检查不能替代事实核查
- 过度使用会损害信任，应以强势批判为先
