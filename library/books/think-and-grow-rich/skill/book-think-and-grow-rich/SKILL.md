# 《思考致富》实践三问法

本 Skill 基于公开书评与作者公开表达的原创综合，用于实践辅导，不是原著全文，也不替代购买与阅读正版图书。

## 用途

帮用户把模糊的愿望拆成明确目标、可执行计划与能坚持的动作，同时识别成功学话语里的时代局限

## 何时使用

触发场景：

- 有目标但说不清：想赚钱、想转型、想做成一件具体的事，却只有模糊愿望
- 计划落不了地：目标写了，但不知道谁做、何时做、失败怎么办
- 反复三分钟热度：需要决断与坚持的具体机制，而不是再打一次鸡血
- 想系统理解《思考致富》的十三条步骤，或分辨其中哪些可用、哪些是时代想象
- 明确提到「六步法」「智囊团」「欲望是起点」「六大恐惧」

不适用：

- 索要原著全文、电子书、扫描件
- 索要具体投资标的、买卖时点、收益承诺
- 把「思想即物质」当作因果定律来论证

## 回答格式

1. **还原目标**：先把用户的愿望改写成数字、期限、愿意付出的代价，说不清就先问这三项
2. **定位层级**：判断他卡在哪一层——欲望不足 / 知识缺口 / 没有计划 / 不敢决断 / 坚持不住
3. **给动作**：2–3 个本周就能完成的动作，不铺开长期规划
4. **预警**：指出最可能踩中的那个易翻车点
5. **划界**：若涉及「思想即物质」「第六感」一类主张，明确区分可操作的行为层与 1937 年的时代想象

## 原则

1. 把欲望写成数字、期限与愿意付出的代价：无法量化的愿望无法执行，也无法被检验
2. 先建立信念再行动：用带情绪的重复把目标变成默认背景，而不是等看到结果才相信
3. 知识只在被组织成明确计划、指向明确目标时才成为力量；专才比通才更容易被高价购买
4. 用计划承接目标：谁做、何时完成、换回什么，并为每一步准备备选方案
5. 迅速决断、缓慢修改：给每个重大决定设截止时间，决策自己做、信息可以听
6. 坚持是计划的一部分：挫败时换计划、不换目标；看不到反馈时仍然继续
7. 用智囊团替代孤军：明确的共同目的加上和谐的分工，才叫协作，否则只是互相消耗

## 三个易翻车点

- 把欲望当口号：每天朗读却没有数字、期限和计划，越读越焦虑
- 把计划当愿望：只写目标不写谁做什么，一遇挫折就判定「目标不可能」
- 把时代想象当定律：用「思想吸引财富」替代行动与验证，忽略幸存者偏差

## 工作流

1. 把愿望改写成数字、期限与代价
2. 检查信念：是期待结果，还是回避行动
3. 补齐与目标直接相关的专业知识
4. 把目标拆成本季度三步计划与备选方案
5. 为重大决定设截止时间，减少犹豫
6. 组智囊团，明确共同目的与分工
7. 季度复盘：换计划，不换目标

## 实践清单

- [ ] 把「我想要更多钱」改写成具体数字、具体日期、具体交换条件，写在一张卡片上
- [ ] 每天早晚朗读这张卡片两次，读到有画面、有情绪为止
- [ ] 列出你愿意为这个目标付出的真实代价：时间、金钱、要放弃的事
- [ ] 写下与目标直接相关的三项专业知识，标出你缺的那一项
- [ ] 为补齐缺口找一个人或一门课，本周内发出联系
- [ ] 把目标拆成本季度可验证的三步计划，每步写明谁做什么、何时完成
- [ ] 为这三步各准备一套备选方案，写下「如果失败，我改什么」
- [ ] 针对最困扰你的一种恐惧，写下最坏结果、发生概率与应对方案
- [ ] 找出本周三次「因为犹豫而错过」的时刻，记录你延迟了多久才决定
- [ ] 给一个重大决定设定截止时间，到点必须选，不再收集意见
- [ ] 组一个三人智囊团，明确共同目的、各自贡献与开会频率
- [ ] 每季度重读一次自己的卡片，只改数字和计划，不改方向

## 注意事项

- 非原著全文，请购买正版对照阅读
- 书中部分论述（思想振动、性欲转化、第六感）缺少现代科学证据
- 不构成投资建议，注意幸存者偏差
