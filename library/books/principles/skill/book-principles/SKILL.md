# 《原则》实践三问法

本 Skill 基于公开书评与作者公开表达的原创综合，用于实践辅导，不是原著全文，也不替代购买与阅读正版图书。

## 用途

把目标、问题、诊断、方案、执行拆成五步，并把有效做法固化成可复用的原则

## 原则

1. 先看清现实，再谈目标：把「应该怎样」换成「实际怎样」
2. 用五步流程承接任何目标：目标—问题—诊断—方案—执行，顺序不能跳
3. 把痛苦当信号：痛过之后必须产出机制上的改变，而不是情绪上的检讨
4. 极度开放是为了更快学习：主动找能看到自己盲点的人，并给意见加权
5. 区分设计者与工作者：退后一步看机器，而不是在机器里更用力
6. 把有效做法写成原则：当……时，我会……，因为……

## 三个易翻车点

- 把「极度透明」当成当面批评：缺少信任与退出机制时，它只制造防御
- 只用五步流程的前两步：不停设目标、找问题，从不诊断与执行
- 反思变成自责：写检讨不改机制，同样的错下季度再来一次

## 工作流

1. 写清目标，必须可判断是否达成
2. 列出正在发生的问题，不许用「还好」掩盖
3. 连问五次为什么，找到根因
4. 把方案写成谁做什么、何时完成、怎么验证
5. 本周完成第一个动作，并设复核日期
6. 把结论写成一条「当……我会……」的原则

## 实践清单

- [ ] 把当前最重要的一件事写成一句话目标，必须能判断「做到 / 没做到」
- [ ] 为这个目标列出三个正在发生的问题，不许用「还好」掩盖
- [ ] 对最痛的那个问题做根因分析：连问五次「为什么」，写到不能再问为止
- [ ] 把根因对应的方案写成动作清单：谁、做什么、何时完成、怎么验证
- [ ] 本周内完成方案里的第一个动作，并在日历上标出验收时间
- [ ] 挑一个你一直在回避的反馈，主动去问，只记录不辩解
- [ ] 列出你在这件事上的「可信度」：过去五次类似判断对了几次
- [ ] 找一个在你弱项上很强的人，明确请他做你的「盲点补丁」
- [ ] 把最近一次失败写成三行：发生了什么、暴露了什么、机制上改什么
- [ ] 为你常做的决定写一条原则，格式是「当……时，我会……，因为……」
- [ ] 把本月的一个重要决定连同当时的理由存档，三个月后回看
- [ ] 检查你最近一次不舒服：是事情错了，还是「应该」错了

## 引用边界

- 「他靠水晶球活着，就会吃到碎玻璃」在网上被广泛归给达利欧，但据引文核对，它既不在 2011 年免费版 PDF，也难以在 2017 年成书中找到；类似说法更早出自 Edgar Fiedler。
- 「极度透明」依赖桥水特定的资本结构、招聘筛选与高薪激励，直接搬进学校或普通公司往往只留下「当面批评」。
- 原书由作者自述成功经验，存在事后归因；建议对照 2023 年《The Fund》等调查报道。

## 注意事项

- 非原著全文，请购买正版对照阅读
- 桥水的极度透明依赖特定资本结构与高薪筛选，移植需谨慎
- 书中存在事后归因，建议对照第三方调查报道阅读
