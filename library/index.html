如何新增一本书

每本书是一个独立目录，页面骨架完全相同，差异只在 data.js。新增一本书分三步：

  1. 复制 books/_template/ 为 books/你的书名拼音/
  2. 改写其中的 data.js（主题、观点、金句、清单、来源）
  3. 在 assets/books.js 的 books 数组里追加一条记录，用 group 指定模块

刷新本页即出现新卡片；模块分区、筛选按钮、书籍页的「切换书籍」下拉、上一本/下一本、统计数字都会自动更新。新增模块只需在 groups 数组里加一条 { id, no, title, desc }。

{
  slug: 'your-book',              // 目录名，须与 books/ 下一致
  title: '书名',
  titleEn: 'Book Title',
  author: '作者',
  color: '#2E5C8A',               // 本书主色
  tag: '主题一 · 主题二',
  group: 'c',                     // 归入哪个模块
  summary: '一句话说明这本书解决什么问题',
  status: 'ready'                 // ready = 上线；planned = 显示为“整理中”
}

数据字段说明见 README.md 与 books/_template/data.js 的注释。

说明：本页只做读书整理索引，各书页面为结构化摘要与少量引文，不是原著全文，也不替代购买正版。引文的英文以原书为准，中文为编译译述。
