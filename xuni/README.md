# OR-SimLab · 运筹学虚拟仿真实验教学平台

> 把运筹学课本上的模型，放进可以动手调参的真实业务场景里。

一个面向运筹学课程的虚拟仿真实验教学平台：**15 个分层实验场景 · 76 道配套练习 · 55 个知识点的知识图谱 · AI 大模型助教**，全部运算在浏览器内完成，零外部依赖，断网可用。

---

## 快速开始

### 方式一：直接打开（最简单）

```
双击 index.html
```

无需安装任何软件。适用于教师备课、外出答辩、无网络的教室。

### 方式二：本地服务器（推荐用于完整功能）

```bash
cd /path/to/虚拟仿真
python -m http.server 8080
# 浏览器访问 http://127.0.0.1:8080/
```

与直接打开功能完全一致（全站零外部请求，无任何依赖 CDN）；学习数据以 `http://` Origin 存储，便于多标签页共享。

### 方式三：部署到局域网 / 公网

见 [`docs/04-部署方案.md`](docs/04-部署方案.md)，包含 Nginx、IIS、Python、NSSM、对象存储五种配置。

## 三分钟上手

| 步骤 | 操作 | 你会看到 |
| --- | --- | --- |
| 1 | 打开平台，点击「生产计划优化」 | 家具厂的桌椅产量优化问题 |
| 2 | 把「木料可用量」滑块从 120 拖到 160 | 最优利润 2050 → 2500，**木料影子价格 15 → 0** |
| 3 | 再把滑块拖到 100 | 影子价格变成 **17.5** —— 同一资源三个区间三个价格 |
| 4 | 点右侧 AI 助教，选「结果诊断」，点快捷提问 | 助教结合你刚调的数值解读结果 |
| 5 | 切到「配套练习」页签做一道题 | 即时判分 + 详细解析，答错自动进错题本 |
| 6 | 切到「知识图谱」页签 | 本实验关联的 6 个知识点按「支撑 → 核心 → 拓展」三层展开 |
| 7 | 打开左侧「知识图谱」总线 | 55 个知识点全图、领域覆盖率、拓扑学习路径、常见误区 |
| 8 | 打开左侧「学习档案」 | 探索进度、知识点掌握度、薄弱环节、下一步建议 |

> **这一步的教学含义**：影子价格只在允许区间内有效。有余量的资源，边际价值为零。学生拖一次滑块建立的直觉，胜过背十遍公式。

## 知识库 × 知识图谱

平台不只是「有知识点」，而是让知识点**可导航、可追踪、可教学**。

### 知识库：55 个结构化知识点，10 个领域

每个知识点不是一段话，而是一条结构化记录：

| 字段 | 内容 |
| --- | --- |
| `definition` | 一句话定义 |
| `formula[]` | 核心公式（含符号说明） |
| `keyPoints[]` | 必须掌握的要点 |
| `mistakes[]` | 常见误区 + 纠正说明 |
| `example` | 教学示例 |
| `hint` | 引导式提示（不直接给答案） |
| `prereq[]` / `related[]` | 前置知识与相关知识点 |

覆盖领域：线性规划、运输与指派、整数规划、网络优化、库存理论、排队论、动态规划、决策分析、马尔可夫链、仿真方法。

### 知识图谱：70 节点 · 227 条边

| 边类型 | 数量 | 语义 |
| --- | ---: | --- |
| `prereq` | 60 | 有向前置依赖（学 A 之前需要 B） |
| `related` | 73 | 无向相关（横向关联） |
| `lab` | 94 | 知识点 ↔ 实验的关联（`role = core / support / extend`） |

图谱不是画出来的静态图，而是可计算的图结构：

- **Kahn 拓扑排序** → 生成有向无环的学习路径
- **DFS 环检测** → 保证前置关系自洽
- **BFS 最短路** → 计算两个知识点之间的认知距离
- **传递前置 / 后继链** → 回答「学这个之前要补哪些」
- **邻域与诱导子图** → 知识点详情页的局部网络

### 五种布局

| 布局 | 适用场景 |
| --- | --- |
| `cluster` | 按领域分环形簇，看全局结构 |
| `layered` | 按难度三列排布，看学习梯度 |
| `force` | Fruchterman-Reingold 力导向，看聚类结构（以 cluster 为初值保证每次渲染一致） |
| `focus` | 以某知识点为中心径向展开，看局部网络 |
| `tiers` | 支撑 → 核心 → 拓展三层，看单个实验的依赖结构 |

### 深度绑定：15 个实验 × 平均 6.3 个知识点

每个实验在 `knowledge` 字段声明三层知识点：

```js
knowledge: {
  core:    ['lp-model', 'lp-simplex', 'lp-dual'],   // 本实验主攻
  support: ['lp-graphical'],                        // 需要前置掌握
  extend:  ['lp-sensitivity', 'lp-blending']        // 学有余力可拓展
}
```

这种绑定贯穿到系统的每个角落：

| 位置 | 融合方式 |
| --- | --- |
| 实验工作台头部 | 显示关联知识点标签条，core / support / extend 三色区分 |
| 实验「知识图谱」页签 | tiers 布局绘制本实验的知识依赖，下方三层卡片可点击跳转 |
| AI 助教（实验内） | 提问时自动注入三层知识点、第一条核心公式、前 4 条常见误区作为上下文 |
| AI 助教（知识点内） | 「AI 精讲」注入 9 行结构化上下文，按四种角色分别组织回答 |
| 知识中心 | 5 个页签：图谱总览 / 领域覆盖 / 学习路径 / 知识点检索 / 常见误区 |
| 知识点详情页 | 定义、公式、要点、示例、误区 + 掌握度明细 + 局部网络 + 拓扑前后导航 |
| 学习档案 | 「知识图谱覆盖」区块：全局掌握率环 + 四级堆叠条 + 10 个领域的覆盖进度 |
| 首页 | 知识地图卡：55 节点 cluster 全图 + 四级图例 + 学习覆盖率 |
| 顶栏搜索 | 双段结果：实验场景 + 知识点 |

### 掌握度模型

```
掌握度 = 正确率 × 0.75 + 探索次数 × 0.25
其中 探索次数 = min(1, runs / 12)
```

四级判定：未学习 / 初步了解 / 基本掌握 / 熟练应用，并支持学生手动标记（如课堂讲授过）。

## 核心特性

### 零依赖

不使用 React / Vue / ECharts / Chart.js，不使用任何 CDN，也没有构建步骤。算法内核、仿真引擎、图表库、知识图谱引擎、UI 组件库全部自研，约 **16 200 行**代码。

| 收益 | 说明 |
| --- | --- |
| 双击即用 | 不需要 Node.js、不需要安装 |
| U 盘分发 | 拷贝文件夹即可在无网络教室使用 |
| 可读可改 | 教师可直接编辑源码，刷新即生效 |
| 体积小 | 首屏 311 KB（gzip 后 ≈75 KB），加载 ≈300 ms |

### 正确性可验证

教学系统最隐蔽的风险是：**错误的结论被学生当作知识记住。**

平台用五种**互不依赖**的手段验证算法，累计 **345 项自动化断言全部通过**：

| 手段 | 适用对象 | 断言数 |
| --- | --- | ---: |
| 交叉验证（与等价线性规划比对） | 运输问题 | 6 |
| 暴力枚举比对（全排列 / 全子集） | 指派问题、背包、资源分配 | 10 |
| 算法互证（Floyd 与 Dijkstra） | 最短路 | 3 |
| 解析解对照（统计一致性） | 排队仿真、PERT、库存、马尔可夫 | 30 |
| 结构约束校验（流守恒等） | 网络流、运输问题 | 9 |
| 契约完整性与分支覆盖 | 场景集成 | 30 |
| 知识图谱结构校验 | 知识库、图谱、布局、SVG | 59 |
| 浏览器渲染回归（jsdom 驱动全路由） | 视图层与交互 | 117 |
| 其他专项断言 | 各算法 | 32 |

场景冒烟测试还会遍历 **189 个参数分支变体**（枚举型逐个取值、数值型取上下界、开关型翻转），断言任何滑杆位置都不产生 `NaN` / `Infinity`。

验证过程共发现 **9 个真实缺陷**，包括 2 个严重缺陷（离散事件仿真的服务台堆管理错误、大样本直方图调用栈溢出）。详见 [`docs/03-实验验证.md`](docs/03-实验验证.md) 第五章。

### AI 助教：四种角色 + 两级通道

| 角色 | 定位 |
| --- | --- |
| 概念答疑 | 讲清原理，「先直觉、后形式化」 |
| **引导提示** | **苏格拉底式引导，绝对不直接给答案** |
| 结果诊断 | 解读当前数据，给出可执行建议 |
| 变式出题 | 基于当前模型生成新练习题 |

两级推理通道，端点不可用自动降级，**AI 不可用率为 0**：

```
大模型端点（兼容 OpenAI 协议，由使用单位在设置页填写）  →  离线知识引擎（纯本地）
```

离线引擎不只是关键词匹配——它直接读取知识库的结构化字段，能回答「这个知识点的定义是什么」「常见误区有哪些」「学它之前要补什么」。

### 学习数据可沉淀、可携带

- 记录每次求解与每次作答
- 学习档案：分层进度、知识点掌握度、知识图谱覆盖率、薄弱环节、下一步建议
- 一键导出 JSON，可附在实验报告里
- 教师可批量汇总（`node tools/collect.js ./学生档案/`）
- **不采集任何身份信息**，数据存于学生本机

## 常用命令

```bash
# ── 自检（345 项断言 + 189 个参数分支变体）───────
node assets/js/lib/__selftest.js         # 算法内核 · 30 项
node assets/js/lib/__selftest_sim.js     # 仿真引擎 · 60 项
node assets/js/labs/__smoketest.js       # 场景集成 + 参数极值遍历 · 30 组 / 189 个变体
node assets/js/kb/__kbtest.js            # 知识图谱 · 59 项
node tools/verify-browser.js             # 浏览器端渲染回归 · 117 项（需 jsdom）

# ── 教学实验数据 ─────────────────────────────────
node tools/exp-report.js                 # 7 组实验，输出到 stdout
node tools/exp-report.js > out.txt       # 保存到文件

# ── 文档维护（修改 docs/*.md 后必须执行）────────
node tools/build-docs.js

# ── 教师：汇总全班学习档案 ──────────────────────
node tools/collect.js ./学生档案/
node tools/collect.js ./学生档案/ --csv > 班级统计.csv

# ── 本地服务 ─────────────────────────────────────
python -m http.server 8080
```

> **提示**：`verify-browser.js` 依赖 jsdom。若未安装，可用 `npm i -D jsdom`，或用 `NODE_PATH` 指向已有安装位置。

## AI 通道配置

作品**不内置任何第三方地址或密钥**。默认以**离线知识引擎**作答（纯本地、零网络请求），开箱即用。

若需接入大模型（学校私有化部署或第三方 API），在「设置 → AI 服务」页填写：

| 字段 | 说明 |
| --- | --- |
| API Base URL | 如 `http://10.0.0.5:8000/v1`（需包含版本路径） |
| API Key | 仅存于本机浏览器，由浏览器直连你的端点 |
| 模型名称 | 如 `qwen2.5:14b`、`deepseek-chat` |

服务端只需兼容 OpenAI 的 `POST {Base}/chat/completions` 接口。已在 vLLM、Ollama、DeepSeek、通义千问（兼容模式）上验证。

**注意**：端点未填写、密钥失效或网络不可用时，系统自动降级到离线知识引擎，功能不中断。`file://` 直接打开时若浏览器限制跨域请求，同样走离线通道；需要大模型能力时建议用 `python -m http.server` 启动本地服务。

## 已知边界

| 边界 | 说明 |
| --- | --- |
| 非通用求解器 | 建议变量数 ≤ 50；定位是教学演示与中等规模问题 |
| 数据存本地 | 换设备需手动迁移（提供 JSON 导出） |
| 排队论限制 | 仅支持指数分布到达；M/G/1 已覆盖服务时间非指数情形 |
| PERT 未考虑工期相关性 | 已在文档中说明，作为进阶讨论点 |
| 无整数规划通用解法 | 覆盖指派问题与背包 / 资源分配，与课程主干匹配 |
| 知识图谱规模 | 55 个知识点覆盖课程主干；扩展需同时维护 `prereq` / `related` 与实验绑定三层关系 |
| 掌握度模型为启发式 | 正确率 0.75 + 探索 0.25 为教学经验权重，非心理测量学标定结果 |
